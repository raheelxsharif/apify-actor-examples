    Apartments.com Rental Listing & Floor Plan Scraper is an Apify Actor published by Dataspryva. It accepts 23 input fields, none of them required at the top level. Each result can carry up to 15 declared fields, including name, address, city, state, zipCode and priceMin. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Services”, “How it works”, “Input”, “Output” and “Usage cost”.

    What it costs

    Apartments.com Rental Listing & Floor Plan Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

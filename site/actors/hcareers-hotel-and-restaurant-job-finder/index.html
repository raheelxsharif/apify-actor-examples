    Hcareers Hotel & Restaurant Job Finder by Category is an Apify Actor published by Dataspryva. It accepts 14 input fields, and mode is required. Each result can carry up to 7 declared fields, including title, employer, location, category, employmentType and compensation. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Output per employer (mode = employers)”, “Input”, “Use cases” and “FAQ”.

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (kitchen jobs in california, full-time). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Hcareers Hotel & Restaurant Job Finder by Category uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "search"; Allowed search, allJobs, byUrls, employers
    keywordsKeywordsstringFree-text search terms (job title, skill, employer/brand name). Leave empty to browse by category/state/brand only. (mode=search)Example "chef"
    locationLocationstringCity, region, or landmark to search near (e.g. New York, NY, Miami Beach). (mode=search)
    stateState / ProvincestringRestrict to a US state or Canadian province. Oregon, Puerto Rico and Quebec are kept for older saved tasks; they have no current Hcareers postings. (mode=search)Allowed AL, AR, AZ, BC, CA, CO, CT, DC and 44 more
    categoryJob categorystringRestrict to a specific hospitality job category. (mode=search)Allowed administrative, bartender-mixologist, catering-banquet, chefs-kitchen, development-construction, engineering-maintenance, executive, finance-accounting and 18 more
    brandHotel brandstringRestrict to jobs at properties of a specific hotel brand or group. (mode=search)Allowed ac-hotels, aloft-hotels, autograph-collection, baymont-inn-suites, best-western, cambria-hotels, candlewood-suites, canopy-by-hilton and 41 more
    remoteOnlyRemote jobs onlybooleanOnly remote-eligible positions. On its own this uses Hcareers' dedicated remote list; combined with other filters it keeps only remote matches of the combined search. (mode=search)Default false
    employmentTypesEmployment typearrayKeep only jobs whose listing badges match one of the selected types. (mode=search)Default []; Allowed Full-Time, Part-Time, Temporary, On-Call, Seasonal
    jobUrlsJob URLs (mode=byUrls)arrayDirect Hcareers job posting URLs or job IDs, e.g. https://www.hcareers.com/jobs/4239412-bell-person or 4239412.Default []
    employerUrlsEmployer profiles (mode=employers)arrayHcareers employer profile URLs or slugs, e.g. https://www.hcareers.com/omni-hotels-resorts or grand-casinos.Default []
    includeEmployerJobsInclude employer's open jobsbooleanAlso collect each employer's open job postings beside its profile. (mode=employers)Default true
    fetchFullDescriptionFetch full job descriptionsbooleanIn mode=search, visit each job's detail page for the full description, pay, apply link, photos and property profile. Always on for mode=allJobs and mode=byUrls. (mode=search)Default true
    updatedSinceOnly jobs updated since (mode=allJobs)stringOptional cutoff for incremental runs — a date 2026-10-11 or a full timestamp 2026-10-11T08:30:00. Only jobs whose Hcareers index entry changed on/after it are returned.
    maxItemsMax itemsintegerHard cap on emitted records (jobs plus employer profiles).Default 24; Allowed 1 to 5000

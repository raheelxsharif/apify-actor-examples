    Snapchat Snap Map Place & Live Snap Extractor is an Apify Actor published by Dataspryva. It accepts 21 input fields, none of them required at the top level. Its build declares no dataset fields; the published README describes the output. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can collect”, “Modes”, “Input”, “Output”, “How the popularity heatmap works” and “Limits”.

    What you get

    The Actor saves one record per result to an Apify dataset. The build declares no dataset view; the README documents 8 fields. Fields without a value can be left out of a record.

    Output fields

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerKeyword (default 10, maximum 50) caps how many results a run collects, and so what it costs.

    What it costs

    Snapchat Snap Map Place & Live Snap Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 21 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringChoose what to scrape: search Snap Map places by keyword, look up specific place URLs or IDs, or browse US cities and categories.Default "searchPlaces"; Allowed searchPlaces, placeDetails, browseLocal
    keywordsPlace keywordsarrayPlace names, landmarks, venues or addresses to search on Snap Map. Used in Search places mode. Examples: Times Square, Eiffel Tower, Tokyo Station.Default []; Example ["Times Square"]
    placeUrlsPlace URLs or IDsarraySnapchat place page URLs, /place/ paths, or bare place UUIDs. Used in Get details mode. Example: https://www.snapchat.com/place/times-square/c8b4f0ee-9992-11e8-88c9-673ed985ff70.Default []
    cityUrlsCitiesarrayUS city names, Snapchat local URLs, or local paths for Browse mode. Examples: new-york, chicago, https://www.snapchat.com/local/united-states/california/los-angeles.Default []
    categoriesCategoriesarrayOptional category slugs for Browse mode, such as bars, restaurants, coffee-shops, historic-landmarks or parks. Leave empty to use the city hub's six featured categories.Default []
    resultTypesResult typesarrayWhich Explore result groups to return in Search places mode. Places is the Snap Map place search; the other groups are the public entities Snapchat shows for the same keyword.Default ["places"]; Allowed places, spotlight, users, profiles, publishers, episodes, lenses
    outputTypeOutput rowsstringPlace records keep one row per place with live snaps nested. Live snap records flatten every live snap into its own row with the place's coordinates, which is easier for maps and time-series analysis.Default "placeRecords"; Allowed placeRecords, liveSnapRecords
    maxResultsPerKeywordMax results per keywordintegerMaximum rows to keep for each result type per keyword. Snapchat returns up to 10 places and roughly 20-24 items for the other groups.Default 10; Example 1; Allowed 1 to 50
    maxPlacesMax placesintegerMaximum places to process in Get details mode.Default 100; Example 1; Allowed 1 to 500
    maxPlacesPerCityMax places per cityintegerMaximum places to keep per city in Browse mode after merging the hub categories.Default 100; Example 20; Allowed 1 to 500
    maxSnapsPerPlaceMax live snaps per placeintegerMaximum live snaps to keep per place. Snapchat's public page exposes a sample of 2-36 current snaps per place.Default 10; Example 3; Allowed 1 to 50
    includeSnapDataInclude live snapsbooleanAdd the public snap sample for each place with media URL, thumbnail, creator and timestamp. Snapchat mixes recent map posts with older Spotlight shares, so use the age filter below to keep only fresh posts. Also fills the legacy first-snap fields.Default true

    Input fields in the published schema, continued
    FieldTypeDescription
    includePlaceDetailsInclude full place detailsbooleanOpen each place page to fill coordinates, address, phone, website, category, rating, reviews, opening hours, popularity and nearby places. Turn off for a faster search-card-only run. Nearby places, reviews, favorite sorting, live-snap output and the live-snap filter open place pages automatically because those values only exist there.Default true
    includeNearbyPlacesInclude nearby placesbooleanAdd the places Snapchat lists at the same location, with their coordinates and categories.Default false
    includeReviewsInclude place reviewsbooleanAdd up to 20 public place reviews with rating, text, date and source URL.Default false
    includePopularityHoursInclude 7x24 popularitybooleanAdd Snapchat's 168 hourly popularity values per place (7 days x 24 hours) plus the peak hour and day index. This is the per-place heatmap signal.Default true
    minRatingMinimum ratingnumberKeep only places whose public rating is at least this value. Places without a rating are dropped when this is above 0.Default 0; Allowed 0 to 5
    requireLiveSnapsOnly places with live snapsbooleanDrop places that currently have no public live snaps.Default false
    snapMaxAgeHoursOnly snaps newer than (hours)integerKeep only snaps posted within this many hours. Set 0 to keep every snap the public page returns. liveSnapCount and latestSnapAt describe only the kept snaps, and the live-snap filter uses that kept count.Default 0; Allowed 0 to 168
    sortBySort bystringOrder places by Snapchat's source order, rating, favorite count or number of live snaps.Default "source"; Allowed source, rating, favorites, liveSnaps

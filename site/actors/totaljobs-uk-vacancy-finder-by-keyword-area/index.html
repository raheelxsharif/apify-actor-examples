    Totaljobs UK Vacancy Finder by Keyword, Area & Pay is an Apify Actor published by Dataspryva. It accepts 12 input fields, and mode is required. Each result can carry up to 11 declared fields, including title, company, location, salary, salaryMin and salaryMax. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (nursing jobs across manchester, newest first). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Totaljobs UK Vacancy Finder by Keyword, Area & Pay uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredChoose what to scrape. The last three values are aliases kept for tasks saved before the revamp.Default "search"; Allowed search, browseLocation, byUrls, searchJobs, searchByLocation, searchBySalary
    keywordsKeywordsarrayJob titles or search terms, e.g. software developer or registered nurse. Each keyword is searched separately. (mode=search)Example ["software developer"]
    locationLocationstringUK town, city, county or postcode, e.g. London, Manchester, Edinburgh, SW1A. Leave empty to search the whole UK by keyword.Example "London"
    postedWithinDate postedstringOnly include jobs posted within this window. Leave empty for any date.Allowed 1, 3, 7, 14
    workFromHomeWork from homestringInclude only home-working roles, or exclude them. Leave empty for both.Allowed only, exclude
    jobTypeJob typestringEmployment type as classified by Totaljobs. Leave empty for all types.Allowed permanent, contract, temporary, part-time, work-from-home, full-time, internship, apprenticeship
    salaryMinMinimum salary (£/year)integerOnly keep jobs whose advertised pay reaches this annual amount. Hourly and daily rates are converted to a yearly figure. Jobs without a published salary are skipped when a salary filter is set.Allowed 0 to 500000
    salaryMaxMaximum salary (£/year)integerOnly keep jobs whose advertised pay starts at or below this annual amount. Hourly and daily rates are converted to a yearly figure.Allowed 0 to 500000
    includeDetailsOpen each job pagebooleanFetch full descriptions, exact posting and expiry dates, parsed salary bands, company details, map coordinates and apply links. Turn off for a faster, lighter listing-only run.Default true; Example false
    onlyNewJobsOnly new jobsbooleanReturn only jobs that were not present in the previous run of this same search. The first run returns everything and seeds the baseline.Default false
    maxItemsMax jobsintegerMaximum number of jobs to save. Totaljobs returns at most 100 jobs per search query; above that the actor automatically splits the search by area and filters to reach more.Default 100; Example 3; Allowed 1 to 5000
    urlsTotaljobs URLsarraySearch pages, company job pages or individual job pages. You can mix them. (mode=byUrls)

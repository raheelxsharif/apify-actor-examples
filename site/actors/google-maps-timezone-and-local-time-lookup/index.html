    Google Maps Timezone & Local Time Lookup is an Apify Actor published by Dataspryva. It accepts 9 input fields, none of them required at the top level. Each result can carry up to 28 declared fields, including recordType, mode, inputAddress, inputLocation, placeName and formattedAddress. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What you can look up”, “Inputs”, “Output fields”, “Examples”, “Use cases” and “FAQ”.

    What it costs

    Google Maps Timezone & Local Time Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringCoordinates resolves latitude/longitude pairs. Place looks up an address, landmark or business name. Place ID resolves a Google Place ID or Maps URL. Mixed processes every filled list in one run.Example "coordinates"; Allowed coordinates, place, placeId, mixed
    locationCoordinates (single)objectOne coordinate as {"lat": 40.7128, "lng": -74.006}. Decimal degrees, WGS84.Example {"lat": 40.7128, "lng": -74.006}
    locationsCoordinates (batch)arrayA list of coordinates, each {"lat": 40.7128, "lng": -74.006}.
    addressAddress or place name (single)stringOne address, landmark, business name or postcode. Example: Eiffel Tower, Paris.
    addressesAddresses or place names (batch)arrayOne address, landmark, business name or postcode per line.
    placeIdPlace ID or Google Maps URL (single)stringOne Google Place ID (starts with ChIJ) or a full Google Maps place URL.
    placeIdsPlace IDs or Google Maps URLs (batch)arrayOne Google Place ID or Google Maps place URL per line.
    languageLanguagestringLanguage Google Maps uses for returned place names, addresses and country names. It does not translate the query itself.Default "en"; Allowed en, en-GB, de, fr, es, es-419, it, pt-BR and 27 more
    countryCountry or region bias (optional)stringOptional ISO 3166-1 alpha-2 country code. The country name is added to place and address queries so an ambiguous search resolves in that country first. Leave empty for no bias.

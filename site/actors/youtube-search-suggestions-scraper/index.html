    YouTube Search Suggestions Scraper is an Apify Actor published by Dataspryva. It accepts 19 input fields, and queries is required. Each result can carry up to 8 declared fields, including suggestion, seed, type, rank, locale and source. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per suggestion”, “Input”, “Examples”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 8 fields in 1 dataset view, and the README documents 9 more. Fields without a value can be left out of a record.

    Output fields

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (exact suggestions for one seed). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 5000, maximum 50000), maxSuggestionsPerSeed (default 2000, maximum 10000) and maxQueriesPerSeed (default 300, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    YouTube Search Suggestions Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 19 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    queriesSeed queriesarray requiredKeywords or phrases to expand with YouTube autocomplete. Short 1-3 word seeds work best.Default ["web scraping"]
    modeExpansion modestringHow far to expand each seed. Exact is one request; All runs every working expansion axis.Default "exact"; Allowed all, exact, alphabet, questions, modifiers, prepositions, comparisons, related
    sourceSuggestion sourcestringYouTube search, YouTube Music, or both. YouTube Music is a separate music-biased source.Default "youtube"; Allowed youtube, youtubeMusic, both
    languageLanguagestringLanguage used to localize suggestions.Default "en"; Allowed en, es, fr, de, it, pt, nl, pl and 70 more
    marketCountry or regionstringCountry or region used to localize suggestions.Default "US"; Allowed US, GB, CA, AU, NZ, IE, DE, FR and 126 more
    maxItemsMaximum rowsintegerGlobal cap on suggestion rows across all seeds and sources.Default 5000; Example 3; Allowed 1 to 50000
    maxSuggestionsPerSeedMaximum suggestions per seedintegerCap on rows kept for each seed after the expansion plan runs.Default 2000; Example 3; Allowed 1 to 10000
    maxQueriesPerSeedMaximum queries per seedintegerCap on autocomplete requests per seed and source. Exact stays one request.Default 300; Allowed 1 to 1000
    expansionDepthRecursion depthinteger0 = selected mode only. 1-2 re-query the best suggestions for deeper long-tail coverage.Default 0; Allowed 0 to 2
    dedupeAcrossSeedsRemove duplicates across seedsbooleanKeep one row when the same suggestion appears for more than one seed. Per-seed duplicates are always removed.Default false
    minLengthMinimum lengthintegerDrop suggestions shorter than this many characters.Allowed 1 to 200
    maxLengthMaximum lengthintegerDrop suggestions longer than this many characters.Allowed 1 to 500

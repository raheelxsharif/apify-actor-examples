    YouTube Community Tab Post & Poll Scraper is an Apify Actor published by Dataspryva. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 7 declared fields, including postId, postType, channelName, contentText, publishedAt and likeCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Output per comment (postComments mode)”, “Input”, “Use cases” and “FAQ”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (recent posts from two channels). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPosts (default 100, maximum 200) and maxComments (default 100, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    YouTube Community Tab Post & Poll Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestringChoose channel posts, one post per URL/ID, or comments from post URLs/IDs.Default "channelPosts"; Allowed channelPosts, postDetails, postComments
    urlsChannel or post URLs / IDsarrayChannel URLs, @handles or channel IDs when mode=channelPosts. Post URLs or post IDs when mode=postDetails/postComments.Example ["https://www.youtube.com/@MrBeast"]
    maxPostsMaximum postsintegerMaximum posts per channel, or per run in the post modes. The run also accepts at most this many channel/post inputs. YouTube exposes at most 200 posts per channel.Default 100; Example 3; Allowed 1 to 200
    postTypesPost typesarrayIn channelPosts mode, only return these post types. Leave empty to include every type. The post modes return the post URLs/IDs you give them.Default []; Allowed text, image, video, poll, quiz, playlist, shared
    keywordKeyword filterstringIn channelPosts mode, only keep posts whose text contains this phrase. Case-insensitive. Leave empty for all posts.
    publishedAfterPublished on or afterstringIn channelPosts mode, keep posts published on or after this date. Uses YouTube's exact publish date, so details are fetched when set.
    publishedBeforePublished on or beforestringIn channelPosts mode, keep posts published on or before this date. Uses YouTube's exact publish date, so details are fetched when set.
    includeDetailsFetch per-post detailsbooleanIn channelPosts mode, fill the exact publish date, exact like count, comment count and a 3-comment preview. Adds one detail and one comment request per post. postDetails always returns details.Default true; Example false
    includeCommentsInclude commentsbooleanReturn comment threads on each post (up to Maximum comments) in channelPosts and postDetails modes. postComments always returns comments.Default false
    maxCommentsMaximum comments per postintegerMaximum top-level comments to keep per post when comments are included. Replies are counted separately.Default 100; Allowed 1 to 1000
    includeRepliesInclude comment repliesbooleanAlso fetch replies under each comment when comments are included.Default false
    maxRepliesPerCommentMaximum replies per commentintegerMaximum replies to keep per comment when replies are included.Default 10; Allowed 1 to 100
    commentSortComment orderstringShow YouTube's featured comments first, or the newest comments first, when comments are returned.Default "top"; Allowed top, newest
    marketMarketstringCountry used to render YouTube's localized labels and relative times.Default "US"; Allowed US, GB, CA, AU, DE, FR, JP, KR and 23 more
    languageInterface languagestringLanguage used for YouTube's relative times and display labels. Post text is never translated.Default "en"; Allowed en, es, pt, de, fr, it, nl, pl and 12 more

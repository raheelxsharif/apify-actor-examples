    Instagram Downloader API - Reels, Video & Photo

    Download Instagram photos, videos, Reels and carousel posts from post links or usernames, up to 100 of each per run. Public posts and profiles need no login; add your own cookies for age-restricted posts and private accounts you follow. Each file gets a download link, size, resolution and length.

    Instagram Downloader API - Reels, Video & Photo is an Apify Actor published by Dataspryva. It accepts 6 input fields, none of them required at the top level. Each result can carry up to 11 declared fields, including status, filename, post_url, username, type and download_status. It costs $0.49 per 1,000 results on Apify's Free plan and $0.30 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Authentication”, “Output per media file”, “Input”, “Using your own cookies” and “Example output”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 1 dataset view, and the README documents 23 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (back up one reel and one photo post). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPosts_per_username (default 10, maximum 100) caps how many results a run collects, and so what it costs.

    What it costs

    Instagram Downloader API - Reels, Video & Photo uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 6 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    postUrlsInstagram Post URLsarrayInstagram post, reel or IGTV URLs to download. Accepts /p/, /reel/, /reels/, /tv/, and canonical username/p/shortcode formats. Duplicates are silently de-duplicated.Example ["https://www.instagram.com/p/Dew5IIlNfMW/"]
    maxPosts_per_usernameMax Posts Per UsernameintegerMaximum number of posts to download per username (after the date and pinned-post filters below). Public profiles need no sign-in, however many posts you ask for; a private profile needs your cookies.Default 10; Example 0; Allowed 0 to 100
    newerThanOnly posts newer thanstringSkip posts published before this date. Leave empty for no date filter. Must be a date from 2000-01-01 up to the day before the run. Applies to usernames only. The date is read from the post's id, so it can be off by up to a day.
    skipPinnedPostsSkip pinned postsbooleanLeave out the posts a profile has pinned to the top of its grid. Applies to usernames only. A pinned post that is also the newest post cannot be recognised and stays in.Default false
    usernamesInstagram Usernames or Profile LinksarrayUsernames whose recent posts should be processed. Each entry can be a username (with or without @) or a profile link such as https://www.instagram.com/natgeo/.Example []
    cookiesInstagram Cookies (Optional)stringOptional. Leave empty to download public posts and the posts of public profiles without signing in. Paste your own Instagram cookies in JSON format to also download age-restricted posts and the posts of private profiles your account follows. It is a secret input, so the Apify Console hides and encrypts it. Format: [{"name":"sessionid","value":"...","domain":".instagram.com"}, ...]

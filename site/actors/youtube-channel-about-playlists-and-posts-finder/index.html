    YouTube Channel About, Playlists & Posts Finder is an Apify Actor published by Dataspryva. It accepts 10 input fields, and channelUrls is required. Each result can carry up to 20 declared fields, including recordType, channelName, title, handle, subscriberCountText and videoCountText. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Channel profile fields”, “Playlist row fields”, “Community Post row fields” and “Input”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (profile only). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    YouTube Channel About, Playlists & Posts Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstringChannel profile returns one row per channel with its About details. Playlists returns one row per public playlist, show, course, or podcast. Posts returns one row per public Community Post.Default "profiles"; Allowed profiles, playlists, posts
    channelUrlsChannel URLsarray requiredPublic YouTube channel URLs, @handles, or UC… channel IDs. One row set is produced for each channel.Example ["https://www.youtube.com/@Apify"]
    includeLinksInclude public external linksbooleanIn channel profile mode, include the external links shown on the public About page, with their titles and favicons.Default true
    includePlaylistsNest playlists in the profile rowbooleanIn channel profile mode, add a snapshot of the channel's public playlists, shows, courses, and podcasts to the same row. Use the playlists mode for one row per playlist.Default false
    maxPlaylistsMaximum playlists per channelintegerMaximum playlist, show, course, or podcast rows to collect per channel. Applies to the playlists mode and to nested profile snapshots.Default 20; Example 10; Allowed 1 to 10000
    includePostsNest Community Posts in the profile rowbooleanIn channel profile mode, add a snapshot of the channel's public Community Posts to the same row. Use the posts mode for one row per post.Default false
    maxPostsMaximum Community Posts per channelintegerMaximum Community Posts to collect per channel. Applies to the posts mode and to nested profile snapshots. YouTube exposes at most 200 posts per channel.Default 20; Example 10; Allowed 1 to 10000
    includePostDetailsFetch exact post dates and likesbooleanOpen each Community Post's public detail page to fill its exact ISO publish date and exact like count. Adds one request per post.Default true; Example false
    includePostCommentsInclude post commentsbooleanCollect public comments on each Community Post, up to the per-post limit. Adds one detail and one or more comment requests per post.Default false
    maxPostCommentsMaximum comments per postintegerMaximum public top-level comments to keep per Community Post when comments are included. Replies are not expanded.Default 20; Example 10; Allowed 1 to 1000

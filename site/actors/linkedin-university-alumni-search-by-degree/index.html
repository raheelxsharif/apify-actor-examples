    LinkedIn University Alumni Search by Degree & Year is an Apify Actor published by Dataspryva. It accepts 12 input fields, none of them required at the top level. Each result can carry up to 9 declared fields, including recordType, schoolName, name, headline, location and profileUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per school insight”, “Output per alumnus”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a school's public alumni insights). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxSchools (default 10, maximum 100) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn University Alumni Search by Degree & Year uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to return: public school-level alumni insights, or individual public alumni profiles found by search.Default "schoolInsights"; Allowed schoolInsights, alumniProfiles
    schoolUrlsSchool URLs or slugsarrayLinkedIn school page URLs or bare slugs, e.g. https://www.linkedin.com/school/mit/ or mit.Example ["https://www.linkedin.com/school/mit/"]
    schoolNamesSchool namesarrayPlain university names when you do not have the LinkedIn URL, e.g. MIT or Harvard University. Names are resolved automatically.
    maxSchoolsMax schoolsintegerMaximum number of schools to process in one run.Default 10; Example 1; Allowed 1 to 100
    maxAlumniPerSchoolMax alumni per schoolintegerMaximum verified public profiles to return per school (mode=alumniProfiles). Values above 200 are clamped to 200 to keep runs bounded.Default 50; Example 3; Allowed 1 to 1000
    degreeDegreestringNarrow discovery toward profiles whose public text mentions this degree (mode=alumniProfiles). Degree is best-effort because LinkedIn hides it on most guest profiles.Default ""; Allowed , Bachelor, Master, MBA, PhD, Associate
    fieldOfStudyField of studystringSchool insights: a public field facet name or ID (e.g. Computer Science). Alumni profiles: searches and prefers this field (best-effort).
    currentFunctionCurrent functionstringSchool insights only: a public function facet name or ID (e.g. Engineering).
    currentCompanyCurrent companystringSchool insights: a public company facet name or ID (e.g. Google). Alumni profiles: only return people whose public current employer matches.
    currentLocationCurrent locationstringAlumni profiles only: only return people whose public location contains this text.
    graduationYearRangeGraduation year rangeobjectAlumni profiles only: keep profiles whose public education end year is inside this inclusive range.
    includeSchoolProfileInclude school profile detailsbooleanSchool insights only: also fetch the school overview page for website, founding year, size, specialties and employee count. Adds one request per school.Default true; Example false

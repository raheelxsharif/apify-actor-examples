Google Maps Nearby Radius Search — Address, Place & Coordinates

Point this actor at a coordinate, an address, or a Google Maps place, give it a radius and one or more categories or keywords, and it returns the places Google shows inside that radius. Every row carries its straight-line distance from the center, so "within 800 m of this address" is an auditable number instead of a relevance guess.

It reads Google Maps' public result feed without a browser, cookies or an API key. Runs are small (1 GB), fast, and do not need proxy configuration.

Search center

Choose one center type:

Center type What to provide Example
Coordinates latitude + longitude 40.7484, -73.9857
Address address 350 5th Ave, New York, NY 10118
Place place (Maps URL or ChIJ Place ID) https://www.google.com/maps/place/?q=place_id:ChIJ...

An address or place is resolved to Google's own coordinates first, then the radius search is anchored there. A place can be a full Maps URL, a short maps.app.goo.gl-style link, or a canonical ChIJ... Place ID.

What it collects

For every place inside the radius:

  • name, categoryName, categories
  • totalScore, reviewsCount, ratingHistogram
  • address, phone, website
  • priceLevel, plusCode, description
  • hours, hoursStatus, isOpenNow
  • timezone, countryCode
  • placeId, featureId, kgmid, cid
  • location ({lat,lng}), latitude, longitude
  • distanceFromCenter (e.g. 450 m), distanceFromCenterMeters
  • photosSample, photoCount
  • placeAttributes, attributes, amenities, serviceOptions
  • fuelPrices, hotelStars, hotelStarRating, priceOfferAmount, priceOfferCurrency, priceOfferDateRange, hotelAmenities
  • bookingLinks, checkInTime, checkOutTime
  • hasStreetView, streetViewCount
  • permanentlyClosed, temporarilyClosed, claimed
  • searchTerm, rankInSearch
  • googleMapsUrl, sourceUrl, scrapedAt, recordType

Fields Google does not publish for a place are omitted, never sent as null or an empty string. includeDetails adds the preview-panel fields (plus code, price, histogram, photos, description, attributes, service options, closure status and hotel/fuel/booking extras when Google publishes them) and costs one extra request per place; listing fields and weekly hours are collected either way.

Examples

Coffee within 500 m of Times Square:

{
  "centerType": "coordinates",
  "latitude": 40.7484,
  "longitude": -73.9857,
  "searchTerms": ["coffee shop"],
  "radiusKm": 0.5,
  "maxResults": 30

Highly rated, open-now restaurants around an address:

{
  "centerType": "address",
  "address": "10 Downing St, London SW1A 2AA",
  "searchTerms": ["restaurant"],
  "radiusKm": 2,
  "minRating": 4.5,
  "openNow": true,
  "maxResults": 50
}

  "centerType": "place",
  "place": "https://www.google.com/maps/place/Eiffel+Tower/@48.8583701,2.2944813,17z",
  "searchTerms": ["pharmacy", "clinic"],
  "radiusKm": 3,
  "includeDetails": false,
  "language": "fr",
  "maxResults": 40
}

How pagination works

Google serves the nearby feed in pages of 20 ranked places. The actor follows those pages until the per-term maxResults is reached, the feed returns an empty section, or two consecutive pages contain nothing inside the radius (Google appends unrelated places from other cities at the end of a window). Deduplication is by Place ID, then feature ID, then Maps URL, then name + address.

A single term's ranked window usually holds roughly 130–180 places inside a dense radius. When that window ends, the actor stops and says so in the status message rather than padding the dataset. For more coverage, split the area into smaller radii or run several narrower category terms.

FAQ

Do I need a Google Maps API key or cookies? No. The actor reads the same public result and preview endpoints the Maps website uses, with no account, cookie or key.

Do I need a proxy? No. It starts direct, and only if Google repeatedly blocks the connection does it move to Apify's datacenter pool and then US residential as a last resort. There is no proxy field to configure.

Why are there fewer rows than maxResults? The ranked window ends, or the radius/filters removed places. The status message reports how many rows were outside the radius and how many were filtered. A tight radius or strict openNow filter can legitimately return zero rows.

Why is distanceFromCenter missing? It is never missing on a returned row: a place without observed coordinates is dropped because it cannot be proven inside the radius.

Can I search more than one category in one run? Yes. Put several entries in searchTerms; each term is searched and paginated separately, and every row records which term found it. maxResults applies per term.

Why do some detail fields appear only sometimes? Plus code, price level, rating histogram, description and attributes are conditional on Google publishing them for that place. Omitted means Google did not show it.

Does a smaller radius return more accurate results? Yes. The radius also selects the map zoom used for the search, so a 500 m request is anchored on a much tighter viewport than a 20 km request.

Is this affiliated with Google? No. It reads publicly visible Google Maps data and is not affiliated with, endorsed by or sponsored by Google.

Limitations

  • One term's ranked window is finite; the actor reports the honest source end instead of inventing rows.
  • Popular times, menus, reviews, emails and social profiles belong to separate actors in this suite.
  • Bounding-box, polygon and multi-cell grid scans belong to the area-scanner actor.
  • Google localises names, addresses and hours with language; the values are returned exactly as Google serves them.

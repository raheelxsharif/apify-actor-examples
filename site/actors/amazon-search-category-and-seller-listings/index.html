    Amazon Search, Category & Seller Listings Extractor is an Apify Actor published by Dataspryva. It accepts 20 input fields, none of them required at the top level. Each result can carry up to 8 declared fields, including title, asin, price, stars, reviewsCount and inStock. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per product”, “Input”, “Supported Amazon Marketplaces”, “Use cases” and “FAQ”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search, cards only). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 0, maximum 100000) and maxItemsPerCategory (default 10, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Search, Category & Seller Listings Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    categoryUrlsSearch, Category & Product URLsarrayAmazon search, category, seller-profile, or exact product URLs. Search pages (/s?k=), browse nodes (/b?node=), seller profiles (/sp?seller=), and product pages (/dp/) are routed automatically. Combine with any other mode.
    keywordsSearch KeywordsarrayPlain search keywords or phrases. Each keyword builds an Amazon search URL (/s?k={query}).Example ["wireless earbuds"]
    productUrlsProduct URLsarrayExact Amazon product URLs. Each URL is normalized to /dp/{ASIN} on its own marketplace and fetched directly (never as a search).
    asinsASINsarrayAmazon ASINs to fetch exactly. Each ASIN opens its own product page (/dp/{ASIN}) directly, never a keyword search.
    sellerIdsSeller IDsarrayAmazon seller/merchant IDs. Each ID builds that seller's storefront listing (/s?me={sellerId}).
    categoryNodeIdsCategory Node IDsarrayAmazon browse-node IDs. Each node builds a real category listing (/s?rh=n:{node}&fs=true), with a merchandising fallback only when Amazon renders no listing grid.
    marketplaceDomainMarketplacestringAmazon marketplace used for keyword, ASIN, seller, and node modes. URLs in categoryUrls/productUrls keep their own marketplace.Default "amazon.com"; Allowed amazon.com, amazon.co.uk, amazon.de, amazon.fr, amazon.it, amazon.es, amazon.ca, amazon.com.au and 13 more
    maxItemsMaximum Items (all sources)integerGlobal cap across every source in the run. 0 means no global cap.Default 0; Example 3; Allowed 0 to 100000
    maxItemsPerCategoryMaximum Items Per SourceintegerMaximum products to return from each keyword, URL, seller, or node source.Default 10; Example 3; Allowed 1 to 10000
    maxPagesMaximum PagesintegerMaximum listing pages per source. Amazon keyword search itself stops at page 7; category listings go deeper.Default 1; Allowed 1 to 50
    scrapeProductDetailsScrape Product DetailsbooleanIf true, visit each accepted product's own page for specs, gallery images, seller, BSR, variants, and histogram. ASIN/product-URL modes always use detail pages. If false, only listing-card fields are returned.Default true; Example false
    includeSpecificationsInclude SpecificationsbooleanIf true (and detail pages are scraped), return the specifications object parsed from the overview and technical-detail tables.Default true; Example false

    X Article Announcement Post Metadata Collector is an Apify Actor published by Dataspryva. It accepts 7 input fields, and tweetUrls is required. Each result can carry up to 6 declared fields, including type, title, author.username, articleId, bodyAvailable and sourceTweetUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per article”, “Output per status row”, “Input”, “Use cases” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 6 fields in 1 dataset view, and the README documents 28 more. Fields without a value can be left out of a record.

    What it costs

    X Article Announcement Post Metadata Collector uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

Target Price, Stock & Deals Finder

Pull live product data straight from Target.com — search results, a single department, one or more exact products by their Target item number, a pasted product URL, or the current trending-deals rail. Every record comes back with pricing, stock status, fulfillment options, and ratings so you can monitor assortments without opening a browser.

What this actor does

  • Five modes: search by keyword, byCategory to browse a department, byTcin to fetch exact items, byUrl to resolve a pasted Target link, and deals for trending/featured items
  • Pricing detail: current price, original list price, computed savings, and active promotion labels
  • Stock and fulfillment: availability status plus shipping, in-store pickup, and same-day delivery flags
  • Review signal: average rating, total rating count, and customer question count
  • Server-side filters: price range, minimum rating, on-sale-only, and in-stock-only, applied before results are counted toward maxItems
  • Empty fields are omitted from each record, so a product without a brand or without review data simply won't have those keys

Output per product

  • tcin — Target item number, the unique product identifier
  • title — product name
  • brand — brand name
  • description — product description text
  • price — current selling price (USD)
  • originalPrice — regular/list price (USD)
  • isOnSale — true when the current price is below the original price
  • saleSavings — dollar amount saved versus the original price
  • promotions[] — active promotion label text (e.g. "Buy 1, get 1 25% off")
  • rating — average customer rating (0–5)
  • ratingCount — total number of customer ratings
  • questionCount — number of customer Q&A entries
  • itemType — product category/department label
  • primaryImageUrl — main product image URL
  • additionalImages[] — extra product gallery image URLs
  • availability — IN_STOCK, LIMITED_STOCK, OUT_OF_STOCK, or UNKNOWN when Target's response carries no fulfillment data
  • fulfillment — { shipping, pickup, sameDay } booleans for how the item can be fulfilled
  • productUrl — direct link to the product's Target.com page
  • recordType — always "product"
  • siteName — always "Target"
  • scrapedAt — ISO 8601 timestamp of when the record was collected

Input

Field Type Default Description
mode string search search, byTcin, byCategory, byUrl, or deals
query string iPhone case Search keyword (mode=search)
tcins array – Target item numbers to fetch (mode=byTcin)
categoryId string electronics Department to browse (mode=byCategory)
url string – A Target product or search page URL to resolve (mode=byUrl)
minPrice number – Drop products priced below this USD amount
maxPrice number – Drop products priced above this USD amount
minRating number – Drop products with average rating below this value (0–5)
onSaleOnly boolean false Only return products currently marked on sale
inStockOnly boolean true Exclude products marked OUT_OF_STOCK (products with LIMITED_STOCK or unknown availability still pass)
maxItems integer 5 Hard cap on returned products (1–500)

Use cases

  • Price monitoring — track price, originalPrice, and saleSavings for a watchlist of TCINs over time
  • Assortment research — browse a department with byCategory to see what's listed and in stock right now
  • Deal discovery — run the deals mode on a schedule to catch newly featured promotions
  • Review benchmarking — compare rating and ratingCount across competing products in the same category
  • Fulfillment auditing — check which items offer same-day delivery or in-store pickup in a given run
  • Catalog enrichment — resolve a list of saved Target URLs into structured product records with byUrl

FAQ

Where does this data come from? Target's own product data as shown on Target.com — the same titles, prices, and availability shoppers see on the live site.

What is a TCIN? TCIN stands for Target Corporation Item Number — Target's internal product identifier, visible in product URLs after /A-.

Do I need a Target account to use this? No. All modes read publicly listed product data; no login is required.

What's the difference between the five modes? search and byCategory both return lists of products — one from a keyword query, the other from a fixed department. byTcin and byUrl both return exact single products, just addressed differently (item number vs. a pasted link). deals returns whatever Target is currently featuring, independent of any query.

Why is a field like brand or rating sometimes missing? Target doesn't populate every field for every listing — some products have no brand attribution, and newly listed items may not yet have reviews. Missing fields are omitted rather than returned empty.

Can I combine the price, rating, and stock filters? Yes. minPrice, maxPrice, minRating, onSaleOnly, and inStockOnly all apply together, and only products passing every filter count toward maxItems.

How many products can one run return? Up to 500, set by maxItems. For broader coverage, run the actor again with a different query or categoryId.

Is this affiliated with Target? No. This is an independent, third-party actor and is not operated by or affiliated with Target Corporation.

    Look up any number of Brazilian CNPJ numbers and get official Receita Federal data: company name, legal status, CNAE industry codes, address, founding date, capital, tax regime, and the partner (QSA) list for each one.

    Brazilian CNPJ Bulk Lookup & Partner Records Scraper is an Apify Actor published by Dataspryva. It accepts 12 input fields, none of them required at the top level. Each result can carry up to 11 declared fields, including cnpj, razaoSocial, nomeFantasia, situacaoCadastral, cnaeDescricao and municipio. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per company”, “Input”, “Use cases”, “FAQ” and “Use it as an API (server mode)”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (bulk lookup with partners). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 1000, maximum 100000) caps how many results a run collects, and so what it costs.

    What it costs

    Brazilian CNPJ Bulk Lookup & Partner Records Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringLook up a list of CNPJs, or discover companies that match filters.Default "lookup"; Allowed lookup, discovery
    cnpjsCNPJ numbersarrayCNPJ numbers to look up (mode=lookup). Numeric or alphanumeric, formatted or plain. Example: ["18.236.120/0001-58", "00000000E08G12"].Example ["18236120000158"]
    cnpjTextCNPJ list or CSV textstringPaste a CSV or any text containing CNPJs (mode=lookup). Every valid CNPJ is extracted, validated and deduplicated. A spreadsheet column with or without a header works.
    cnaesCNAE codesarrayOne or more 7-digit CNAE codes (mode=discovery). Matches primary or secondary activity. Example: ["6209100", "6201501"].
    ufStatestringBrazilian state to narrow discovery (mode=discovery).Default "ALL"; Allowed ALL, AC, AL, AP, AM, BA, CE, DF and 20 more
    municipioMunicipality codestringIBGE or SIAFI municipality code, digits only (mode=discovery). Example: 3550308 (São Paulo), 5300108 (Brasília). This is a code, not a city name.
    naturezaJuridicaLegal nature codestring4-digit legal-nature code (mode=discovery). Example: 2135 (Empresário Individual), 2062 (Sociedade Empresária Limitada).
    partnerCpfPartner CPF/CNPJstringMasked partner document from the QSA (mode=discovery), in the Receita format such as *123456. Add a state or CNAE to narrow the search; the same mask can match different people.
    situacaoRegistration statusstringKeep only companies with this registration status (mode=discovery).Default "ATIVA"; Allowed all, ATIVA, SUSPENSA, INAPTA, BAIXADA, NULA
    includePartnersInclude partners (QSA)booleanInclude the full partner/shareholder list.Default true
    includeSecondaryActivitiesInclude secondary CNAEsbooleanInclude the list of secondary CNAE activities.Default true
    maxItemsMaximum recordsintegerMaximum CNPJs to process in lookup, or maximum records to emit in discovery.Default 1000; Example 1; Allowed 1 to 100000

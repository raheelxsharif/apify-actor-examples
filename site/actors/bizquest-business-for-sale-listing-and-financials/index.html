    BizQuest Business-for-Sale Listing & Financials Extractor is an Apify Actor published by Dataspryva. It accepts 6 input fields, none of them required at the top level. Each result can carry up to 12 declared fields, including listingId, title, priceLabel, askingPrice, cashFlow and grossRevenue. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Use cases” and “FAQ”.

    What it costs

    BizQuest Business-for-Sale Listing & Financials Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema

NOTE: BizQuest's own search often ignores the ?q= parameter on the default browse URL — results may be the same regardless.

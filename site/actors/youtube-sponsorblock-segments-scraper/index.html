    YouTube SponsorBlock Segments Scraper is an Apify Actor published by Dataspryva. It accepts 12 input fields, and videoUrls is required. Each result can carry up to 41 declared fields, including recordType, videoId, category, actionType, startTime and endTime. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    YouTube SponsorBlock Segments Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    videoUrlsVideo URLs or IDsarray requiredYouTube video URLs or 11-character video IDs. Accepts watch, youtu.be, Shorts, live, embed, and music links. Add multiple videos for a batch.Example ["https://www.youtube.com/watch?v=7wtfhZwyrcc"]
    categoriesSegment categoriesarrayOnly return these SponsorBlock categories. Leave empty to include every category.Default []; Example ["sponsor", "intro"]; Allowed sponsor, selfpromo, interaction, intro, outro, preview, hook, music_offtopic and 4 more
    actionTypesAction typesarrayOnly return segments whose action matches one of these. Leave empty to include every action.Default []; Allowed skip, mute, full, poi, chapter
    sourceSegment sourcestringUse 'Visible segments' for the segments SponsorBlock currently acts on. Use 'All submissions' to include hidden and disputed submissions from the search database.Default "visible"; Allowed visible, all
    minVotesMinimum votesintegerDrop segments with fewer community votes than this. Use -2 to include every submission, 0 to drop downvoted ones, or a higher value to keep only well-confirmed segments.Default 0; Allowed -2 to 1000000
    includeHiddenSegmentsInclude hidden submissionsbooleanWhen the source is 'All submissions', also return segments hidden by moderation or a shadowbanned submitter.Default false
    includeDescriptionsInclude segment descriptionsbooleanInclude the community-written note attached to a segment when one exists.Default true
    includeSubmitterInfoInclude public submitter infobooleanResolve each segment's public SponsorBlock submitter ID to a username and aggregate stats when available. Never exposes private IDs.Default true
    includeYouTubeMetadataInclude YouTube metadatabooleanAdd the video title, channel name/URL/ID, thumbnail, YouTube duration, view count, publish date, and live status from YouTube's public oEmbed and player endpoints.Default true
    includeSummaryInclude summary rowsbooleanAdd one per-video summary row (segment count, total seconds, category/action breakdown) and one run summary row.Default false
    maxSegmentsPerVideoMaximum segments per videointegerKeep at most this many segments per video after filtering and sorting by start time. Use 0 for no limit.Default 0; Allowed 0 to 1000000
    concurrencySimultaneous videosintegerHow many videos to process at the same time. Higher is faster but can trigger rate limits.Default 4; Allowed 1 to 10

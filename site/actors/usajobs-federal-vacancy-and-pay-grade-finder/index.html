    USAJOBS Federal Vacancy & Pay Grade Finder is an Apify Actor published by Dataspryva. It accepts 20 input fields, and mode is required. Each result can carry up to 10 declared fields, including positionTitle, organizationName, payScale, payGradeMin, payGradeMax and locationName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Input”, “Output per posting”, “How it works” and “Limitations”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 10 fields in 1 dataset view, and the README documents 5 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (software engineer roles, gs 9-12, open to the public). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    USAJOBS Federal Vacancy & Pay Grade Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

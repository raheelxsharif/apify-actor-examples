    USAJOBS Federal Vacancy & Pay Grade Finder is an Apify Actor published by Dataspryva. It accepts 20 input fields, and mode is required. Each result can carry up to 10 declared fields, including positionTitle, organizationName, payScale, payGradeMin, payGradeMax and locationName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    USAJOBS is the US government's official federal job board. This actor reads its live public search and announcement pages directly, so it returns federal vacancies, pay scales and grades, salary ranges, hiring paths, clearance requirements and full announcement text with no API key, login or cookie.

    What this actor does

    • Searches current federal postings by keyword, location, agency or parent department, occupational series, GS-equivalent grade range, work schedule, hiring path, clearance, appointment type, travel, work site (remote / telework / exclude remote), relocation assistance and minimum salary.
    • Pages through the full result set (up to USAJOBS's own 10,000-result ceiling), removes duplicate postings and stops at maxItems.
    • Optionally opens each posting's announcement page to add duties, qualifications, education, evaluation criteria, exact salary range, promotion potential and remote/telework status.
    • Reads individual announcement links in Job Details mode, so you can enrich a list of job URLs you already collected.
    • Keeps the older input keys (organization, positionSchedule, whoMayApply, gradeMin, gradeMax, apiKey, datePostedDays) working in code, so saved tasks keep running.

    How it works

    The actor calls the same public search endpoint the USAJOBS website uses, then reads announcement pages for full details. No API key is needed. Requests are retried on rate limits and transient server errors, and if a datacenter address is blocked the actor automatically retries through Apify's included datacenter proxy.

    Questions

    Do I need a USAJOBS API key?

    No. This actor uses the public website search and announcement pages, so it needs no API key, account, cookie or proxy setup. The old apiKey key is accepted but ignored.

    Can I search by GS pay grade?

    Yes. Set gradeMin and/or gradeMax (1-15). Results include every GS-equivalent grade in the range, and each record reports payScale, payGradeMin and payGradeMax.

    What does "Who May Apply" mean?

    It is the audience the posting is open to: public means any US citizen, competitive service means current or former federal employees, and other hiring paths cover veterans, military spouses, students, graduates, disability, overseas family members and special authorities.

    Why is a field such as salaryMax missing?

    Some announcements publish only a starting salary. The actor omits the missing bound rather than guessing.

    Is this affiliated with USAJOBS or the US government?

    No. This is an independent tool and is not affiliated with, endorsed by or sponsored by USAJOBS or the US Office of Personnel Management.

    Limits and notes

    Limitations

    • USAJOBS caps a single search at 10,000 postings. Narrow by agency, location, grade, series or keyword to reach postings beyond that ceiling.
    • Date-posted filtering is not available on the public search. The legacy datePostedDays key is accepted but ignored; use sortBy: recentlyPosted and maxItems instead.
    • Full announcement text is as published. Very long duties or qualification sections are returned whole, which makes detail-enabled runs heavier than search-only runs.
    • Grade filtering follows USAJOBS's GS-equivalent buckets. Some pay plans (for example SV or NF) use letter grades and may not match a numeric GS range.
    • A removed or closed announcement can still appear briefly in search. If its detail page is already gone, the core search fields are still returned and the run reports how many detail pages could not be opened.

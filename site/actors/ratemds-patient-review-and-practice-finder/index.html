    RateMDs Patient Review & Practice Finder is an Apify Actor published by Dataspryva. It accepts 22 input fields, none of them required at the top level. Each result can carry up to 10 declared fields, including recordType, name, practiceName, specialty, city and state. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Output per doctor”, “Output per practice”, “Input”, “Pagination and limits” and “How it works”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 10 fields in 1 dataset view, and the README documents 9 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    RateMDs Patient Review & Practice Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 22 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to fetch from RateMDs.Default "search"; Allowed search, bySpecialty, doctorProfile, byUrl, practiceSearch, practiceProfile
    searchQuerySearch querystringDoctor name, specialty keyword or medical condition (mode=search). Example: 'cardiologist' or 'Dr. Jane Doe'.Default "cardiologist"
    locationLocationstringLegacy free-text location, e.g. 'New York' or 'Toronto, ON'. Used with search and bySpecialty. Structured City/State below take precedence.Default ""
    specialtySpecialtystringMedical specialty to browse (mode=bySpecialty) or to narrow a keyword search.Default ""; Allowed , acupuncturist, addiction-medicine, allergist-immunologist, anesthesiologist, audiologist, bariatric-weight-loss, cardiologist and 58 more
    stateState / provincestringTwo-letter state/province code (e.g. 'ny', 'ca', 'on') used with search, bySpecialty and practiceSearch.Default ""
    cityCitystringCity name or slug (e.g. 'New York' or 'new-york') used with search, bySpecialty and practiceSearch.Default ""
    countryCountrystringCountry filter for doctor or practice searches.Default ""; Allowed , us, ca, au, in, za, uk
    genderDoctor genderstringFilter doctors by gender when RateMDs publishes it.Default "any"; Allowed any, F, M
    verifiedVerified profiles onlybooleanOnly return doctors marked as verified by RateMDs.Default false
    acceptingNewPatientsAccepting new patientsbooleanOnly return doctors currently accepting new patients.Default false
    acceptingVirtualVisitsAccepting virtual visitsbooleanOnly return doctors offering virtual/telehealth appointments.Default false

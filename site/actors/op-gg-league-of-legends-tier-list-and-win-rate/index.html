    OP.GG League of Legends Tier List & Win Rate Tracker is an Apify Actor published by Dataspryva. It accepts 10 input fields, and mode is required. Each result can carry up to 22 declared fields, including championName, position, tier, tierNumber, tierRank and rankChange. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per champion tier row (mode = tierList)”, “Output per champion stat row (mode = championStats)”, “Output per counter row (mode = fullCounters)”, “Input” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 22 fields in 3 dataset views, and the README documents 14 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (default ranked tier list). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    OP.GG League of Legends Tier List & Win Rate Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: a champion tier list, champion statistics, or every matchup for selected champions. byPosition is a legacy alias for a position-scoped tier list.Default "tierList"; Allowed tierList, championStats, fullCounters, byPosition
    queueTypeQueuestringQueue to read. Classic applies to tierList and fullCounters; ARAM applies to championStats.Default "ranked"; Allowed ranked, flex, classic, aram
    regionRegionstringServer to read. Global combines every server OP.GG tracks.Default "global"; Allowed global, na, me, euw, eune, oce, kr, jp and 8 more
    rankTierPlayer rankstringOnly include games from this rank. Champion stats mode uses the base tier for plus tiers (e.g. Emerald+ → Emerald).Default "emerald_plus"; Allowed all, challenger, grandmaster, master_plus, master, diamond_plus, diamond, emerald_plus and 8 more
    positionPositionstringLane to read. ALL returns every lane; in fullCounters it uses each champion's primary lane.Default "ALL"; Allowed ALL, TOP, JUNGLE, MID, ADC, SUPPORT
    championsChampionsarrayChampion names, keys, or OP.GG build URLs to fetch every matchup for (mode=fullCounters). Example: Ahri, jinx, https://op.gg/lol/champions/ahri/build/mid.Example []
    patchPatchstringTier-list and fullCounter patch. OP.GG keeps the latest and previous patch; Classic has no patch history.Default "latest"; Allowed latest, previous
    minTierMinimum champion tierstringTier-list cutoff. OP is the strongest, then 1 through 5. Lower numbers keep stronger champions.Default "all"; Allowed all, 0, 1, 2, 3, 4, 5
    periodStats periodstringTime window for champion statistics (mode=championStats).Default "month"; Allowed month, week, day
    maxItemsMax itemsintegerHard cap on emitted records. OP.GG returns at most 271 tier rows or 173 stat rows per filter.Default 100; Example 20; Allowed 1 to 1000

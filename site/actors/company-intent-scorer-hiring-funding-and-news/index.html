    Company Intent Scorer: Hiring, Funding & News Signals is an Apify Actor published by Dataspryva. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 17 declared fields, including companyName, domain, grade, score, priorityFlag and topSignal. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per company”, “Input”, “Use cases” and “FAQ”.

    What you get

    What it costs

    Company Intent Scorer: Hiring, Funding & News Signals uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringScore every company, or compare this run with the previous run for the same monitor key.Default "score"; Allowed score, monitor
    companiesTextCompanies (one per line)stringPaste company names, one per line. Domains and careers URLs are accepted in the advanced list below.Example "Figma\nNotion\nLinear"
    companiesCompanies (advanced)arrayAdvanced list. Each item can include companyName (or name), domain, careersUrl, ats, atsToken and disambiguator. Plain strings are also accepted. If provided, this overrides the text list.
    signalsSignalsarrayBuying signals to check. Disabling a scored signal normalizes the remaining weights to 100.Default ["hiring", "funding", "news", "execChanges", "layoffs", "...; Allowed hiring, funding, news, execChanges, layoffs, techStack
    lookbackDaysLookback daysintegerFunding, news and executive-change window. News trend counts also cover 7, 30 and 90 days.Default 90; Allowed 7 to 365
    minScoreMinimum scoreintegerDrop scored companies below this intent score. Error records are always kept.Default 0; Allowed 0 to 100
    targetTechnologyTarget technologystringOptional technology to check on the company homepage, e.g. HubSpot or Marketo. The gap result does not change the intent score.
    includeRawSignalsInclude raw evidencebooleanIn full output, add sample job titles and the top news headlines for auditing.Default false
    outputFormatOutput formatstringcompact returns ranking fields plus top signals. full adds the score breakdown and per-signal detail.Default "compact"; Allowed compact, full
    maxCompaniesMax companiesintegerHard cap on companies processed per run.Default 100; Example 3; Allowed 1 to 1000
    maxConcurrencyMax concurrencyintegerHow many companies to process in parallel. Lower values are gentler on public sources.Default 3; Allowed 1 to 10
    monitorKeyMonitor keystring(mode=monitor) Name of the tracking history. Use the same key each run to compare against the previous snapshot.
    emitUnchangedEmit unchanged companiesboolean(mode=monitor) Include companies with no new or resolved signals and no score change.Default false

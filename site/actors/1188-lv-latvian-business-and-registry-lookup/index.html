    1188.lv Latvian Business & Registry Lookup is an Apify Actor published by Dataspryva. It accepts 11 input fields, and mode is required. Each result can carry up to 12 declared fields, including name, category, city, street, phone and rating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per business”, “Input”, “Use cases”, “Limitations” and “FAQ”.

    What it costs

    1188.lv Latvian Business & Registry Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 11 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: keyword search across all categories, browse a single category, fetch business profiles from direct 1188.lv URLs, or look up companies by their Latvian registration number.Default "search"; Allowed search, byCategory, byUrls, byRegistrationNumber
    searchQueriesSearch keywordsarrayOne or more keywords to search for, e.g. a business name, product, or service ('restorāns', 'zobārsts', 'auto serviss'). Used when mode=search. Matches business names, descriptions and categories across the whole catalog. Results are deduplicated across all keywords.Default ["restorāns"]
    categoryCategorystringBusiness category to browse (mode=byCategory). Pick from the full 1188.lv category list, or choose 'Custom category' and type your own 'slug-id' below.Default "restorans-2686"; Allowed custom, advokati-10, aizkari-audumi-510, akmens-apstrade-70, alkoholiskie-dzerieni-alus-razosana-100, alkohols-alus-tirdznieciba-110, amatnieciba-amatnieki-1360, antenas-150 and 377 more
    customCategoryCustom category (overrides selection above)stringFree-text category in 'slug-id' form, e.g. 'restorans-2686' (mode=byCategory). Find the slug-id by browsing https://www.1188.lv/katalogs and copying the URL segment after /katalogs/. Takes priority over 'Category' when set.
    locationsCities / townsarrayOnly return businesses in these Latvian cities or towns, e.g. 'Rīga', 'Jūrmala', 'Liepāja', 'Daugavpils' (applies to any mode). Each name is resolved to 1188.lv's own location filter; unmatched names fall back to matching the parsed address. Leave empty for all of Latvia.Default []
    registrationNumbersRegistration numbers (mode=byRegistrationNumber)arrayLatvian company registration numbers to look up, e.g. '40003710810'. Returns only businesses whose published registry number matches exactly. One company can have several directory listings.Default []
    businessUrlsBusiness URLs (mode=byUrls)array1188.lv URLs to fetch: business pages (e.g. https://www.1188.lv/katalogs/restorans-2686/some-business-123456 from the 'sourceUrl' output field), plus pasted search or category URLs, which are crawled with pagination. Profiles and listing pages can be mixed in one run.Default []
    minRatingMinimum ratingintegerOnly return businesses rated at least this many stars (1-5). 0 means no minimum. Businesses with no rating are excluded once this is set above 0.Default 0; Allowed 0 to 5
    requireWebsiteRequire websitebooleanOnly return businesses that have a website listed on their 1188.lv profile.Default false
    requireEmailRequire emailbooleanOnly return businesses that have at least one email address listed on their 1188.lv profile.Default false
    maxItemsMax itemsintegerHard cap on the number of business records to return.Default 20; Example 3; Allowed 1 to 1000

    Naver Place Visitor & Blog Review Finder is an Apify Actor published by Dataspryva. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 75 declared fields, including reviewType, placeName, searchKeyword, reviewRating, reviewText and blogTitle. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (reviews for specific places). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPlacesPerKeyword (default 3, maximum 100) and maxItems (default 100, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    Naver Place Visitor & Blog Review Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    placeUrlsPlace URLs or IDsarrayNaver Place URLs, naver.me short links, or bare numeric Place IDs. Examples: 'https://map.naver.com/p/entry/place/38239053', 'https://pcmap.place.naver.com/place/38239053/home', '38239053'.Example ["https://map.naver.com/p/entry/place/38239053"]
    searchKeywordsSearch keywordsarrayKeywords to discover places first, then scrape their reviews. Example: ['강남 맛집', '홍대 카페']. Can be combined with placeUrls.
    maxPlacesPerKeywordMax places per keywordintegerMaximum places to scrape per keyword search. Naver's search page returns up to 100 places per keyword.Default 3; Allowed 1 to 100
    maxReviewsMax visitor reviews per placeintegerMaximum visitor reviews to collect per place, across both the text-review stream and the rating-only stream. Naver paginates 50 reviews per request.Default 100; Example 3; Allowed 1 to 5000
    includeVisitorReviewsInclude visitor reviewsbooleanCollect visitor reviews. Turn off for a blog-only or stats-only run.Default true
    includeRatingOnlyReviewsInclude rating-only reviewsbooleanAlso collect reviews that have a star rating but no written text. These come from a separate Naver review stream and count toward maxReviews.Default true; Example false
    includeBlogReviewsInclude blog reviewsbooleanCollect Naver Blog and cafe posts linked to the place, with exact publish dates.Default true; Example false
    maxBlogReviewsMax blog reviews per placeintegerMaximum linked blog/cafe posts per place. Naver exposes at most 100 per place.Default 100; Example 10; Allowed 1 to 100
    includeReviewPhotosInclude review photosbooleanInclude photo and video-thumbnail URLs attached to each visitor review.Default false
    includeReviewStatsInclude review statisticsbooleanEmit one stats record per place: average rating, rating distribution, themes, top menus, voted keywords, and review counts.Default true; Example false
    visitedSinceVisited since (YYYY-MM-DD)stringOnly keep visitor reviews whose visit date is on or after this date. Reviews without a visit date are skipped when this filter is set.
    excludeReviewIdsExclude review IDs or blog URLsarrayVisitor review IDs and blog post URLs to skip. Useful for incremental runs that only want new reviews.
    maxConcurrencyMax concurrent placesintegerHow many places to scrape in parallel. Higher is faster but increases rate-limit risk.Default 3; Allowed 1 to 10
    maxItemsMax itemsintegerHard cap on total records emitted across all places.Default 100; Example 3; Allowed 1 to 5000
    proxyConfigurationProxy configurationobjectOptional. Leave empty to use direct requests; the actor escalates to an Apify datacenter proxy only after a real block.

LinkedIn Community Event Scraper — Webinars & Past Events

Scrape the public LinkedIn Sales Community and LinkedIn Talent Community event calendars without cookies, login, or proxy setup. Search by keyword, browse every upcoming or past event, or paste event URLs to get exact schedules, timezones, descriptions, cover images, registration links, categories, and languages as clean structured rows.

The actor is fully cookieless: no cookies, no login, and no proxy configuration are required. It uses the two public LinkedIn community event sites, which publish their event pages openly. Main www.linkedin.com/events/<id> pages are login-walled, so those URLs return their real id and slug, plus optional archived guest-page details when a Wayback Machine snapshot exists.

What this actor does

  • Three modes: search by keyword, browse the full inventory, byUrls for specific event pages
  • Exact schedules: ISO 8601 start/end timestamps in UTC plus the event's IANA timezone
  • Rich event content: description text, cover image, external registration URL and label, category, language
  • Both communities: Sales (scommunity) and Talent (tcommunity), upcoming and past
  • Honest output: empty fields are omitted, never filled with placeholders

Output per event

  • eventName — event title
  • eventUrl — canonical public event page
  • eventId, eventSlug — event identifier and URL slug
  • community — LinkedIn Sales Community or LinkedIn Talent Community
  • organizerName, organizerUrl — the publishing community
  • startDate, endDate — exact start/end, ISO 8601 UTC
  • startTime, endTime — legacy mirrors of the same values
  • timezone — IANA zone, e.g. Europe/Dublin
  • format — ONLINE, IN_PERSON, or HYBRID
  • eventType — VIRTUAL, IN_PERSON, or HYBRID
  • eventCategory — the source label, e.g. ENGLISH, RECRUITER, SEARCH & STAFFING
  • language — ISO code when the source label is a language (en, es, fr, de, pt, it, nl, zh, ja)
  • description — full event description text (omitted when includeDescriptions is false)
  • coverImageUrl — event cover image (live community events)
  • registrationUrl, registrationUrlLabel — external registration page and the source's button label
  • attendeesCount, attendeeCount — only when the source reports a non-zero count
  • address — structured venue, only for archived in-person main events that expose one
  • locationText — free-text venue from an archived guest page
  • scheduleText — date text from an archived guest page
  • archiveSnapshotUrl — Wayback snapshot used for a main event URL
  • sourceType — community, archive, or linkedin
  • scrapedAt — UTC scrape timestamp

FAQ

Do I need a LinkedIn account or cookie? No. The actor reads the public Sales and Talent community event pages, which are served without login. There is no cookie, token, or proxy input.

Which LinkedIn events are covered? The two public community calendars: scommunity.linkedin.com/events (Sales) and tcommunity.linkedin.com/events (Talent). Both upcoming and past tabs are supported, and every event detail page is parsed.

Why can't I get details for a normal www.linkedin.com/events link? Live main LinkedIn event pages redirect to the login wall, so they are not publicly readable. The actor returns the event id and slug from the URL, and can optionally add name, host, date text, description, and venue from a public Wayback Machine guest snapshot. Archived cover images are omitted because their signed LinkedIn CDN URLs expire and Wayback replays them with 403/429.

Why are attendee counts and speaker lists missing? Attendee identities and counts require a logged-in member, and the public event pages do not expose a structured speaker field. The actor does not fabricate them; it emits only fields the public source actually provides.

Why are all community events marked virtual? The Sales and Talent communities currently publish virtual events only. If an in-person event appears later, the format is taken from the source rather than assumed.

What is the difference between eventCategory and language? The source uses one label for both topic and language. eventCategory keeps the raw label (e.g. RECRUITER), while language is filled only when that label is a known language (e.g. DEUTSCH becomes de).

Why does a language filter return fewer events? Some community events are labelled with a topic such as RECRUITER instead of a language. When you set a language filter, those unlabelled events are omitted rather than guessed.

Does search look inside descriptions? No. The public listing pages have no server-side search, so keyword matching runs over event titles. Browse the full inventory if you need every event in a category.

How fresh is the data? Every run reads the live community calendars and event pages, so schedules, descriptions, images, and registration links reflect the source at scrape time.

Is this affiliated with LinkedIn? No. This is an independent, third-party actor. It uses publicly accessible event pages and is not affiliated with or endorsed by LinkedIn Corporation.

    What it costs

    Bayt.com MENA Job Listing & Salary Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 20 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to scrape. Search jobs builds one Bayt search per query. Paste URLs accepts job, search or company links. Job IDs resolves specific postings. Company pulls a profile and its open roles.Default "search"; Allowed search, byUrls, byJobIds, company
    searchQueriesSearch keywordsarrayOne keyword per entry, for example accountant or software engineer. Several entries are searched in order and duplicates are removed.Default ["accountant"]
    countryMarketstringBayt market to search. Pick International for every country, or choose one of the 24 supported markets.Default "international"; Example "uae"; Allowed international, uae, saudi-arabia, qatar, kuwait, bahrain, oman, egypt and 16 more
    cityCitystringOptional city name such as Dubai, Riyadh or Cairo. If Bayt has no page for the city, the search falls back to the whole country.
    employmentTypeEmployment typestringFilter by the employment type Bayt publishes for the job.Default "any"; Allowed any, full_time, part_time, contractor, temporary, internship, freelance
    careerLevelCareer levelstringFilter by seniority. Bayt publishes this for some jobs, mostly employer postings.Default "any"; Allowed any, student, fresh_graduate, entry, mid_career, management, director, senior_executive
    datePostedDate postedstringOnly return jobs Bayt marks as posted within this window.Default "any"; Allowed any, last_24_hours, last_week, last_month
    sortBySort bystringNewest first is best for monitoring. Most relevant is best for broad keyword research.Default "date"; Allowed date, relevance
    industryIndustrystringFilter by one of Bayt's employer industries.Default "any"; Allowed any, accounting, pharmaceutical-manufacturing, construction-building, recruitment-employment-agency, general-engineering-consultancy, hospitality-accommodation, hr-outsourcing and 15 more
    companyNameCompany namestringOptional employer name filter, for example Al Futtaim or Infosys. Bayt matches the employer facet, so partial names may work differently from exact names.
    remoteOnlyRemote or hybrid onlybooleanUse Bayt's server-side remote-working filter.Default false
    easyApplyOnlyEasy Apply onlybooleanOnly return jobs that accept an application directly on Bayt.Default false

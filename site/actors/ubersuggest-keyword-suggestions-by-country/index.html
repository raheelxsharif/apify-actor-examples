    Ubersuggest Keyword Suggestions by Country & Language is an Apify Actor published by Dataspryva. It accepts 10 input fields, none of them required at the top level. Each result can carry up to 13 declared fields, including type, keyword, country, language, suggestions and seedOverview. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Ubersuggest Keyword Suggestions by Country & Language uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    keywordsSeed keywordsarrayKeywords to expand. Each seed returns its own suggestions. Add several to research a topic.Example ["coffee"]
    urlsDomains as seeds (legacy)arrayOptional domains or URLs converted into rough keyword seeds (make.com becomes make). This is not a domain keyword report; use the keywords field for real research.Example []
    countryCountrystringMarket for the suggestions. worldwide returns the global list. Russia and Belarus are not available from the source.Default "us"
    languageLanguagestringLanguage of the suggestions. Leave English with auto-match on to use the market's main language automatically.Default "en"; Allowed en, af, ak, sq, ach, am, ar, hy and 114 more
    autoMatchLanguageToCountryAuto-match language to countrybooleanWhen language is English and the chosen market has another main language, switch to it automatically (Germany to German, Japan to Japanese). Turn off to keep English.Default true
    sortBySort suggestions bystringOrder of the suggestion list.Default "-searchVolume"; Allowed -searchVolume, +searchVolume, -cpc, +cpc, -sd, +sd, -pd, +pd and 2 more
    maxSuggestionsPerSeedMax suggestions per seedintegerMaximum suggestions returned for each seed. The default keeps runs fast; raise it for deep keyword lists.Default 100; Example 1; Allowed 1 to 1000
    maxItemsMax suggestions in totalintegerMaximum suggestions across all seeds in one run.Default 1000; Example 1; Allowed 1 to 10000
    includeSeedOverviewInclude seed metricsbooleanFetch each seed's own metrics: search volume, CPC, competition, difficulty, intent, 4-month trend, global volume and device shares. Adds one request per seed.Default true; Example false
    outputFormatOutput formatstringOne record per seed with nested suggestions (legacy), or one flat record per suggestion.Default "perSeed"; Allowed perSeed, perSuggestion

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search across both communities). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxEvents (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    LinkedIn Event Finder with Speaker & Venue Details uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch.Default "search"; Example "browse"; Allowed search, browse, byUrls
    searchQuerySearch querystringKeyword filter over event titles (mode=search). Leave empty to return every event. Matching is case- and accent-insensitive.Default ""
    eventUrlsEvent URLsarrayCommunity event URLs (scommunity.linkedin.com/events/... or tcommunity.linkedin.com/events/...) or main www.linkedin.com/events/<id> URLs (mode=byUrls).
    communitiesCommunitiesstringWhich public LinkedIn community sites to scan (mode=search/browse).Default "both"; Allowed both, sales, talent
    eventTimingEvent timingstringWhich listing tab to scan (mode=search/browse).Default "upcoming"; Example "all"; Allowed upcoming, past, all
    eventFormatEvent formatstringFilter by format (mode=search/browse). Public community events are virtual; other values legitimately return 0.Default ""; Allowed , VIRTUAL, IN_PERSON, HYBRID
    languageEvent languagestringKeep events whose source label is this language (mode=search/browse). Events labelled with a topic instead of a language are omitted when this filter is set.Default ""; Allowed , en, es, fr, de, pt, it, nl and 2 more
    maxEventsMax eventsintegerHard cap on emitted records. A direct event URL always returns its one event.Default 50; Example 1; Allowed 1 to 1000
    includeDescriptionsInclude descriptionsbooleanAdd the full event description text. Schedules, timezones, images, registration links and categories are always fetched.Default true; Example false
    includeArchivedDetailsInclude archived details for main event URLsbooleanFor main www.linkedin.com/events URLs only (mode=byUrls): look for a public Wayback Machine guest snapshot with name, host, date text, description and venue (when archived).

    Best Buy Price Drop & Stock Tracker is an Apify Actor published by Dataspryva. It accepts 12 input fields, none of them required at the top level. Each result can carry up to 17 declared fields, including sku, name, brand, currentPrice, regularPrice and savings. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Four ways to build a product list”, “What you can do with it”, “Input”, “Output fields”, “How it works” and “Limitations and honest notes”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 17 fields in 1 dataset view, and the README documents 15 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (exact-product watchlist). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResults (default 24, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Best Buy Price Drop & Stock Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    searchQueriesSearch keywordsarrayOne or more Best Buy searches, for example sony headphones or oled tv. Each query is paginated until maxResults is reached.Example ["sony headphones"]
    categoryUrlsCategory or search URLsarrayBest Buy category, browse or search-result links, e.g. https://www.bestbuy.com/site/headphones/.../pcmcat....c?id=.... Pagination, sorting and condition filters are applied automatically.Default []
    productUrlsProduct URLsarrayExact Best Buy product links in either the new /product/.../sku/... or legacy /site/.../<sku>.p?skuId=... format.Default []
    skuIdsSKUsarrayBest Buy SKU numbers (6–9 digits). Product links are also accepted here.Default []
    maxResultsMax resultsintegerHard cap on the total number of product records emitted across every mode.Default 24; Example 3; Allowed 1 to 1000
    maxPagesMax pages per query or categoryintegerPagination guard for each keyword or category link. Each page carries up to about 24 products.Default 50; Allowed 1 to 100
    sortBySort resultsstringBest Buy's own sort order. Price, rating and discount orders are also enforced on the collected records.Default "Best-Match"; Allowed Best-Match, Best-Selling, Best-Discount, Price-Low-To-High, Price-High-To-Low, Customer-Rating, New-Arrivals
    conditionConditionstringKeep only new, open-box or refurbished products. All conditions disables this filter.Default "all"; Allowed all, new, open-box, refurbished
    minPriceMinimum price ($)integerDrop products below this current price. 0 means no minimum.Default 0; Allowed 0 to 1000000
    maxPriceMaximum price ($)integerDrop products above this current price. 0 means no maximum.Default 0; Allowed 0 to 1000000
    inStockOnlyIn stock onlybooleanDrop products that Best Buy marks sold out, out of stock or unavailable.Default false
    includeDetailsInclude product-page detailsbooleanOpen each product page for description, model number, GTIN/UPC and seller. Slower; unavailable fields are omitted honestly.Default false

Actors/Zillow Research Home Value & Market Heat Scraper

Zillow Research Home Value & Market Heat Scraper

Get US state-level home value trends, active-listing inventory, and metro-level market heat index data from Zillow's published research files. Filter by state and cap the number of records returned.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
modestringrequiredWhat to return: latest values, full history, a multi-metric region snapshot, or the dataset catalog. The legacy options keep old saved tasks working with the previous wide output.
datasetstringoptionalZillow Research file to read. Covers home values, rents, inventory, days on market, price cuts, sales, market heat, forecasts, new construction and affordability at the geography levels Zillow publishes.
customDatasetUrlstringoptionalOptional Zillow Research CSV URL (https://files.zillowstatic.com/research/...csv) for a dataset newer than this actor's catalog. Overrides Dataset.

FieldTypeRequiredDescription
modestringrequiredWhat to return: latest values, full history, a multi-metric region snapshot, or the dataset catalog. The legacy options keep old saved tasks working with the previous wide output.
datasetstringoptionalZillow Research file to read. Covers home values, rents, inventory, days on market, price cuts, sales, market heat, forecasts, new construction and affordability at the geography levels Zillow publishes.
customDatasetUrlstringoptionalOptional Zillow Research CSV URL (https://files.zillowstatic.com/research/...csv) for a dataset newer than this actor's catalog. Overrides Dataset.
regionsarrayoptionalOptional region names or substrings: 'Austin, TX', 'Texas', 'TX', '90210', 'Harris County'. Matches region, state, city, county and metro names. Leave empty for all regions.
regionIdsarrayoptionalOptional exact Zillow RegionIDs (for example 102001 for the United States). If both Regions and Region IDs are set, a row must match both.
startDatestringoptionalOptional inclusive start date in YYYY-MM-DD format. Omit for the earliest published date.
endDatestringoptionalOptional inclusive end date in YYYY-MM-DD format. Omit for the latest published date.
includeChangesbooleanoptionalAdd 1-month, 3-month and 1-year percentage changes to latest and snapshot records when prior values exist.
snapshotMetricsarrayoptionalMetrics to include in snapshot mode. Allowed values: zhvi, zori, inventory, newListings, medianListPrice, medianSalePrice, salesCount, daysToPending, priceCutShare, saleToListRatio, marketHeatIndex, newConstructionSales. Leave empty for all 12.
categorystringoptionalFilter the dataset catalog in catalog mode. Ignored in other modes.
maxItemsintegeroptionalMaximum number of records to return. Large ZIP or neighborhood histories need a date range, region filter, or a higher cap.

Read the full published documentation

Zillow Research Data Scraper — ZHVI, ZORI & Market Heat

Download Zillow Research's public housing datasets as clean rows for analytics, dashboards and market reports. Choose from 208 home-value, rent, inventory, days-on-market, price-cut, sales, market-heat, forecast, new-construction and affordability files, for the US, states, metros, counties, cities, ZIP codes and neighborhoods Zillow publishes. No Zillow account, API key or proxy is needed.

What this actor does

  • 208 datasets in one actor: every live file on Zillow's research data page, including all ZHVI cuts (all homes, SFR, condo, bedrooms, tiers), ZORI rent cuts, inventory, new listings, pending listings, median list price, sale prices, sales counts, days to pending/close, price cuts, sale-to-list, percent sold above/below list, market heat, ZHVF/ZORF forecasts, new construction and affordability.
  • Four modes: latest returns one row per region with the newest value and 1-month, 3-month and 1-year changes; history returns tidy rows for every region and date; snapshot returns a 12-metric view for selected metro regions with rent-to-price yield; catalog lists the available datasets.
  • Region and date filters: match names or Zillow RegionIDs, and select an inclusive date range.
  • Zillow join keys: records carry regionId, sizeRank, regionName and regionType so they join cleanly to other Zillow series.
  • Uses only published research files: it reads Zillow's CSV files, not the listings site, so it is not affected by listing anti-bot walls.
  • Empty values are omitted from records rather than returned as null.

Output per observation

One record per region in latest mode, or per region and date in history mode:

  • recordType — observation, metricSnapshot or dataset
  • datasetId, category, metric, metricName — the selected dataset and metric
  • geography, frequency — metro, state, county, city, zip, neighborhood or us; monthly or weekly
  • regionId, sizeRank, regionName, regionType — Zillow's region identity
  • stateName, state, city, countyName, metro — location fields, with state/county/metro filled in when Zillow leaves them blank
  • stateFips, municipalCodeFips — present in county-level files
  • date — observation date (YYYY-MM-DD)
  • value — numeric value in the dataset's unit
  • unit — USD, USD/month, USD/year, USD/sqft, percent, days, count, index, ratio or years
  • latestValue, latestDate — newest value in latest and snapshot modes
  • change1mPct, change3mPct, change1yPct — changes in latest and snapshot modes when prior values exist (4-week, 13-week and 52-week offsets on weekly datasets)
  • grossRentalYieldPct — annual rent divided by home value, when a snapshot has both ZORI and ZHVI
  • baseDate, horizonMonths — forecast origin and horizon (1, 3 or 12 months) on forecast rows
  • sourceUrl, dataSource, scrapedAt — the exact file read and the download time

In catalog mode, each record describes one dataset: datasetId, category, metric, metricName, geography, frequency, unit, dataType, firstDate, lastDate, sizeBytes, isForecast and sourceUrl.

FAQ

Is this affiliated with Zillow? No. This actor reads Zillow Research's public data files. Zillow is not affiliated with and does not endorse this actor. Attribution to Zillow Research is required when you publish the data.

Do I need a Zillow account, API key or proxy? No. The research CSV files are public. The actor needs no login, API key, cookie or proxy configuration.

What is the difference between ZHVI and ZORI? ZHVI is Zillow's typical home value index. ZORI is its observed rent index. The dataset picker includes all-homes, single-family, condo, bedroom-count and price-tier cuts where Zillow publishes them.

Why does rent data cover fewer metros than home values? Zillow publishes ZORI for fewer regions than ZHVI. The actor returns only regions present in the chosen file; it does not fill missing regions with estimates.

Why do some months have no value for my region? Zillow starts some series later or stops publishing a cut. Empty cells are skipped, so a record appears only when Zillow published a value for that region and month.

Why does history data sometimes change between runs? Zillow restates its back-series when methodology or source data change. Each run reads the current published file, so a later download can differ from an earlier one. scrapedAt records when the file was read.

How do I get a full ZIP or neighborhood history? Those files are large and the actor caps output at 100,000 records per run. Use latest for a current snapshot, or split the request by state, region or date range.

Are market heat and forecast values percentages? Market heat is an index value; higher means a hotter seller's market. ZHVF and ZORF forecast values are percentages. The unit field on every row tells you which applies.

Can I use a dataset that is not in the picker? Yes. Paste its Zillow Research CSV URL into customDatasetUrl. Only files.zillowstatic.com/research/...csv URLs are accepted.

How current is the data? Zillow updates monthly datasets around the middle of the following month and weekly files on a monthly cadence. The latestDate field shows the newest observation in the file you selected.

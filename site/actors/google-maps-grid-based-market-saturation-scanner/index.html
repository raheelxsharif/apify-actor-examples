    Google Maps Grid-Based Market Saturation Scanner is an Apify Actor published by Dataspryva. It accepts 14 input fields, and searchQuery is required. Each result can carry up to 29 declared fields, including recordType, name, categoryName, totalScore, reviewsCount and address. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per business”, “Input”, “Use cases”, “Tips for best results” and “Limitations”.

    What it costs

    Google Maps Grid-Based Market Saturation Scanner uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    searchQuerySearch Querystring requiredType of business to search for (e.g., 'pharmacy', 'restaurant', 'dentist').Example "coffee shops"
    locationNameLocation NamestringName of a public Google Maps location (e.g., 'Brooklyn, NY'). Google resolves its real center anonymously, then the actor scans the user-controlled radiusKm around it. Use boundingBox or GeoJSON for exact boundaries.
    boundingBoxBounding BoxobjectGeographic bounding box defining the scan area. Provide north/south/east/west coordinates.Example {"north": 40.77, "south": 40.73, "east": -73.97, "west": ...
    circleCenterCircle CenterobjectCenter point for a circular scan area. Use with radiusKm.
    radiusKmRadius (km)numberRadius in kilometers for circular scan area (used with circleCenter or locationName).Default 5; Allowed 0.1 to 50
    customGeolocationCustom Geolocation (GeoJSON Polygon)objectCustom GeoJSON Polygon defining the scan boundary.
    zoomLevelZoom LevelintegerControls grid cell granularity. Higher = smaller cells, more thorough coverage.Default 15; Allowed 12 to 18
    maxPlacesPerCellMax Places Per CellintegerMaximum businesses to collect from each grid cell (1–260; Google's ranked window for one cell reaches roughly 136–213 places).Default 120; Example 5; Allowed 1 to 260
    maxPagesPerCellMax Pages Per CellintegerHow many 20-result pages to read per cell. Deeper pages surface more businesses — page 1 finds about 20% of a cell's places, page 9 finds all of them.Default 13; Allowed 1 to 13
    maxTotalResultsMax Total ResultsintegerMaximum total businesses to extract across all cells. Stops scanning when reached.Default 10000; Example 5; Allowed 1 to 100000
    deduplicateResultsDeduplicate ResultsbooleanRemove duplicate businesses that appear in multiple adjacent grid cells.Default true
    enrichDetailsEnrich Place DetailsbooleanOpen each place's page for extra fields (price level, Plus Code, photo sample, rating histogram, open/closed status). Slower; leave off for large exports since listing fields are always collected.Default false
    minRatingMinimum RatingnumberOnly include businesses with a rating at or above this value (1.0–5.0). Leave empty to include all.Allowed 1 to 5
    languageLanguagestringLanguage for Google Maps interface and results.Default "en"; Allowed en, es, fr, de, it, pt, ja, ko and 3 more

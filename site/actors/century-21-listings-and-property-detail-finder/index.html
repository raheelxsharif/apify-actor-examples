    Century 21 Listings & Property Detail Finder is an Apify Actor published by Dataspryva. It accepts 27 input fields, and mode is required. Each result can carry up to 15 declared fields, including listingId, listingStatus, listingType, address, city and stateCode. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Find homes on Century21.com by city, county, neighborhood, ZIP, state, or a pasted URL. The actor reads Century 21's own public listing API from a plain HTTP request — no login, cookie, proxy, or API key from you — and returns clean records for for-sale, for-rent, pending, coming-soon, sold, expired, inactive, withdrawn, rented, and canceled listings.

    It covers the full listing lifecycle rather than only active inventory: price, beds/baths, living area, lot size, year built, photos, open houses, virtual tours, MLS number, listing office, agent contact details (when the MLS publishes them), taxes, HOA dues, schools, and optional room-by-room property details.

    What this actor does

    • Four modes: search by place, byUrl from pasted Century 21 search/listing URLs, byAddress with exact-address matching, byListingId from an ID or listing URL
    • Every public status: active, pending, coming soon, sold, expired, inactive, withdrawn, rented, canceled
    • For sale or for rent with the site's own rental index
    • Filters: property type, status, price, min/max bedrooms, min bathrooms, days on market, sqft, lot size, year built, open houses, new construction, virtual tours, luxury, and sort order
    • Pagination: up to 300 listings per request, paged until your maxItems or the source runs out; results are deduplicated across pages
    • Full detail enrichment: description, taxes, HOA, schools, room descriptions, appliances, utilities, every photo, open-house windows, and agent email/phone/profile when available
    • Omit-empty output: a field appears only when Century 21 actually returned a real value

    Use cases

    • Sold comparable research — pull sold listings by ZIP or neighborhood and compare last list prices, size, and year built
    • Open-house routing — find every upcoming open house in a target area and hand the schedule to buyers or agents
    • Agent lead lists — export listing agent names, phones, emails, and brokerage offices with the property context attached
    • Rental market monitoring — compare rents, deposits, and unit sizes across neighborhoods
    • Inventory and price tracking — re-run the same search daily and diff price, status, and new listings
    • Property underwriting — filter by lot size, year built, and square footage, then enrich the shortlist with taxes, HOA, and room details

    Questions

    Does this need a proxy, login, or API key?

    No. Century21.com's own listing API is public and works from a plain HTTP request. The actor uses no proxy and never asks for cookies or credentials.

    Can it scrape sold or off-market homes?

    Yes. Century 21's public index exposes sold, expired, inactive, withdrawn, rented, and canceled statuses alongside active inventory. Select the statuses you want. A property that is not in the public index at all cannot be returned.

    How are open houses returned?

    When Century 21 publishes open-house windows, each record includes an openHouses[] array with ISO startTime and endTime. The hasOpenHouses filter limits results to listings with an upcoming open house.

    What happens if I paste an address Century 21 does not list?

    The actor rejects it instead of returning a nearby look-alike. Century 21's address suggestions include nearby properties even when the exact house number is missing; this actor requires the house number and street name to match, so a no-match run is empty rather than wrong data.

    Can I paste a Century 21 URL?

    Yes. Search URLs (/homes/list/...) honour their city/county/ZIP/state/neighborhood path and any filters in the query string. Listing URLs (.../lid-...) fetch the full detail record. Both can be mixed in one run.

    How do I find a listing ID?

    Every record from any mode includes listingId. You can also paste the listing's full URL.

    Why does a search result have fewer fields than a detail lookup?

    Century 21's search endpoint returns a lighter record. Set includeFullDetails: true to fetch the full detail (description, taxes, schools, room details, all photos) for every search result; this adds one request per listing. byAddress, byListingId, and listing URLs always return full details.

    Why is an agent phone or email missing?

    Contact details are published only when the listing's MLS supplies them. Most listings include an agent name and office; email and phone are less common and are omitted rather than fabricated.

    Are sold prices the final sale price?

    Century 21's public sold records show the MLS list/close price it publishes for the listing. It is not an independent deed or county-recorder sale price.

    What area does this cover?

    Century21.com's US market. Coverage depends on the MLS/IDX feed for each area; Century 21's country-specific sites (Canada, Portugal, Spain, France, etc.) use different systems and are not part of this actor.

    How fresh is the data?

    Records are pulled live from Century 21's current public feed on every run. There is no cache.

    Limits and notes

    Limitations

    • US Century21.com only; other Century 21 country domains are not supported.
    • A listing must be present in Century 21's public index. Private/off-market listings are not reachable.
    • Status availability varies by MLS; some feeds omit expired, inactive, or sold records entirely.
    • Detail fields such as taxes, HOA, schools, room descriptions, agent email, and phone are conditional on what the listing MLS publishes. They are omitted when absent.
    • byAddress is intentionally strict: it requires an exact house-number and street match, so spelling variants that the suggestion service cannot normalise will return zero records.

    TikTok Hashtag Momentum & Top Creator Tracker is an Apify Actor published by Dataspryva. It accepts 16 input fields, none of them required at the top level. Each result can carry up to 13 declared fields, including rowType, rankIndex, hashtagName, publishCnt, vv and observedCountry. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (this week's us hashtags, every industry). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 1000, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    TikTok Hashtag Momentum & Top Creator Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstringChoose 'Trending hashtags' for TikTok's ranked hashtag charts (post/view counts, popularity curve, creators) or 'Trending videos' for TikTok's ranked video charts (views, engagement, author stats).Default "trendingHashtags"; Allowed trendingHashtags, trendingVideos
    countriesMarketsarray(mode=trendingHashtags) One or more markets to read the hashtag chart for. Each market adds its own ranked rows.Default ["US"]; Allowed US, GB, CA, AU, DE, FR, IT, ES and 19 more
    periodsTime Windowsarray(mode=trendingHashtags) Lookback windows in days. 7 shows recent spikes, 90 shows longer-term trends. Select one or more.Default ["7"]; Allowed 7, 30, 90
    includeOverallRankingInclude Overall Chartboolean(mode=trendingHashtags) Include each market's overall top-3 hashtag chart. Turn off to read only the industry charts selected below.Default true
    scanAllIndustriesScan All Industriesboolean(mode=trendingHashtags) Read all 19 industry charts for every market and window. This widens coverage from 3 to up to 60 hashtags per market and window, because each industry chart is read separately.Default true; Example false
    industriesIndustry Chartsarray(mode=trendingHashtags) Specific industry charts to read when 'Scan all industries' is off.

    Twitter (X) Space Scraper is an Apify Actor published by Dataspryva. It accepts 14 input fields, none of them required at the top level. Each result can carry up to 8 declared fields, including type, title, state, creator.username, listenersLive and listenersReplay. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Three ways to find Spaces”, “What you get”, “Input”, “How discovery works”, “FAQ” and “Limits”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 8 fields in 1 dataset view, and the README documents 2 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxParticipantProfiles (default 50, maximum 100) caps how many results a run collects, and so what it costs.

    What it costs

    Twitter (X) Space Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    spaceUrlsSpace links, IDs or announcement postsarrayPaste Space links such as https://x.com/i/spaces/1YpKkZgnrDXxj, bare Space IDs, or the post that announces a Space (the actor finds the Space from its card). x.com and twitter.com links both work.Example ["https://x.com/i/spaces/1YpKkZgnrDXxj"]
    searchQueriesSearch keywords or hashtagsarrayFind public Spaces from posts that match a keyword or hashtag, for example AI, crypto or #Space. Each query reads recent matching posts and resolves the Spaces they announce.
    hostUsernamesHost usernamesarrayFind Spaces announced by specific X accounts. Paste handles with or without @, or a profile URL.
    maxSpacesMaximum discovered SpacesintegerUpper limit for Spaces found through keywords and hosts. Spaces that you paste as links or IDs are always collected.Default 20; Example 1; Allowed 1 to 200
    spaceStateSpace statestringOnly keep Spaces in this state. Applies to links and discovery alike.Default "any"; Allowed any, live, upcoming, ended
    includeParticipantsInclude participantsbooleanAdd the host, speakers and listeners to the Space row and emit one separate "space participant" row per person.Default true
    includeParticipantProfilesEnrich participant profilesbooleanLook up each participant's public profile (bio, followers, website, verification) instead of only the compact name shown in the Space. Adds one request per participant.Default true; Example false
    maxParticipantProfilesMaximum enriched participant profilesintegerCap on profile lookups per Space. 0 means every participant. Large Spaces with many listeners can be expensive.Default 50; Example 10; Allowed 0 to 100
    includeReplayAudioInclude replay audiobooleanAdd the HLS replay link and, when a file can be produced, store a downloadable audio file with its duration and size.Default false
    includeTranscriptInclude transcriptbooleanProduce a spoken-word transcript. Captions are used when the replay has them; otherwise AI speech recognition runs (slower and memory-hungry).Default false
    transcriptSegmentsAsRowsEmit transcript segments as rowsbooleanIn addition to the transcript summary row, emit one "space transcript segment" row per timed segment.Default false
    transcriptionMethodTranscription methodstringHow the transcript should be produced.Default "auto"; Allowed auto, captions, ai
    whisperModelAI transcription qualitystringWhisper model for AI transcription. Larger models are more accurate but need more actor memory; on 1 GB the actor safely falls back to a smaller model.Default "base"; Allowed tiny, base, small, medium, large-v3
    proxyConfigurationProxy configurationobjectOptional. The actor works without a proxy and switches to Apify Proxy automatically if X blocks the direct connection.

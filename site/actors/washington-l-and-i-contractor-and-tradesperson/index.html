    Washington L&I Contractor & Tradesperson License Scraper is an Apify Actor published by Dataspryva. It accepts 14 input fields, and mode is required. Each result can carry up to 8 declared fields, including businessName, licenseId, contractorType, status, city and state. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Data source”, “Output per license record”, “Input”, “Use cases” and “Limitations”.

    What it costs

    Washington L&I Contractor & Tradesperson License Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredHow to search the L&I registry.Default "byName"; Allowed byName, byLicenseId, byUbi, byAccountId
    nameName (mode=byName)stringBusiness name or last name of an individual (e.g. smith, abc construction). Partial matches are supported, minimum 2 characters.Default "smith"
    licenseIdLicense / registration / certificate number (mode=byLicenseId)stringThe contractor license, electrician/plumber certificate, or registration number (e.g. ABCAR**824BB, asterisks included where L&I's own record has them). Partial prefixes are supported.Example "ABCAR**824BB"
    ubiUBI number (mode=byUbi)stringWashington Unified Business Identifier — exactly 9 digits (e.g. 604164913).Example "604164913"
    accountIdWorkers' comp account ID (mode=byAccountId)stringL&I workers' compensation account ID, e.g. 88160900 (digits only). Formatted legacy values such as 881,609-00 are accepted and normalized.Example "88160900"
    cityFilter by citystringOnly emit results located in this Washington city (case-insensitive exact match, e.g. Seattle). Applied server-side alongside mode. Leave blank for all cities.Default ""
    zipCodeFilter by zip codestringOnly emit results in this 5-digit Washington zip code (e.g. 98121). Applied server-side alongside mode. Ignored if city is also set. Leave blank for all zip codes.Default ""
    licenseCategoryFilter by license categorystringOnly emit records whose contractor/trade type matches this category. Leave unset for all categories.Default ""; Allowed , Construction Contractor, Electrical Contractor, Electrical Administrator, Electrical Trainee, Electrician, Master Electrician, Modified Trainee and 13 more
    statusFilterFilter by license statusstringOnly emit records with this top-level license status. Leave unset for all statuses.Default ""; Allowed , active, inactive, expired, suspended, out of business, re-licensed, superseded and 1 more
    violationsOnlyOnly show licenses with violationsbooleanOnly emit records that have a safety violation and/or contractor violation flagged (hasSafetyViolation or hasContractorViolation). Useful for compliance monitoring and vendor due diligence.Default false
    sortBySort bystringOrder of results: L&I's own relevance ranking, or business name.Default "relevance"; Allowed relevance, name
    sortOrderSort directionstringAscending or descending, applied to the selected Sort by field.Default "desc"; Allowed desc, asc
    fetchDetailsFetch full license detailsbooleanEnrich each result with the full detail record: address, bonds, insurance, business owners, violations, associated licenses, and DOSH inspections. Adds one extra request per record, so it is capped by Max items.Default true
    maxItemsMax itemsintegerHard cap on emitted license records (1-500). Results are fetched 100 at a time.Default 10; Allowed 1 to 500

Snapchat Highlight & Story Media Downloader

Pull individual snaps out of a public Snapchat profile's curated highlight albums and active story — no login, cookies, or API key. Point it at a username and get back direct, downloadable media URLs plus the creator and post details attached to each snap.

What this actor does

  • Extracts every snap from a creator's saved highlight albums, which stay live indefinitely.
  • Extracts every snap from a creator's current public story, which refreshes roughly every 24 hours.
  • Returns a direct, ready-to-download media URL and preview thumbnail for each snap.
  • Merges creator details (display name, subscriber count, bio, avatar) into every snap record so no join is needed downstream.
  • A postedAfter date filter lets scheduled runs skip re-collecting the same long-lived highlight content every time.
  • Empty fields are omitted from records — a snap without geotags or a sponsorship flag simply won't have those keys.

Output per snap

  • username, displayName, isVerified, subscriberCount, bio, profileUrl, profilePictureUrl — creator details, repeated on every snap from that profile
  • storySource — curatedHighlight or activeStory, marking where the snap came from
  • highlightId, storyTitle, highlightThumbnailUrl — the parent album/story ID, title, and cover image
  • snapIndex — zero-based position of the snap within its highlight or story
  • snapId — the snap's own ID (often absent on curated highlights)
  • mediaUrl, mediaPreviewUrl, mediaType — direct media file, its preview image, and whether it's video or image
  • postedAt — when the snap was originally posted
  • snapTitle, snapSubtitles — any caption text or overlay subtitles on the snap
  • lat, lng — geotag coordinates, when the snap carries one
  • hasAttachment, isSponsored — whether the snap links out, and whether it's marked sponsored
  • audioTranscriptionObjectUrl — a transcription file URL, when Snapchat provides one
  • storySubtitle, storyShareId, emoji, storyTapId, canonicalUrlSuffix, videoTrackUrl, isAttributed — extra fields that only appear on activeStory records
  • scrapedAt — when this actor fetched the record
  • inputUsername, error — present instead of the above on a failed-profile record

Input

Field Type Default Description
usernames array of strings – Snapchat usernames or profile URLs. Accepts bare usernames, @username, snapchat.com/add/username, or snapchat.com/@username.
maxSnapsPerUser integer 50 Maximum snaps to extract per user across the selected sources (1–500).
sources array of strings ["curatedHighlights", "activeStory"] Which story sources to pull: curatedHighlights (saved albums) and/or activeStory (current public story).
postedAfter string – Only return snaps posted on or after this date (YYYY-MM-DD). Leave empty to collect everything available.
proxyConfiguration object – Optional Apify proxy. Public profiles usually work without one.

Example: pull everything for a creator

{
  "usernames": ["djkhaled"],
  "maxSnapsPerUser": 100
}

Example: only new highlight content since the last run

{
  "usernames": ["khaby.lame", "brentrivera"],
  "sources": ["curatedHighlights"],
  "postedAfter": "2026-06-01"
}

Example: active stories only, across several creators

{
  "usernames": ["@djkhaled", "https://www.snapchat.com/@brentrivera"],
  "sources": ["activeStory"],
  "maxSnapsPerUser": 30
}

Use cases

  • Content archiving — keep a permanent, downloadable copy of a creator's highlight reel before it's edited or removed.
  • Influencer monitoring — track what a creator is posting across both highlights and their live story.
  • Media and brand research — pull isSponsored snaps across multiple creators to study sponsored-content patterns.
  • Social listening tools — feed structured snap metadata and timestamps into an analytics pipeline.
  • Scheduled monitoring — use postedAfter to run daily/weekly without re-downloading already-seen highlight snaps.

FAQ

Do I need a Snapchat account or cookies? No. The actor reads only public profile pages over standard HTTP; no login or session is required.

What's the difference between curated highlights and an active story? Curated highlights are albums a creator manually saves, so they persist until the creator removes them. The active story is the creator's current public 24-hour story and changes constantly. Both are pulled by default; set sources to collect only one.

How do I tell which source a snap came from? Every record's storySource field is curatedHighlight or activeStory.

What happens if a profile is private or has no public content? The actor pushes a record with inputUsername and error describing the issue and moves on — a missing profile doesn't fail the whole run.

Does maxSnapsPerUser apply per source or across both? It's a combined cap per user. Curated-highlight snaps are counted first, then active-story snaps fill the remainder up to the limit.

Will the mediaUrl still work days later? Highlight media URLs tend to stay valid for weeks or months. Active-story URLs carry short-lived CDN tokens and can expire within hours, so download that media soon after the run.

Why use postedAfter at all if highlights don't expire? Without it, a scheduled run re-collects the same highlight snaps every time since they rarely disappear. Setting it to your last run's date keeps subsequent runs limited to genuinely new content.

Is this affiliated with Snapchat? No. This is an independent third-party actor that reads public Snapchat profile pages; it is not operated by or affiliated with Snap Inc.

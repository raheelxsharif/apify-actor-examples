    Decrypt Crypto News Finder by Category & Keyword is an Apify Actor published by Dataspryva. It accepts 16 input fields, and mode is required. Each result can carry up to 7 declared fields, including title, authors, category, publishedAt, readingTimeMinutes and wordCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search with relevance and a date window). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 10, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Decrypt Crypto News Finder by Category & Keyword uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch. Search matches titles, excerpts and article bodies. The latest mode returns the newest stories.Default "search"; Allowed search, browseByCategory, byId, trending, byTag, byCoin, byAuthor
    searchQuerySearch querystringKeyword or phrase matched against article titles, excerpts and bodies (mode=search). E.g. bitcoin, ethereum, NFT.Default ""; Example "bitcoin"
    categoryCategorystringOne Decrypt category slug (mode=browseByCategory and as a filter in other modes). Leave empty for any category.Default ""; Example "news"; Allowed , ai, artificial-intelligence, artificial-intelligence-learn, build, business, course-articles, courses and 40 more
    categoriesMultiple categoriesarrayFilter by several category slugs at once. Applies to search, latest, tag, coin and author modes.Default []; Allowed ai, artificial-intelligence, artificial-intelligence-learn, build, business, course-articles, courses, cryptocurrencies and 39 more
    tagSlugsTag slugsarrayFilter by Decrypt tag slugs, e.g. bitcoin, ethereum, regulation. Tag names are not accepted; use the slugs returned in each record.Default []
    coinSlugsCoin slugsarrayFilter by coin slugs, e.g. bitcoin, ethereum, solana. Names and ticker symbols are also accepted and mapped to slugs. The source can match articles with no explicit coin relation; those rows omit coins and coinSlugs.Default []; Allowed 1inch, aave, algorand, apecoin, aptos, arbitrum, arweave, aster and 113 more
    authorSlugsAuthor slugsarrayFilter by author slugs, e.g. jose, stephengraves. Author names are not accepted; use the slugs returned in each record.Default []
    articleIdsArticle IDs or URLsarrayArticle IDs or decrypt.co URLs (mode=byId). Accepts bare IDs, /id/slug, localized /es/id/slug, ?p=id and /resources/slug URLs.Default []; Example ["375656"]

    dateRangeFromPublished fromstringOnly articles published on or after this date (YYYY-MM-DD). The date range is applied by the source.
    dateRangeToPublished untilstringOnly articles published on or before this date (YYYY-MM-DD). The date range is applied by the source.
    sortBySort orderstringNewest first, oldest first, or best match. Best match needs a search query; otherwise newest is used.Default "newest"; Allowed newest, oldest, relevance

    X Community Activity & Member Finder is an Apify Actor published by Dataspryva. It accepts 17 input fields, and communityUrls is required. Each result can carry up to 21 declared fields, including type, communityName, name, text, author.username and createdAt. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (community overview plus top posts). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPosts (default 50, maximum 1000) and maxMembers (default 50, maximum 200) cap how many results a run collects, and so what it costs.

    What it costs

    X Community Activity & Member Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

Amazon Brand Store Page & Merchandising Crawler

Amazon Brand Store Page & Merchandising Crawler

Brands design their Amazon Store page like a mini storefront — navigation tabs, banner creative, and a curated product mix. This actor crawls that storefront, walking the navigation menu into subpages, and returns the page structure, the creative modules, and every product it links to.

What this actor does

  • Crawls a Brand Store's landing page and, optionally, the subpages reachable through its own navigation menu.
  • Resolves a brand's Store URL automatically when you only have a product page URL or ASIN instead.
  • Finds every real product link on each crawled page, with price, rating, and badges included only when actually shown next to that link.
  • Optionally captures the page's creative modules: banner images, video, headings, and call-to-action text.
  • Reports a page explicitly as blocked or missing rather than silently returning it as an empty store.

A Brand Store is curated by the brand, not a full product catalog — Amazon doesn't guarantee every item a brand sells appears there. This actor reports every product link it can find on the pages it crawls; for a seller's complete catalog, a seller-shop scraper is the better tool.

Output: store page record (recordType: storePage)

Field Description
storeUrl The Brand Store URL this page belongs to
brand Brand name
storePageId Page identifier from the URL
pageName Navigation label for this page, e.g. "HOME", "FEATURED DEALS"
description Page meta description, when present
logoUrl Brand logo image
navigation Subpage links found on this page, each with name, url, storePageId, order
depth How many navigation hops from the landing page this page is
pagePosition Position in the crawl order
scrapedAt When the actor collected the record

Output: creative asset record (recordType: asset, when includeAssets is on)

Field Description
storeUrl, brand, storeSubPage Which store and page the asset appears on
moduleType image or video
heading, bodyText Nearby section heading and caption text, when present
ctaText Call-to-action text, e.g. "Shop now"
imageUrl, imageAlt Image modules
videoUrl, videoThumbnail, videoTitle Video modules
destinationUrl Link target, when the asset itself links to a non-product page
modulePosition Position of this module on the page
scrapedAt When the actor collected the record

Output: product record (recordType: product)

Field Description
asin Amazon product ID
title Product title, when visible next to the link
url Product page URL
thumbnailImage Product thumbnail
price, listPrice Price and list price, each with value, currency, display, only when visible on the page
stars, reviewsCount Rating and review count, only when visible near the link
badge One of BestSeller, AmazonsChoice, OverallPick, LimitedTimeDeal, NewOnAmazon, SmallBusiness, only when shown
discountPercent Percent off, only when a discount badge is shown
brand Brand name
storeUrl, storeSubPage Store and page the product was found on
modulePosition Position of the product tile on the page
scrapedAt When the actor collected the record

Output: page error record (recordType: storePageError)

Emitted instead of a storePage record when a page couldn't be read. Fields: storeUrl, pageClassification (e.g. NOT_FOUND, CAPTCHA, AUTH_REQUIRED), depth, pagePosition.

Use cases

  • Brand monitoring teams track how a competitor merchandises and navigates their Amazon storefront.
  • Catalog discovery teams find every product a brand currently features on its Store page.
  • Creative audit teams collect a brand's storefront imagery, video, and CTA copy in one pass.
  • Merchandising researchers compare navigation structure and featured-product mix across brands.
  • Pricing teams snapshot the price and rating shown on each Store product tile.

FAQ

Is this the same as a seller's product catalog? No. A Brand Store is a curated page the brand designs; a seller catalog lists everything that seller has for sale. Use this actor for the storefront experience, and a seller-shop tool for the full catalog.

Why do some products have no price or rating? Brand Store product tiles don't always render price or rating in the page itself — a field is only included when it's actually visible next to the product link, never a guessed value.

What if I only have a product URL, not a store URL? Pass it via productUrls (or the ASIN via asins); the actor opens that product page, follows its "Visit the Store" link, and crawls that store instead.

Does this need a login or cookies? No. Brand Store pages are public.

Why does the actor sometimes report a storePageError instead of products? Amazon occasionally serves a block or rate-limit page instead of the real store. Rather than reporting zero products as if the store were simply empty, the actor records explicitly what happened on that page.

Does this capture every product a brand sells? No — see "What this actor does" above; a Brand Store is editorially curated, not a full catalog.

Which Amazon marketplaces are supported? Any Amazon domain — amazon.com, amazon.co.uk, amazon.de, and so on — just pass the full Store URL for that marketplace.

Is this affiliated with Amazon? No. This actor independently reads Amazon's public Brand Store pages and is not affiliated with or endorsed by Amazon.

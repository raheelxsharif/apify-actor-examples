Google Maps Top List & Ranked Places Extractor

Pull the ranked places from a Google Maps Top list query like 'Top hotels in Paris', or from a list/search URL, with optional full place-page enrichment.

Google Maps Top List & Ranked Places Extractor is an Apify Actor published by Dataspryva. It accepts 19 input fields, none of them required at the top level. Its build declares a results dataset with 2 views. Runs happen on Apify, where the Store page lists the current price.

Google Maps Top List & Ranked Places Extractor

Google Maps ranks the places in a "Top hotels in Paris" search and in every shared list you save. This actor reads that ranked order — directly from Google's public Maps endpoints, without a browser, cookies, an API key, or proxy setup — and writes one row per place.

It handles two kinds of inputs:

  • Top-list queries such as Top hotels in Paris, Best coffee in Brooklyn, or Things to do in Tokyo.
  • Shared list links such as https://www.google.com/maps/placelists/list/... or a short maps.app.goo.gl link. A Maps search URL is accepted too.

What you get

  • The rank Google gives each place, plus the query or list it came from.
  • Shared-list context: list title and description, list ID, owner, the saver's note, and the saved date.
  • Business facts: category, rating, review count, address, phone, website, hours, open/closed status, coordinates, price, and Place IDs.
  • Optional detail enrichment: Plus Code, rating histogram, photos, amenities, service options, booking links, hotel stars and amenities, fuel prices, and closure flags.

No record contains null, empty strings, or empty arrays. A field Google does not publish for a place is omitted.

Field notes

  • rank is the position Google returned for that query or list, starting at 1. Filtering never renumbers it.
  • placeId is the canonical ChIJ... ID. A legacy 0x...:0x... token is kept separately in featureId.
  • price is the amount Google prints on a hotel card, kept verbatim (currency and K/M shorthand included). priceLevel is Google's standing band such as $$$ or a dining price range.
  • highlights are the short feature pills on a hotel list card. amenities is the fuller badge set from the place page.
  • note and savedAt come from the shared list and are present only for list rows. listTitle and listDescription carry the list's own title and description.

Use cases

  • Travel research: compile ranked hotels, restaurants and attractions per city.
  • Local SEO: compare how a category ranks across markets.
  • Lead generation: export name, rating, phone, website and address from a shortlist.
  • Content: turn shared "best of" lists into structured tables.
  • Site selection: measure the density and quality of a category in an area.

FAQ

Does it need cookies, a login or an API key? No. Every mode reads public Google Maps data.

Do I need to configure a proxy? No. The actor chooses its connection automatically. There is no proxy field to fill in.

How many places can a query return? It varies by query and city. Broad categories commonly expose 150–450 ranked places; narrow queries expose fewer. The actor follows Google's pages until maxResults, the end of the result window, or the source's own stop signal.

How many places can a shared list have? The public list endpoint returns the whole list in one response. This actor requests up to 5,000 places per list; that is the practical source window for very large lists.

Why did I get fewer rows than maxResults? Google's result window ended, the list was shorter, or filters removed rows. The run status says which case applies and how many rows the filters skipped.

What does enrichDetails add? Plus Code, rating histogram, photos, amenities, service options, booking links, hotel details, fuel prices and closure flags. It costs one extra request per place; turn it off when the list-card fields are enough.

Are sponsored places included? No. Google can print paid hotel cards at the top of a feed. They are excluded, so rank follows the organic list, as in the previous version.

Are popularTimesSummary and menuLink filled? popularTimesSummary is not published by the public Maps feed used here, so it is not emitted. menuLink appears only when a place's detail data exposes a menu URL, which is rare. Use the dedicated popular-times or menu actor when you need those fields.

Does it support non-English Maps? Yes. Pick any language in the dropdown; names, categories, addresses and hours are localized by Google.

What happens when Google blocks a request? The actor retries and escalates its connection automatically. If no result view ever arrives, the run status says it was an upstream block or degraded response — never "no places found".

Is this affiliated with Google? No. It is an independent tool that reads publicly available Google Maps pages. You are responsible for using the data lawfully and consistently with Google's terms.

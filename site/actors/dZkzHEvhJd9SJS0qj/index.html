Actors/Crexi Commercial Property Listings & Pricing Extractor

Crexi Commercial Property Listings & Pricing Extractor

Collects active commercial real estate listings from Crexi across any US state and 14 property types, with asking price, square footage, location, and brokerage details.

Open on ApifyGitHub source

Published README

Read the full published documentation

Crexi Commercial Property Listings & Pricing Extractor

Crexi is one of the largest US marketplaces for commercial real estate. This actor reads Crexi's own public listing APIs and returns for-sale, for-lease and auction properties as clean, structured rows — asking price, cap rate, NOI, building size, year built, lot size, broker contacts, photo galleries and coordinates. No account, cookies or proxy setup are required.

What this actor does

  • Three marketplaces in one actor: for-sale listings, for-lease listings and live auctions, with the filters each one actually supports.
  • Full filter surface: keywords, states, cities, counties, ZIP codes, 14 property categories, 50 subtypes, building class, asking price, price per square foot, cap rate, building size, lease rate, and Opportunity Zone listings.
  • Handles Crexi's result window for you. Crexi's API only returns 1,500 rows per filter combination. When you ask for more, the actor automatically splits the search into price-range partitions and merges the results, deduplicated.
  • Direct URL mode: paste any Crexi property link or ID — for-sale or for-lease — and the actor fetches exactly those records.
  • Optional enrichment: one toggle adds full broker contacts (name, brokerage website, license, profile), high-resolution gallery photos, investment highlights, the marketing write-up and published fact-sheet values.
  • Optional comps: attach up to six similar nearby listings to each record.
  • Fields Crexi does not publish for a listing (for example an undisclosed price) are omitted from that record instead of being written as blank or null.

Output per listing

  • property_id, name, property_url, record_type: "property" (property-record rows use record_type: "property_record")
  • transaction_type — sale or lease; is_auction and the auction block for auction listings
  • property_type (asset class), subtypes[]
  • address, city, county, state, zip_code, latitude, longitude
  • price (formatted) and price_usd (number), price_per_sqft, price_per_acre
  • square_footage (formatted) and building_sqft (number), lot_acres
  • cap_rate, net_operating_income (formatted) and noi_usd (number)
  • year_built, year_renovated, class, tenancy, units, stories
  • brokerage, broker_names[] — and with enrichment, brokers[] with profile, website, license, photo, phone and email, plus broker_phones[]/broker_emails[] and broker_of_record (name, license, phone when Crexi publishes it)
  • listing_status, investment_type, offers_due_on, is_opportunity_zone

Use cases

  • Acquisition sourcing — build lists of for-sale and for-lease assets that match a buy box of state, city, ZIP, type, size, price and cap rate.
  • Market research — compare inventory and asking prices across metros, categories and lease versus sale markets.

FAQ

Do I need a Crexi account, cookies or a proxy? No. The actor connects to Crexi automatically; there is nothing to configure.

Why did I get exactly 1,500 rows for a broad search? Crexi's API returns at most 1,500 rows per filter combination. The actor works around this by splitting large searches into price-range partitions and merging the results; a nationwide request for more than 1,500 rows is collected partition by partition. If a single indivisible slice still exceeds 1,500, the run's status message tells you the site's total and suggests narrowing filters.

Why is price missing on some listings? Some sellers publish a listing without an asking price. Those rows still contain everything else; with includeUnpriced off they are excluded entirely — and an active price filter always requires a published price.

Why are cap_rate or net_operating_income missing on some rows? Crexi only exposes those figures when the listing publishes them. When they are absent from the source, the fields are omitted rather than estimated.

What does scrapeDetails add? Each listing's detail data: broker phone and email contacts (with brokerage website, license number and profile link), plus broker_phones[]/broker_emails[] roll-ups; the full gallery in high resolution; investment highlights; the marketing description; published fact-sheet values such as zoning and ownership; the lease rate block for lease listings; and full auction details (deposits, bid increment, reserve status, bidder counts). It takes longer to run, so it is off by default.

Does this include sold or off-market properties? Crexi's sold prices and sale dates sit behind its paid Intelligence product and are never published anonymously, so the actor cannot return them. It does cover active for-sale, for-lease and auction listings, and it can fetch public property records (parcel data such as APN, lot and building size, class and comp flags) when you paste a crexi.com/property-records/... URL into propertyUrls.

Can I filter by year built, NOI or occupancy? Crexi only filters cap rate server-side (the minCapRate/maxCapRate inputs). Year built and NOI are returned on each record when published but cannot be filtered before download; occupancy is masked for anonymous users on sale listings (for-lease rows expose vacant_suites).

Can I mix sale and lease results in one run? Yes — select both in transactionTypes and the actor searches each marketplace and combines the rows into one deduplicated dataset. Crexi's for-sale and for-lease marketplaces use separate ID spaces, so the same property_id can appear once per marketplace; transaction_type and property_url tell the two records apart.

How fresh is the data? Every run queries Crexi live, so results reflect the marketplace at the moment the run starts.

Is this actor affiliated with Crexi? No. It is an independent tool that reads Crexi's public listing pages and APIs and is not operated by or affiliated with Crexi.

    Vivino Wine Ratings & Tasting Profile Scraper is an Apify Actor published by Dataspryva. It accepts 17 input fields, and mode is required. Each result can carry up to 8 declared fields, including name, winery, vintage, country, displayRating and ratingsCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per wine”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search for a wine). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 2500) caps how many results a run collects, and so what it costs.

    What it costs

    Vivino Wine Ratings & Tasting Profile Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to fetch. search runs one or more free-text queries; explore browses with filters; byWineId resolves wine/vintage URLs or IDs; winery pages through a producer's catalogue.Default "search"; Allowed search, explore, byWineId, winery
    searchQueriesSearch queriesarrayOne or more free-text wine searches (mode=search). Searches match wine, winery, region and grape names. Example: barolo, chateau petrus, napa valley cabernet.Default ["barolo"]

    wineryWinery ID, slug or URLstringWinery to scrape (mode=winery). Accepts 1945, michele-chiarlo, or a Vivino winery URL.
    wineTypeWine typestringFilter by wine type. Applies to search, explore and winery.Default ""; Allowed , 1, 2, 3, 4, 7, 24

    Patch.com Local News, Events & Classifieds Finder is an Apify Actor published by Dataspryva. It accepts 24 input fields, and mode is required. Each result can carry up to 10 declared fields, including recordType, headline, town, category, author and publishedDate. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Input”, “Modes”, “Output fields”, “Examples” and “How pagination works”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 10 fields in 1 dataset view. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    Patch.com Local News, Events & Classifieds Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to fetch from Patch.com.Default "search"; Allowed search, byTown, byCategory, byAuthor, byTag, events, classifieds, byUrl
    startUrlsPatch URLsarraymode=byUrl only. Paste Patch article, event, classified, town, category/topic, state or search URLs. Article/event/classified URLs are scraped directly; town/topic/state/search URLs are converted into the equivalent scoped query.
    searchQuerySearch querystringFree-text keyword to search for (mode=search; also applies to mode=events/classifieds and to scope URLs). Leave empty to browse the newest articles matching the other filters.Example "city council"
    searchMatchSearch matchstringHow multi-word searches match. "All words" requires every word anywhere in the headline/summary/topic (more results). "Exact phrase" requires the words to appear together (the old behavior).Default "allWords"; Allowed allWords, exactPhrase
    authorNameAuthor namestringExact byline/reporter/poster name (required for mode=byAuthor; on any other mode it is an extra server-side filter). Copy it from this actor's author output field, e.g. "Eric Heyl".Default ""
    tagNameTag namestringExact editorial tag (required for mode=byTag; on article modes it is an extra filter). Copy it from this actor's tags field, e.g. "Back To School". Only a minority of articles carry tags.Default ""
    regionSlugStatestringUS state/edition to scope results to (required for mode=byTown; optional filter on every other mode). "Across America" is Patch's national edition (code US); "US Territories" is a valid Patch region with no current articles.Default ""; Allowed , across-america, alabama, alaska, arizona, arkansas, california, colorado and 46 more
    townSlugTown/city slugstringPatch town/city URL slug (required for mode=byTown; requires regionSlug too). Find it in a Patch URL, e.g. patch.com/california/santamonica -> "santamonica". Example: "santamonica" (with regionSlug=california).Default ""
    categoryCategorystringNews category/topic to filter by (required for mode=byCategory; optional filter on mode=search/byTown/byAuthor/byTag). Not applicable to mode=events/classifieds -- use classifiedCategory for mode=classifieds instead.Default ""; Allowed , around-town, arts-entertainment, bulletinboard, business, going-green, holidays, kids-family and 14 more
    classifiedCategoryClassified categorystringClassifieds category to filter by (mode=classifieds only; a completely separate value set from category, which is news-only). Leave as "(any category)" to browse every classified category.Default ""; Allowed , announcements, for-sale, free-stuff, gigs-services, housing, lost-found, news-tip and 4 more
    sortBySort bystringOrder of results. "Nearest first" requires both nearLat/nearLng AND mode=search/byTown/byCategory/byAuthor/byTag (news); otherwise it falls back to Relevance. "Soonest event first" requires mode=events; on any other mode it also falls back to Relevance.Default "relevance"; Allowed relevance, newest, oldest, nearest, eventDate
    publishedAfterPublished after (YYYY-MM-DD)stringOnly include articles/events/classifieds posted to Patch on or after this date (i.e. listing date, not an event's own occurrence date -- see eventDateAfter for that). Format: YYYY-MM-DD. Combine with publishedBefore for a date range.

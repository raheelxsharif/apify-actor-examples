    TikTok Keyword & Brand Mention Monitor is an Apify Actor published by Dataspryva. It accepts 13 input fields, and keywords is required. Each result can carry up to 24 declared fields, including postId, keyword, rank, mentionInCaption, caption and createdAt. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “How matching works”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (brand monitor, last week, newest first). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerKeyword (default 50, maximum 500) and maxItems (maximum 100000) cap how many results a run collects, and so what it costs.

    What it costs

    TikTok Keyword & Brand Mention Monitor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    keywordsKeywords, brands, hashtags or handlesarray requiredTerms to monitor. One per line. Accepts plain keywords and phrases ('nike', 'nike shoes'), hashtags ('#JustDoIt') and handles ('@gymshark'). Multi-word caption matches require a contiguous phrase; direct @handles require a clickable tag.Example ["coffee"]
    matchModeWhat counts as a mentionstring'Real mentions' keeps posts with a contiguous caption phrase, a matching hashtag slug, a clickable @mention or an explicit sound match. For direct @handle inputs only the clickable tag (or sound) counts. 'Every search result' also keeps weak search hits, labelled searchResult.Default "mentionsOnly"; Allowed mentionsOnly, allResults
    datePostedPosted withinstringOnly keep posts published in this window. The actor asks TikTok for the matching publish window, merges a bounded unfiltered pass for recall, and applies the exact cutoff.Default "anyTime"; Allowed anyTime, past24Hours, pastWeek, pastMonth, past3Months, past6Months
    postedAfterPosted on or afterstringOptional exact cut-off, e.g. 2026-10-01 or '3 days'. The tighter of this and 'Posted within' applies.
    sortByOrderstringOrder of the final rows. 'Newest first' is the monitor-friendly order; TikTok's own newest ordering is used where available, with a client-side fallback.Default "relevance"; Allowed relevance, newest, mostLiked
    searchDepthHow wide to searchstring'Just this term' runs one search. 'Standard' adds the #hashtag and @handle for single-word terms. 'Deep' also reads photo/slideshow posts, related searches and case/spacing variants. A direct @handle stays tagged-only in mentionsOnly.Default "standard"; Example "keywordOnly"; Allowed keywordOnly, standard, deep
    maxResultsPerKeywordMax posts per keywordintegerMaximum rows kept for each keyword after all sources are merged (1-500). TikTok returns roughly 130-240 posts per source query; deep mode can find more across sources.Default 50; Example 3; Allowed 1 to 500
    maxItemsMax posts in totalintegerOptional global cap across all keywords and sources.Allowed 1 to 100000
    minPlayCountMinimum viewsintegerDrop posts with fewer plays/views. Leave empty for no minimum.Allowed at least 0
    searchCountrySearch from countrystring'Any country' uses the fastest free connection. A specific country pins the search to that market's results, which is slower but shows what people there see.Default "any"; Allowed any, US, CA, MX, BR, AR, CO, CL and 43 more
    onlyNewMentionsOnly new mentionsbooleanEmit only posts not seen by this monitor in previous runs. The first run backfills; 'new' means new to this monitor, not new on TikTok.Default false
    monitorNameMonitor namestringName for this watchlist's saved state. Use a different name for a separate set of keywords.Default "default"
    soundUrlsBrand or campaign soundsarrayOptional TikTok sound URLs or IDs to read as explicit sources, e.g. https://www.tiktok.com/music/original-sound-123... . Sound evidence sets soundMatch; a sound-only row uses source=sound and keyword=sound:<musicId>.

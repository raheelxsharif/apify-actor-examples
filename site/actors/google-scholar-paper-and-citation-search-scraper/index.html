    Google Scholar Paper & Citation Search Scraper is an Apify Actor published by Dataspryva. It accepts 15 input fields, none of them required at the top level. Each result can carry up to 13 declared fields, including recordType, title, name, authors, year and publication. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Examples”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 13 fields in 1 dataset view, and the README documents 17 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search recent review papers on a medical topic). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Google Scholar Paper & Citation Search Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringWhat to fetch: paper search, citing papers, or public author profiles.Default "search"; Allowed search, citations, authorProfile
    queriesSearch QueriesarrayKeywords or paper titles to search on Google Scholar (mode=search). Each query runs separately.Example ["attention is all you need"]
    clusterIdsCluster IDs or Citing URLsarrayPaper cluster IDs or Google Scholar 'cites=' URLs to list citing papers for (mode=citations).
    authorIdsAuthor IDs or Profile URLsarrayGoogle Scholar author IDs or profile URLs to export (mode=authorProfile).
    maxItemsMaximum ResultsintegerMaximum papers per query or cluster, or papers per author. Google Scholar serves about 10 search results per page.Default 100; Example 3; Allowed 1 to 1000
    sortBySort BystringSort search results by relevance or date (mode=search).Default "relevance"; Allowed relevance, date
    filterDocument FormatstringKeep only PDF or HTML results; applied to returned rows (mode=search).Default "all"; Allowed all, pdfOnly, htmlOnly
    articleTypeArticle TypestringReturn all articles or review articles only (mode=search).Default "any"; Allowed any, review
    newerThanPublished After (Year)integerOnly include papers published in this year or later (mode=search).Allowed 1900 to 2030
    olderThanPublished Before (Year)integerOnly include papers published in this year or earlier (mode=search).Allowed 1900 to 2030
    authorAuthored BystringReturn papers written by this author, e.g. 'Geoffrey Hinton' (mode=search).
    publicationPublished InstringReturn papers from this journal or venue, e.g. 'Nature' (mode=search).
    titleOnlySearch Titles OnlybooleanMatch the query against paper titles instead of the full text (mode=search).Default false
    includeCitationFormatsInclude Citation FormatsbooleanAlso return MLA, APA, Chicago, Harvard, and Vancouver citations for returned rows, within a bounded budget (mode=search or citations).Default false
    includePaperDetailsInclude Paper DetailsbooleanFetch journal, volume, pages, publisher, and abstract for each author publication (mode=authorProfile).Default false

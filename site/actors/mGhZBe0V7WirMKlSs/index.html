Wallapop Listings by Keyword, Item & Seller

Wallapop is one of the largest second-hand marketplaces in Spain, Italy, and Portugal. This actor reads its public listing data three ways: search by keyword near a location, fetch a specific item by URL or ID, or pull every active listing from one seller.

What this actor does

  • Searches Wallapop listings by keyword, centered on a latitude/longitude point, with sort order, price range, and category filters.
  • Fetches full details for one or more specific items by URL or item ID.
  • Pulls every listing currently posted by a given seller's user ID.
  • Reports distance from your search center for each result, so you can gauge how local a match is.
  • Any field a listing doesn't have — such as GPS coordinates when a seller hasn't shared one, or a reserved flag when the item isn't reserved — is left out of that record.

Output per listing

Field Description
itemId Wallapop's unique identifier for the item
title, description Listing title and full description
price, currency Asking price and its currency (usually EUR)
seller, sellerId Seller's display name and user ID
city, country Where the item is located
latitude, longitude Seller's coordinates, when shared
imageUrl, imageUrls Primary image, and the full list of listing images
itemUrl Direct link to the listing
categoryId Wallapop's numeric category ID for the listing
publishedDate, modifiedDate When the listing was created and last updated (Unix timestamps)
distanceM Distance from the search center, in meters, for search mode results
reserved true when the item is marked reserved
soldOutside true when the seller marked the item sold outside Wallapop
banned true when Wallapop has flagged the listing as banned
scrapedAt Collection timestamp

Input

Field Type Default Description
mode String (select) search search, itemDetails, or sellerListings.
keyword String iPhone Search keyword, used by search.
itemUrls Array [] Item URLs or item IDs to fetch, used by itemDetails.
sellerUserId String – Seller's user ID (from their profile URL), used by sellerListings.
latitude Number 40.4165 (Madrid) Center latitude for search.
longitude Number -3.7026 (Madrid) Center longitude for search.
orderBy String (select) newest newest, price_low_to_high, price_high_to_low, or most_relevance.
minPrice Integer – Minimum price in EUR.
maxPrice Integer – Maximum price in EUR.
category String (select) all One of Wallapop's category IDs: Electronics, Mobile phones, Cars & motorbikes, Clothing & accessories, Sports & leisure, Home & garden, Movies/books/music, Toys & games, Jobs.
maxItems Integer 20 Maximum listings to return (1-500).

Use cases

  • Price research — see what similar second-hand items are currently asking in the Spanish, Italian, or Portuguese markets.
  • Local inventory monitoring — track new listings for a specific product near a chosen location.
  • Seller auditing — pull everything a given seller currently has listed.
  • Category trend tracking — compare pricing across a category over repeated runs.
  • Lead sourcing — find sellers currently listing specific items for bulk or resale purchasing.

FAQ

Do I need an account or API key? No — Wallapop's listing data used here is publicly accessible without authentication.

Which countries does this cover? Primarily Spain, with Italy and Portugal also served by the same underlying marketplace.

How does location-based search work? search mode centers results on the latitude/longitude you provide (defaulting to Madrid) and reports each result's distanceM from that point.

How many results can one run return? Up to 500 per run via maxItems; Wallapop's own search pages typically return listings in batches that the actor pages through automatically.

Why would I see listing IDs starting with sample-? If a request returns no live results at all, the run still finishes with a small set of clearly labeled placeholder records (IDs like sample-001) instead of an empty dataset — treat those as a signal to retry rather than real listings.

What do category values correspond to? Each option maps to one of Wallapop's own numeric category IDs — Electronics, Mobile phones, Cars & motorbikes, Clothing & accessories, Sports & leisure, Home & garden, Movies/books/music, Toys & games, or Jobs.

Is this affiliated with Wallapop? No. This actor reads Wallapop's publicly accessible listing data and has no affiliation with Wallapop.

    Target Price, Stock & Deals Finder is an Apify Actor published by Dataspryva. It accepts 14 input fields, and mode is required. Each result can carry up to 14 declared fields, including title, brand, price, originalPrice, priceType and isOnSale. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per product”, “Input”, “Use cases” and “FAQ”.

    What you get

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search with a price ceiling). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 24, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Target Price, Stock & Deals Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch from Target.Default "search"; Allowed search, byCategory, byTcin, byUrl, deals
    querySearch querystringKeyword to search for (mode=search). E.g. 'iPhone case'.Default "iPhone case"
    tcinsTarget item numbers (mode=byTcin)arrayOne or more Target item numbers (TCINs), e.g. '94715153'. Comma-separated strings are also accepted.Default []
    categoryIdDepartment (mode=byCategory)stringTarget department to browse.Default "electronics"; Allowed electronics, clothing-women, clothing-men, toys, home, baby, beauty, food and 12 more
    urlTarget URL (mode=byUrl)stringA Target product, category, brand or search URL. E.g. 'https://www.target.com/p/item/-/A-12345678'.
    sortBySort orderstringHow Target should order results.Default "relevance"; Allowed relevance, featured, priceLow, priceHigh, ratingHigh, bestSeller, newest
    includeDetailsFetch full product detailsbooleanFetch each product page to add description, UPC/DPCI, category breadcrumbs, specifications, review counts and the online stock status Target publishes.Default true; Example false
    minPriceMin price (USD)numberDrop products cheaper than this price.Allowed 0 to 99999
    maxPriceMax price (USD)numberDrop products more expensive than this price.Allowed 0 to 99999
    minRatingMin ratingnumberDrop products with an average rating below this value (0–5).Allowed 0 to 5
    onSaleOnlyOn sale onlybooleanOnly emit products currently marked on sale or clearance.Default false
    inStockOnlyIn stock onlybooleanExclude products Target reports as out of stock. Search, department and deals listings that carry no stock signal are kept and marked UNKNOWN unless full-detail enrichment resolves them.Default true
    maxItemsMax itemsintegerHard cap on emitted records (1–1000). Target exposes up to 50 pages of 24 results per query.Default 24; Example 2; Allowed 1 to 1000
    maxPagesMax pagesintegerMaximum result pages to request per query (1–50; 24 products per page).Default 10; Example 1; Allowed 1 to 50

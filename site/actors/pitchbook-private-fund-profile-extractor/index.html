    PitchBook Private Fund Profile Extractor is an Apify Actor published by Dataspryva. It accepts 12 input fields, none of them required at the top level. Each result can carry up to 29 declared fields, including name, fundStrategy, fundStatus, fundSize, vintageYear and fundManager. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Three ways to collect funds”, “What you get per fund”, “Inputs”, “How the public data is reached”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    What it costs

    PitchBook Private Fund Profile Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    profileUrlsFund profile URLs or IDsarrayPitchBook fund profile links or bare IDs (for example https://pitchbook.com/profiles/fund/11295-73F or 11295-73F). When supplied, every listed fund is processed and the other source fields are ignored.Example ["11295-73F"]
    searchQueryKeyword searchstringFund name, manager or strategy keyword, for example 'Sequoia Capital Fund XV', 'growth equity' or 'buyout europe'. PitchBook's public best match is tried first, then public profiles are scanned for more matches. Used only when no profile URLs are supplied.
    maxItemsMaximum fundsintegerUpper limit on fund records returned. Direct-URL runs process every listed URL; search and sitemap runs stop once this many funds match.Default 3; Allowed 1 to 100000
    fundTypesFund typesarrayKeep only funds whose published strategy matches one of these types. Leave empty for all types.Allowed Agriculture, Angel Fund, Bridge Financing, Buyout, Co-Investment, Collateralized Loan Obligation (CLO), Credit Special Situations, Debt - General and 33 more
    fundStatusesFund statusesarrayKeep only funds in one of these lifecycle states, for example Liquidated or Open.Allowed Cancelled, Closed, Evergreen, Fully Invested, Liquidated, Open, Open (First Close), Open (Interim Close) and 3 more
    fundCategoriesFund categoriesarrayKeep only funds in one of these asset classes.Allowed Co-Investment - General, Debt, Fund of Funds - General, Other, Private Equity, Real Assets, Secondaries - General, Venture Capital
    countriesCountries or regionsarrayKeep funds whose country or domicile contains any of these names, for example United States, Europe or Germany.

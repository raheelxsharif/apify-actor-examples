    Instagram Comments Scraper for Reels & Posts is an Apify Actor published by Dataspryva. It accepts 5 input fields, and postUrls is required. Each result can carry up to 23 declared fields, including status, postUrl, postShortcode, commentId, text and commentType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.30 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per comment”, “Input”, “Authentication”, “Good to know” and “Example output”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 23 fields in 1 dataset view. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (all comments and replies on one post). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxCommentsPerPost (default 100, maximum 100000) and maxRepliesPerComment (default 20, maximum 1000) cap how many results a run collects, and so what it costs.

    What it costs

    Instagram Comments Scraper for Reels & Posts uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 5 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    postUrlsInstagram Post URLsarray requiredInstagram post, reel or IGTV URLs to scrape comments from. Accepts /p/, /reel/, /reels/, /tv/, and canonical username/p/shortcode formats. Duplicates are silently de-duplicated. A bare shortcode also works.Example ["https://www.instagram.com/p/DRaAMuaiTZR/"]
    maxCommentsPerPostMax Comments Per PostintegerMaximum number of comments to read per post (1-100,000). Replies are read in addition to this number. Reading 100,000 comments takes about an hour.Default 100; Allowed 1 to 100000
    includeRepliesInclude RepliesbooleanAlso read the replies under each comment. Instagram lists replies only to a signed-in visitor, so this needs the cookies below; without them the comments are read and the log says that no replies are read.Default true
    maxRepliesPerCommentMax Replies Per CommentintegerMaximum number of replies to read per comment thread (1-1,000), when Include Replies is on. For example, 5 means at most 5 replies per comment.Default 20; Allowed 1 to 1000
    cookiesInstagram Cookies (Optional)stringOptional. Your own Instagram cookies as JSON. They are needed to read replies, and for posts that a visitor who is not signed in cannot open (a private account you follow, an age check). Leave empty to read the comments of public posts. Format: [{"name":"sessionid","value":"...","domain":".instagram.com"}, ...]

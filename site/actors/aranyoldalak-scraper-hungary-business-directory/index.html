    What it costs

    AranyOldalak Scraper - Hungary Business Directory uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    FieldTypeDescription
    modeModestring requiredWhat to fetch: search a business category in a city/county, or fetch full business profiles from direct aranyoldalak.hu URLs.Default "search"; Allowed search, detail
    categoryCategorystringBusiness category / type to search for. Pick a common category, or choose 'Custom category' and type your own below (mode=search). Values use proper Hungarian spelling/diacritics -- aranyoldalak.hu's own search matching relies on them.Default "étterem"; Allowed custom, étterem, pizzéria, cukrászda, kávézó, gyorsétterem, szálloda, panzió and 63 more
    customCategoryCustom category (overrides selection above)stringFree-text business category/type not in the curated list above, e.g. 'kulcsmásolás' or 'dohánybolt' (mode=search). Takes priority over 'Category' when set. aranyoldalak.hu resolves this like its own search box, so most Hungarian business-type terms work -- use proper Hungarian diacritics for best matching.
    locationCity or countystringHungarian city or county (megye) to search in. Pick one, or choose 'Custom location' and type your own below (mode=search).

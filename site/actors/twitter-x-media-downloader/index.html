    Twitter (X) Media Downloader is an Apify Actor published by Dataspryva. It accepts 18 input fields, none of them required at the top level. Each result can carry up to 34 declared fields, including tweetUrl, uploaderUsername, mediaType, filename, fileSizeBytes and width. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Services”, “How it works”, “Input”, “Output” and “Usage cost”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 34 fields in 2 dataset views. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (download two posts). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPostsPerUser (default 20, maximum 1000) and maxItems (default 100, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Twitter (X) Media Downloader uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    postUrlsPost links or IDsarrayPaste links of posts to download media from. Accepts x.com and twitter.com links, i/web/status links, or bare post IDs. Optional if you provide usernames or profile links below.Example ["https://x.com/NASA/status/2107095768821576019"]
    usernamesUsernames or profile links to scanarrayScan a profile's media posts and download their photos, videos and GIFs. Type handles with or without @, or paste full profile links. Optional if you provide post links above.Example []
    maxPostsPerUserMaximum media posts to check per usernameintegerHow many of each profile's most recent media posts to look at. Posts without matching media or filtered-out posts are skipped.Default 20; Example 1; Allowed 1 to 1000
    maxItemsMaximum media files to collectintegerHard cap on dataset rows for the whole run. The actor stops collecting and downloading once this many files are emitted.Default 100; Example 1; Allowed 1 to 10000
    mediaTypesMedia types to downloadarrayChoose which kinds of media to download. All types are selected by default.Default ["video", "photo", "gif"]; Allowed video, photo, gif
    imageQualityPhoto qualitystringQuality to use for photos (and video poster images). Original is the full-resolution file posted on X.Default "orig"; Allowed orig, large, medium, small
    videoQualityVideo qualitystringPreferred video resolution. The actor picks the closest available quality when the exact one is not offered.Default "best"; Allowed best, 2160p, 1080p, 720p, 480p, worst
    downloadAllQualitiesDownload every video qualitybooleanEmit and download one separate file for every progressive MP4 quality X offers (for example 1080p, 720p, 480p) instead of only the preferred one. Every quality gets its own row, filename and download link.Default false
    includePosterImageAlso save video poster imagesbooleanSave the thumbnail/poster image of each video or GIF as an additional photo file.Default true; Example false
    includeAltTextInclude image alt textbooleanAttach the alt text (image description) X stores for each photo or video thumbnail to the media row.Default true
    audioOnlyAudio only (extract sound from videos)booleanDownload only the audio track of videos. Photos and GIFs are skipped. Files are extracted with ffmpeg and file saving is enabled automatically.Default false
    audioFormatAudio file formatstringFormat used when Audio only is on.Default "m4a"; Allowed m4a, mp3

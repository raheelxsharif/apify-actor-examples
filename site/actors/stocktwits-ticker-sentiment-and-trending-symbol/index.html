    StockTwits Ticker Sentiment & Trending Symbol Feed is an Apify Actor published by Dataspryva. It accepts 19 input fields, and mode is required. Each result can carry up to 12 declared fields, including recordType, symbol, title, sentiment, sentimentScore and priceLast. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record type”, “Input”, “Use cases”, “FAQ” and “Use it as an API (server mode)”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (latest tagged sentiment on several tickers). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 30, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    StockTwits Ticker Sentiment & Trending Symbol Feed uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 19 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch from StockTwits.Default "symbolMessages"; Allowed symbolMessages, userMessages, trendingSymbols, marketMessages, symbolSentiment, symbolOverview, priceHistory, search and 3 more
    symbolsTickers (mode=symbolMessages / symbolSentiment / symbolOverview / priceHistory)arrayTickers to fetch, e.g. AAPL, TSLA, BTC.X, BRK.B, SHOP.TSX. Accepts $cashtags and StockTwits symbol URLs. Use .X for crypto.Default ["AAPL"]
    usernamesUsernames (mode=userMessages)arrayStockTwits usernames without @, or profile URLs, e.g. KirRoyalTrader, https://stocktwits.com/Fibonaccino.Default []
    searchQueriesSearch queries (mode=search)arrayCompany names, tickers, or trader names to search for, e.g. tesla, apple, TraderLion.Default []
    searchTypeSearch type (mode=search)stringWhat to return from each query.Default "all"; Allowed all, symbols, users
    streamFilterMessage sort (mode=symbolMessages)stringAll = newest first, Top = StockTwits ranking, Trending = curated high-engagement posts for the ticker (up to 100).Default "all"; Allowed all, top, trending
    contentFilterContent filter (message modes)stringKeep only messages with this attachment. Videos are rare; All keeps every message.Default "all"; Allowed all, links, charts, videos
    sentimentFilterSentiment filter (message modes)stringKeep posts by the author's self-tagged sentiment. Most posts are untagged; Any keeps all.Default "any"; Allowed any, bullish, bearish, tagged
    onlyPriceTargetsOnly price predictions (message modes)booleanKeep only messages where the author attached a StockTwits price prediction (price target).Default false
    feedTypeMarket feed (mode=marketMessages)stringTrending = market-wide trending posts; Suggested = posts from StockTwits' curated suggested traders; All = public market-wide firehose (deep, chronological).Default "trending"; Allowed trending, suggested, all
    trendingAssetClassAsset class (mode=trendingSymbols)stringWhich trending instruments to keep. All includes stocks, ETFs, crypto, ADRs, commodities, and other classes.Default "all"; Allowed all, stocks, etf, crypto, adr, commodity
    sentimentRangeSentiment range (mode=symbolSentiment)stringNow = current sentiment across 15m, 24h, now, 1D–ALL. Other values return the daily/intraday history for that window.Default "now"; Allowed now, 1D, 1W, 1M, 3M, 6M, 1Y, 5Y and 1 more

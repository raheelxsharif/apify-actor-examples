    Crypto Market Sentiment Index Tracker is an Apify Actor published by Dataspryva. It accepts 7 input fields, and mode is required. Each result can carry up to 7 declared fields, including date, value, valueClassification, source, timeframe and timestamp. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Why this actor”, “Modes”, “Input”, “Output per reading”, “Source coverage and methodology” and “Use cases”.

    What it costs

    Crypto Market Sentiment Index Tracker uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 7 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: the current reading, the last N readings, or a custom date range.Default "latest"; Allowed latest, historical, dateRange
    sourceIndex sourcestringWhich publisher to read. alternative.me has daily history since 2018; CoinMarketCap since 2023 with BTC price and volume; CFGI has daily history since 2022 plus short rolling 4h/1h/15m windows, a 10-component breakdown and market cap.Default "alternativeMe"; Allowed alternativeMe, coinmarketcap, cfgi
    timeframeCFGI timeframestringReading interval for the CFGI source only: daily, 4-hour, hourly or 15-minute. CFGI intraday history is a short rolling window; other sources always return daily readings.Default "1d"; Allowed 1d, 4h, 1h, 15m
    limitNumber of readings (historical)integerHow many of the most recent readings to return in historical mode. One reading per day for daily sources.Default 30; Allowed 1 to 5000
    startDateStart date (date range)stringInclusive start of the range, e.g. 2024-01-01. Slash dates and US dates are also accepted (mode=dateRange).
    endDateEnd date (date range)stringInclusive end of the range, e.g. 2024-12-31 (mode=dateRange).
    classificationFilterClassification filterstringKeep only readings in one sentiment band (historical and dateRange modes). Leave empty to keep every band.Allowed , Extreme Fear, Fear, Neutral, Greed, Extreme Greed

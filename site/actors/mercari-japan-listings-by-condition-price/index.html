    Mercari Japan Listings by Condition, Price & Status is an Apify Actor published by Dataspryva. It accepts 16 input fields, none of them required at the top level. Each result can carry up to 8 declared fields, including name, price, currency, condition, status and brandName. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Use cases” and “FAQ”.

    What you get

    What it costs

    Mercari Japan Listings by Condition, Price & Status uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringHow to find listings.Default "search"; Allowed search, byUrl, shop
    keywordKeywordstringSearch term, in Japanese or English (mode=search).Example "Nintendo Switch"
    startUrlsMercari URLsarraySearch, item or shop links to scrape (mode=byUrl). Mixing link types is fine.
    shopMercari Shops ID or URLstringShop ID, storefront URL or shop product URL (mode=shop).
    statusListing statusstringOn sale, exact sold out, trading, sold (sold out plus trading, the site's sold filter), or all.Default "on_sale"
    conditionItem conditionstringFilter by Mercari's six condition grades.Default "any"
    sortBySort bystringResult order.Default "default"; Allowed default, created_time, price_asc, price_desc, num_likes
    categoryCategorystringCategory name, path or numeric ID, e.g. ゲーム・おもちゃ・グッズ > テレビゲーム or 7002.
    brandBrandstringBrand name (Japanese or English) or numeric ID, e.g. Nintendo, 任天堂 or 15487.
    sizeSizestringMercari size filter. The group name is shown before each size.Default "any"; Allowed any, 153, 154, 2, 3, 4, 5, 155 and 123 more
    sellerTypeSeller typestringIndividual sellers, Mercari Shops, or both.Default "any"; Allowed any, individual, shop
    excludeKeywordExclude keywordstringDrop listings whose title contains this word. Applied by Mercari's search.

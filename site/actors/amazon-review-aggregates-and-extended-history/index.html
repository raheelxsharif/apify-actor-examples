    Amazon Review Aggregates & Extended History Scraper is an Apify Actor published by Dataspryva. It accepts 17 input fields, none of them required at the top level. Each result can carry up to 28 declared fields, including productAsin, reviewedProductAsin, ratingScore, reviewTitle, reviewDescription and isVerified. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per review”, “Output per product (rating aggregate)”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 28 fields in 1 dataset view, and the README documents 10 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (extended history for one product). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxProductsToDiscover (default 10, maximum 50) caps how many results a run collects, and so what it costs.

    What it costs

    Amazon Review Aggregates & Extended History Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 17 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    productUrlsProduct URLsarrayList of Amazon product URLs to scrape reviews from. Supports /dp/, /gp/product/, /gp/aw/d/ and /product/ URL formats across 19+ Amazon domains. A bare 10-character ASIN (e.g. "B09X7MPX8L", no URL) is also accepted -- it is expanded into a full URL using the country domain below. Leave empty and use keywords/categoryUrls instead to discover products automatically.Example ["https://www.amazon.com/dp/B09X7MPX8L"]
    keywordsKeywords (auto-discover products)arraySearch keywords used to auto-discover products when productUrls is empty (e.g. "wireless earbuds"). Fetches Amazon's public /s?k= search results page for each keyword and reviews up to maxProductsToDiscover resulting products.Default []
    categoryUrlsCategory / Search URLs (auto-discover products)arrayAdvanced mode: supply your own Amazon /s?... or /b?node=... category/search URL(s) directly (used only when productUrls is empty). Products are discovered the same way as keywords.Default []
    maxProductsToDiscoverMax Products to DiscoverintegerMaximum number of products to discover per run from keywords/categoryUrls. Ignored when productUrls is supplied directly.Default 10; Allowed 1 to 50
    extendedHistoryExtended Review HistorybooleanMerge Amazon's public extended review feed for each ASIN (no login, no cookie): up to 100 reviews per star/sort bucket, and walking every bucket yields 100-850+ unique reviews for popular US products, deduplicated against the product-page sample. Coverage varies by ASIN (some products expose few or no rows) and the feed carries Amazon.com reviews only; when off, only the ~8-13 product-page top reviews are returned.Default true
    mergeMarketplacesMerge Extra MarketplacesarrayAdditional Amazon marketplaces whose product page is fetched for the same ASIN and whose reviews are merged (deduplicated by review ID and content). Each marketplace typically adds a handful of locally-written reviews. Empty = only the product's own marketplace.Default []; Allowed amazon.com, amazon.co.uk, amazon.de, amazon.fr, amazon.it, amazon.es, amazon.ca, amazon.com.au and 11 more
    includeAggregatesInclude Review AggregatesbooleanEmit one additional amazon_review_aggregate record per product with the product title, average rating, global ratings count, star histogram (plus derived per-star counts), and "Customers say" AI summary with aspects -- parsed from the same page HTML already fetched. These widgets render server-side even when individual review cards are gated, so this record is available more reliably than the reviews themselves.Default true
    countryAmazon DomainstringAmazon country domain to scrape from. URLs from a different domain are honored automatically.Default "amazon.com"; Allowed amazon.com, amazon.co.uk, amazon.de, amazon.fr, amazon.it, amazon.es, amazon.ca, amazon.com.au and 11 more
    maxReviewsMax Reviews per ProductintegerHard cap on the number of reviews returned per product AFTER merging and deduplication (1-2000). The product-page sample alone yields ~8-13; the extended review feed can add 100-850+ for popular US products.Default 100; Example 15; Allowed 1 to 2000
    sortBySort Reviews BystringHow to sort the returned reviews: most helpful first, or most recent first.Default "helpful"; Allowed helpful, recent
    filterByStarFilter by Star RatingstringKeep only reviews with this rating. positive keeps 4-5 star reviews; critical keeps 1-2 star reviews. Applied to the merged set, so narrow filters can legitimately return few or no rows.Default ""; Allowed , 1, 2, 3, 4, 5, positive, critical
    verifiedPurchasesOnlyVerified Purchases OnlybooleanKeep only reviews carrying Amazon's Verified Purchase badge. Applied server-side for the extended feed and client-side for product-page rows.Default false

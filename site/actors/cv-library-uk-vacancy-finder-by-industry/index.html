    CV-Library UK Vacancy Finder by Industry & Location is an Apify Actor published by Dataspryva. It accepts 14 input fields, and mode is required. Each result can carry up to 10 declared fields, including jobTitle, companyName, location, salary, salaryAnnualMin and salaryAnnualMax. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    CV-Library UK Vacancy Finder by Industry & Location uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to scrapestring requiredSearch by keyword and location, browse one industry sector, or scrape specific CV-Library URLs.Default "searchJobs"; Allowed searchJobs, searchByIndustry, searchByUrl
    querySearch keywordsstringJob title, skill or phrase for mode=searchJobs, for example 'software developer' or 'registered nurse'.Default "software developer"
    locationUK locationstringTown, city, county or postcode, for example 'London', 'Manchester' or 'M1'. Leave blank for UK-wide results.Default "London"
    industryIndustry sectorstringSector to browse for mode=searchByIndustry. The location field still narrows it when set.Default "it"; Allowed it, engineering, finance, healthcare, sales, marketing, hr, legal and 27 more
    startUrlsCV-Library URLsarrayFor mode=searchByUrl: paste CV-Library search, industry or job URLs, for example 'https://www.cv-library.co.uk/software-developer-jobs-in-london'.Default []
    jobTypeJob typestringKeep only one employment type. CV-Library does not allow filter query strings for anonymous clients, so the actor filters matches itself.Default ""; Allowed , permanent, contract, temporary, part-time, full-time, apprenticeship
    remoteOnlyRemote jobs onlybooleanUse CV-Library's remote search path and keep only remote or work-from-home listings.Default false
    postedWithinDaysPosted withinstringKeep jobs posted in this many days. 0 means any date.Default "0"; Allowed 0, 1, 3, 7, 14, 30
    salaryMinMinimum salary (GBP)integerAnnual salary floor in pounds. Hourly, daily and weekly pay is annualised before comparison. Listings without a parseable salary are excluded when either salary bound is set.Allowed 0 to 500000
    salaryMaxMaximum salary (GBP)integerAnnual salary ceiling in pounds. Applied to the annualised range.Allowed 0 to 500000
    sortBySort resultsstringSort the jobs collected for this run before they are saved.Default "relevance"; Allowed relevance, newest, salaryHigh, salaryLow
    includeDetailsFetch full job detailsbooleanOpen each job page for the full description and structured pay fields. Turn off for a faster listing-only run.Default true
    maxItemsMaximum jobsintegerHard cap on saved job records.Default 50; Example 3; Allowed 1 to 1000
    maxPagesMaximum result pagesintegerSafety cap on result pages fetched per search. Raise it to reach deeper results; 20 jobs are shown per page.Default 50; Example 5; Allowed 1 to 100

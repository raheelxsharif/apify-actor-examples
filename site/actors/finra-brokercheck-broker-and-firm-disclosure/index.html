    FINRA BrokerCheck Broker & Firm Disclosure Lookup is an Apify Actor published by Dataspryva. It accepts 12 input fields, and mode is required. Each result can carry up to 17 declared fields, including fullName, firmName, recordType, scope, disclosureCount and currentEmploymentCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    FINRA BrokerCheck Broker & Firm Disclosure Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to search or fetch on FINRA BrokerCheck.Default "searchBrokers"; Allowed searchBrokers, firmSearch, searchByState, disclosureSearch, brokerProfiles, firmProfiles
    nameBroker name or CRDstringBroker name (full or partial), CRD number or BrokerCheck individual URL. Used by searchBrokers, searchByState and disclosureSearch; also accepted as a firmSearch fallback.Default "John Smith"
    firmNameFirm name or CRDstringFirm name (full or partial), CRD number or BrokerCheck firm URL (mode=firmSearch).
    firmNameOrCrdEmployer firm filterstringOptional firm name or CRD. Constrains broker searches to people currently employed at that firm; leave name empty to scan the firm's representatives (modes=searchBrokers, searchByState, disclosureSearch).
    crdNumbersCRDs or profile URLsarrayCRD numbers or BrokerCheck profile URLs to fetch (modes=brokerProfiles, firmProfiles). Up to 1,000 entries; duplicates are removed.Default []
    stateRegistered statestringUS state filter. Required for searchByState; optional for broker and firm searches. FINRA matches records with a registration or employment location in this state, so it can be broader than the current office state.Default ""; Allowed , AL, AK, AZ, AR, CA, CO, CT and 44 more
    statusRegistration statusstringActively registered, previously registered, barred (brokers) or expelled (firms).Default "all"; Allowed all, active, previouslyRegistered, barred, expelled
    disclosuresOnlyDisclosures onlybooleanOnly emit brokers or firms with at least one broker-dealer or investment-adviser disclosure flag on file.Default false
    includePreviousInclude previous employersbooleanInclude previous employment history in broker search results and profile records.Default true
    enrichDetailsFetch full profile detailsbooleanFetch each record's full BrokerCheck profile (disclosures, exams, registrations, employment history). Adds one request per record.Default true; Example false
    includeDisclosuresInclude disclosure eventsbooleanInclude individual disclosure events with dates, allegations and sanctions when full profile details are fetched.Default true
    maxItemsMax itemsintegerMaximum number of records to emit.Default 20; Example 3; Allowed 1 to 1000

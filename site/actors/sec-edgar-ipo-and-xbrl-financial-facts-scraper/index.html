    SEC EDGAR IPO & XBRL Financial Facts Scraper is an Apify Actor published by Dataspryva. It accepts 9 input fields, and mode is required. Each result can carry up to 12 declared fields, including companyName, ticker, cik, formType, filingDate and description. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Four ways to use it”, “Input”, “Output”, “Examples”, “Use cases” and “Limits and data notes”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 25, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    SEC EDGAR IPO & XBRL Financial Facts Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch from SEC EDGAR.Default "searchFilings"; Example "browseIPOs"; Allowed searchFilings, getCompanyFilings, getCompanyFacts, browseIPOs
    querySearch querystringFull-text search query for mode=searchFilings. Supports phrases in quotes. Examples: "artificial intelligence", "going concern", "material weakness", "IPO".
    formTypeForm typestringSEC form type filter for searchFilings and getCompanyFilings. browseIPOs always uses S-1 (plus S-1/A when Include amendments is on).Default "all"; Example "S-1"; Allowed all, S-1, S-1/A, S-3, S-4, F-1, F-1/A, 10-K and 16 more
    dateStartDate from (YYYY-MM-DD)stringOnly include filings filed on or after this date. Applies to searchFilings, browseIPOs and getCompanyFilings.
    dateEndDate to (YYYY-MM-DD)stringOnly include filings filed on or before this date. Applies to searchFilings, browseIPOs and getCompanyFilings.
    cikOrTickerCompany CIK or tickerstringStock ticker (AAPL, MSFT, GOOGL) or SEC CIK (0000320193). Required for getCompanyFilings and getCompanyFacts; optional company filter for searchFilings and browseIPOs.
    includeAmendmentsInclude amendmentsbooleanFor browseIPOs, also include S-1/A amendment filings alongside new S-1 registrations.Default false
    factTaxonomyXBRL taxonomystringFor getCompanyFacts, choose which XBRL taxonomy to return.Default "all"; Allowed all, us-gaap, dei
    maxItemsMax itemsintegerMaximum number of records to return. SEC full-text search caps at 10,000 results.Default 25; Example 3; Allowed 1 to 10000

    Official MLB Team, Schedule & Stat Line Scraper is an Apify Actor published by Dataspryva. It accepts 18 input fields, and mode is required. Each result can carry up to 12 declared fields, including recordType, playerName, teamName, gamePk, officialDate and statGroup. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Output per record type”, “Input”, “Examples” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 12 fields in 1 dataset view. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a team's roster with season stats). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Official MLB Team, Schedule & Stat Line Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch. Nine modes cover teams, players/rosters, player stats, game logs, schedules, standings, box scores, leaders, and reference data.Default "getPlayerStats"; Example "getPlayers"; Allowed getTeams, getPlayers, getPlayerStats, getGameLog, getSchedule, getStandings, getBoxscore, getLeaders and 1 more
    seasonsSeasonsarraySeason years, e.g. 2024 or 2025. Leave empty for the current season. Stats cover 1876 onward; schedules cover 1901 onward. Multiple seasons can be fetched in one run (mode=getTeams, getPlayers, getPlayerStats, getSchedule, getStandings, getLeaders, getReference).Default []
    teamIdsTeamsarrayFilter by MLB team IDs (147 = Yankees), team names (Yankees), abbreviations (NYY), or team URLs (https://www.mlb.com/yankees). Leave empty for all teams. Used by teams, players, player stats, schedule, standings, box score, and leaders modes.Default []
    playerIdsPlayer IDsarrayMLB player IDs, e.g. 660271 for Shohei Ohtani. Used by players, player stats, and game log modes. Use Search query to find a player ID by name.Default []
    gamePksGame IDsarrayMLB game IDs (gamePk), e.g. 822974. Used by mode=getBoxscore. Leave empty to derive games from seasons, dates, or teams.Default []
    startDateStart datestringStart date in YYYY-MM-DD format. Used by schedule, box score, and player stats (statType=byDateRange). A single date can be set in either date field.
    endDateEnd datestringEnd date in YYYY-MM-DD format. Used by schedule, box score, and player stats (statType=byDateRange).
    statGroupStat groupstringWhich stat category to return for players, player stats, game logs, box scores, and leaders.Default "hitting"; Allowed hitting, pitching, fielding
    statTypeStat typestringScope for mode=getPlayerStats. Season, career, and date-range stats work for the whole player pool; season-by-season, month, day-of-week, and home/away splits require playerIds or teamIds.Default "season"; Allowed season, career, yearByYear, byMonth, byDayOfWeek, homeAndAway, byDateRange
    rosterTypeRoster typestringWhich roster to return for mode=getPlayers when teamIds is set.Default "active"; Allowed active, 40Man, fullSeason, depthChart, coach
    searchQuerySearch querystringFind players by name for mode=getPlayers, e.g. Ohtani or Aaron Judge. Returns up to 50 matching players.
    leagueIdLeaguestringFilter standings and leaders to the American League, National League, or both.Default "both"; Allowed both, AL, NL

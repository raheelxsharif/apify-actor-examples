    Executive Moves Tracker: Appointments & Departures is an Apify Actor published by Dataspryva. It accepts 16 input fields, none of them required at the top level. Each result can carry up to 15 declared fields, including personName, newTitle, companyName, companyDomain, companyTicker and moveType. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Inputs”, “Output fields”, “How de-duplication works”, “Data sources and limits” and “Example inputs”.

    What it costs

    Executive Moves Tracker: Appointments & Departures uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 16 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringMonitor companies: moves for the companies you list. Market feed: all moves in a date range. People: reported moves for specific names.Default "marketFeed"; Allowed companyMonitor, marketFeed, people
    companiesCompanies (companyMonitor)arrayCompany names, domains, tickers, SEC CIKs or UK company numbers. Examples: apple.com, Monzo Bank Limited, AAPL, 0000320193, 09446231.Default []
    peoplePeople (people mode)arrayPerson names to look up in SEC filings, Companies House officer records and press releases.Default []
    dateFromDate fromstringStart date (inclusive) in YYYY-MM-DD format. Leave empty to use the lookback window.
    dateToDate tostringEnd date (inclusive) in YYYY-MM-DD format. Leave empty for today.
    lookbackDaysLookback daysintegerUsed when Date from is empty: how many days back to scan.Default 7; Example 3; Allowed 1 to 3650
    countryCountrystringFilter moves by company country. SEC sources are US; Companies House is GB; press and leadership pages use the site's country when it can be inferred.Default "any"; Allowed any, US, GB
    industryIndustrystringFilter by broad industry sector derived from the company's SEC SIC code.Default "any"; Allowed any, technology, financials, healthcare, energy, industrials, consumer, realEstate and 3 more
    roleLevelRole levelstringFilter by seniority inferred from the new or previous title.Default "any"; Allowed any, board, cLevel, vp, director
    moveTypeMove typestringFilter by the type of leadership move.Default "any"; Allowed any, appointment, departure, promotion, retirement, interim
    sourcesSourcesarrayWhich public sources to query. SEC sources work in all modes; Companies House and leadership pages work in companyMonitor (Companies House also in people mode); press releases work in all modes.Default ["sec8k", "secForm3"]; Example ["secForm3"]; Allowed sec8k, secForm3, secForm4, companiesHouse, pressReleases, leadershipPages
    leadershipPagesLeadership page URLsarrayOptional leadership/team page URLs for companyMonitor. Leave empty to auto-discover common paths on each company domain.Default []

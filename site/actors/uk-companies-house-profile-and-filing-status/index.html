    UK Companies House Profile & Filing Status Scraper is an Apify Actor published by Dataspryva. It accepts 15 input fields, and mode is required. Each result can carry up to 19 declared fields, including companyNumber, companyName, companyType, companyStatus, dateOfCreation and jurisdiction. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Search filters and pagination”, “Output fields”, “Input reference”, “Example inputs” and “Use cases”.

    What it costs

    UK Companies House Profile & Filing Status Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 15 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to collect: search results, full company profiles, officers, or filing history.Default "searchCompanies"; Allowed searchCompanies, getCompanyProfile, getCompanyOfficers, getFilingHistory, getCompanyDetail
    apiKeyCompanies House API Key (optional)stringOptional free key from developer.company-information.service.gov.uk. It adds structured addresses, jurisdiction, and overdue flags. Without a key the actor uses the public website and still returns companies, officers, and filings.
    searchQueryCompany Name or KeywordsstringCompany name or keyword to search for, e.g. 'Tesco', 'consulting', or 'renewable energy'.Example "tesco"
    companyNumbersCompany Numbers or Profile URLsarrayRegistration numbers or Companies House profile links, e.g. ['00445790'] or ['https://find-and-update.company-information.service.gov.uk/company/00445790']. Used by the three lookup modes.
    companyStatusCompany Status FilterstringLimit search results to one register status. Leave as All statuses to include every status.Default ""; Allowed , active, dissolved, open, closed, converted-closed, removed, receivership and 4 more
    companyTypeCompany Type FilterstringLimit search results to one legal form. Leave as All types to include every form.Default ""; Allowed , ltd, plc, llp, limited-partnership, private-limited-guarant-nsc, private-limited-guarant-nsc-limited-exemption, private-limited-shares-section-30-exemption and 22 more
    registeredOfficeAddressRegistered Office LocationstringFilter by all or part of a registered office address, e.g. 'Welwyn Garden City' or 'Cardiff'.
    sicCodeSIC CodestringFilter by one 5-digit Standard Industrial Classification code, e.g. '62012' for computer programming.
    incorporatedFromIncorporated FromstringEarliest incorporation date (YYYY-MM-DD).
    incorporatedToIncorporated TostringLatest incorporation date (YYYY-MM-DD).
    dissolvedFromDissolved FromstringEarliest dissolution date (YYYY-MM-DD). Companies House only shows dissolutions since 2010.
    dissolvedToDissolved TostringLatest dissolution date (YYYY-MM-DD).
    officerStatusOfficer StatusstringIn officers mode, return all appointments, only current officers, or only resigned officers.Default "all"; Allowed all, active, resigned
    filingCategoryFiling CategorystringIn filing-history mode, limit records to one category. Leave as All filings to return everything.Default ""; Allowed , accounts, capital, charges, confirmation-statement, incorporation, officers
    maxItemsMax ItemsintegerMaximum number of company, officer, or filing records to return across all supplied company numbers.Default 25; Example 3; Allowed 1 to 5000

    Dailymotion Video Discovery by Topic & Channel is an Apify Actor published by Dataspryva. It accepts 17 input fields, and mode is required. Each result can carry up to 8 declared fields, including recordType, title, ownerUsername, views, likes and duration. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video”, “Output per channel (mode = searchUsers)”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Dailymotion Video Discovery by Topic & Channel uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    sortBySort orderstringResult order. Values apply where the Dailymotion API supports them: relevance needs mode=search/searchUsers; popular is mode=searchUsers only; old/id-asc are not available in trending mode. Unsupported values fall back to the mode's default order and the run note says so. Runs with maxItems above 1,000 always use a recent/old time-ordered sweep.Default "relevance"; Allowed relevance, recent, trending, visited, visited-hour, visited-today, visited-week, visited-month and 4 more

    liveOnlyLive streams onlybooleanOnly include live streams instead of on-demand videos.Default false
    tagTag filterstringOnly include videos carrying this tag (mode=search, byTopic, byUser, byPlaylist). Example: jazz.
    createdAfterPublished afterstringOnly include videos published on or after this date, as YYYY-MM-DD (mode=search, trending, byTopic, byUser). Long ranges are fetched automatically in overlapping windows. Dailymotion applies date filters in ~5-minute buckets, so a day boundary can include up to five minutes of neighbouring content.

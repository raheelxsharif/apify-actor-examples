Meetup & Lu.ma Event Finder by City, Group & Calendar

Search, browse, or look up events on Meetup and Lu.ma by city, group, or calendar: dates, venue, organizer, attendee count, photo and RSVP status from one actor and input shape.

Meetup & Lu.ma Event Finder by City, Group & Calendar is an Apify Actor published by Dataspryva. It accepts 26 input fields, and platform and mode are required. Its build declares a results dataset with 1 view. Runs happen on Apify, where the Store page lists the current price.

Meetup & Lu.ma Event Finder by City, Group & Calendar

Meetup and Lu.ma host two very different event ecosystems. This actor reads both from one input shape: search by keyword and city, browse a group or calendar, open a specific event URL, or discover what is happening around a city — with pagination, filters, and rich event details.

What this actor does

  • One actor, two platforms — set platform to meetup or luma and reuse the same fields
  • Eight intent modes — keyword search, event lookup, group profile, group/calendar event lists, nearby discovery, trending discovery, and URL auto-routing
  • Full result pages — Meetup cursor pagination and Lu.ma cursor pagination, not just the first page
  • Useful filters — dates, event format, radius, minimum attendance, free-only, category, and sort order
  • Rich records — venue and coordinates, group size, topics, hosts, prices, ticket tiers, and RSVP/guest counts
  • Optional enrichment — Meetup attendee names/photos and Lu.ma event descriptions/ticket tiers/featured guests, both off by default
  • Monitoring — onlyNewSinceLastRun remembers IDs for the same input and skips them next time
  • Clean data — empty fields are omitted at every depth; no null, "", [], or {}

No login, cookie, API key, or browser is required.

Modes

Mode Meetup Lu.ma
searchEvents Keyword search with location, dates, type, radius, category, attendance Keyword search, city feed, or category feed
byEvent Event URL, group/eventId URL, or numeric event ID Event URL (lu.ma or luma.com), slug, or evt-... ID
byGroup Group profile and stats Calendar/community profile
groupEvents Group's upcoming or past events Calendar's upcoming or past events
byCalendar Alias for groupEvents Calendar profile plus its events
discoverNearby Recommended events near a location/category City or nearest featured city feed
discoverTrending Recommended events by category/location Featured city/category feeds
byUrl Auto-routes event and group URLs Auto-routes event and calendar URLs

Output per Meetup event

  • id, name, url — event identity and link
  • startAt, endAt, timezone — scheduling (timezone falls back to the group's timezone)
  • description — full description from the event payload
  • eventType, rsvpState, status, waitlistMode — event state
  • imageUrl, imageId — event photo
  • guestCount, attendeeCount, waitlistCount, capacity — attendance and capacity
  • isFree, feeAmount, feeCurrency, feeAccepts, feeRequired — pricing
  • group, groupName, groupUrlname, groupMemberCount, groupCategory — group summary
  • venueName, venueAddress, city, state, country, postalCode, latitude, longitude, googleMapsUrl — venue
  • topics[] — topic id, name, and urlkey
  • hosts[] — host name and photo
  • attendees[] — optional public RSVP names/photos when includeAttendees is on (capped at 250)
  • seriesId, seriesName — recurring series, when present
  • recordType, platform, siteName, scrapedAt — record metadata

Output per Meetup group

  • id, name, urlname, url, timezone, description, photoUrl
  • foundedDate, city, state, country, latitude, longitude
  • memberCount, rating, ratingCount, isNewGroup
  • category, categoryId, categoryUrlkey, topics[]
  • organizer, socials — organizer profile and linked social accounts
  • upcomingEventCount, pastEventCount
  • memberSample[] — optional public members when includeMembers is on

Output per Lu.ma event

  • id, name, url, slug, startAt, endAt, timezone
  • description — full ProseMirror text on detail/enrichment
  • imageUrl, eventType, locationType, waitlistActive, hideRsvp
  • guestCount, ticketCount, isFree, feeAmount, maxFeeAmount, currency
  • ticketTiers[] — tier name, price, currency, type, spots remaining, registration count
  • isSoldOut, requireApproval, isNearCapacity, spotsRemaining, registrationAvailability
  • venues and location fields — venueName, fullAddress, venueAddress, city, state, country, latitude, longitude
  • hosts[], organizerName, featuredGuests[]
  • calendar, calendarName — calendar identity, socials, website, and location
  • categories[], featuredCity
  • recordType, platform, siteName, scrapedAt

Output per Lu.ma calendar

  • id, name, slug, url, description
  • avatarUrl, coverImageUrl
  • instagram, linkedin, twitter, website, socials
  • timezone, city, state, country
  • eventCount, subscriberCount, upcomingEventCount, pastEventCount
  • recordType (calendar or city), platform, siteName, scrapedAt

Output per error record

If a specific URL, slug, or event ID cannot be fetched or parsed, the actor emits an error record rather than silently dropping it:

  • recordType — error
  • platform, reason, source, httpStatus
  • url, slug, eventId, or groupUrlname — the identifier that failed
  • scrapedAt

FAQ

Is this affiliated with Meetup or Lu.ma? No. This is an independent actor that reads publicly available data from both platforms and is not operated by or affiliated with either.

Do I need an account, cookie, or API key? No. Every supported path works anonymously and cookielessly; nothing is required beyond the input fields.

Why does a Lu.ma keyword search stop at 50 results? Lu.ma's public keyword search is capped at 50 results per query. For more coverage, split the keyword into narrower terms or use a city or category feed, which supports cursor pagination.

Can I get past events? Yes for Meetup groups (groupEvents with eventPeriod: "past") and Lu.ma calendars (byCalendar, groupEvents, or eventPeriod). Meetup keyword search and Lu.ma city/category feeds do not expose past events.

Why are Lu.ma attendee names missing? Lu.ma only publishes counts, featured guests, and first-name previews. The full guest list requires a signed-in user with access to the event, so this actor returns counts and featured guests only.

Are Meetup attendee names public? On many events the public RSVP list is visible and can be included with includeAttendees. Some organizers hide it; in that case the field is omitted. Attendee data is opt-in and never part of the small default run.

Why are some prices or venues missing? Hosts can hide prices, and some events are online-only or use an obfuscated address. The actor reports only what the platform discloses; it never invents a price or address.

What happens if a request is blocked? The actor retries politely and, only after a real block, makes one automatic proxy retry. There is no proxy field to configure.

How many records can one run return? Up to maxItems (maximum 1000). Coverage depends on what the platform publishes for the query, city, group, or calendar.

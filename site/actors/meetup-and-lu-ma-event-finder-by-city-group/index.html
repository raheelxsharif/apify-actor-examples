    Meetup & Lu.ma Event Finder by City, Group & Calendar is an Apify Actor published by Dataspryva. It accepts 26 input fields, and platform and mode are required. Each result can carry up to 10 declared fields, including platform, recordType, name, startAt, venueName and city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Meetup and Lu.ma host two very different event ecosystems. This actor reads both from one input shape: search by keyword and city, browse a group or calendar, open a specific event URL, or discover what is happening around a city — with pagination, filters, and rich event details.

    What this actor does

    • One actor, two platforms — set platform to meetup or luma and reuse the same fields
    • Eight intent modes — keyword search, event lookup, group profile, group/calendar event lists, nearby discovery, trending discovery, and URL auto-routing
    • Full result pages — Meetup cursor pagination and Lu.ma cursor pagination, not just the first page
    • Useful filters — dates, event format, radius, minimum attendance, free-only, category, and sort order
    • Rich records — venue and coordinates, group size, topics, hosts, prices, ticket tiers, and RSVP/guest counts
    • Optional enrichment — Meetup attendee names/photos and Lu.ma event descriptions/ticket tiers/featured guests, both off by default
    • Monitoring — onlyNewSinceLastRun remembers IDs for the same input and skips them next time
    • Clean data — empty fields are omitted at every depth; no null, "", [], or {}

    No login, cookie, API key, or browser is required.

    Use cases

    • Build a combined Meetup + Lu.ma event feed for a city or topic
    • Track a community group's or calendar's upcoming and past schedule
    • Research venues, prices, hosts, and attendance before attending
    • Monitor new events for a saved search with onlyNewSinceLastRun
    • Compare how a topic is represented across both platforms

    Questions

    Is this affiliated with Meetup or Lu.ma?

    No. This is an independent actor that reads publicly available data from both platforms and is not operated by or affiliated with either.

    Do I need an account, cookie, or API key?

    No. Every supported path works anonymously and cookielessly; nothing is required beyond the input fields.

    Why does a Lu.ma keyword search stop at 50 results?

    Lu.ma's public keyword search is capped at 50 results per query. For more coverage, split the keyword into narrower terms or use a city or category feed, which supports cursor pagination.

    Can I get past events?

    Yes for Meetup groups (groupEvents with eventPeriod: "past") and Lu.ma calendars (byCalendar, groupEvents, or eventPeriod). Meetup keyword search and Lu.ma city/category feeds do not expose past events.

    Why are Lu.ma attendee names missing?

    Lu.ma only publishes counts, featured guests, and first-name previews. The full guest list requires a signed-in user with access to the event, so this actor returns counts and featured guests only.

    Are Meetup attendee names public?

    On many events the public RSVP list is visible and can be included with includeAttendees. Some organizers hide it; in that case the field is omitted. Attendee data is opt-in and never part of the small default run.

    Why are some prices or venues missing?

    Hosts can hide prices, and some events are online-only or use an obfuscated address. The actor reports only what the platform discloses; it never invents a price or address.

    What happens if a request is blocked?

    The actor retries politely and, only after a real block, makes one automatic proxy retry. There is no proxy field to configure.

    How many records can one run return?

    Up to maxItems (maximum 1000). Coverage depends on what the platform publishes for the query, city, group, or calendar.

    Meetup & Lu.ma Event Finder by City, Group & Calendar is an Apify Actor published by Dataspryva. It accepts 26 input fields, and platform and mode are required. Each result can carry up to 10 declared fields, including platform, recordType, name, startAt, venueName and city. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it costs

    Meetup & Lu.ma Event Finder by City, Group & Calendar uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

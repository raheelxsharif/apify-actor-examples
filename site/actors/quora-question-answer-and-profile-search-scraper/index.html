    Quora Question, Answer & Profile Search Scraper is an Apify Actor published by Dataspryva. It accepts 22 input fields, none of them required at the top level. Each result can carry up to 18 declared fields, including content_type, title, url, question_id, answer_id and author_name. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “How discovery works”, “Modes”, “What each row contains”, “Input reference”, “Example inputs” and “Use cases”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxRelatedQuestionsPerSeed (default 20, maximum 70), maxQuestionsPerQuery (default 50, maximum 500) and maxItems (default 200, maximum 50000) cap how many results a run collects, and so what it costs.

    What it costs

    Quora Question, Answer & Profile Search Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 22 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringSearch discovers questions through the DuckDuckGo index and Quora related questions. URLs is deterministic and does not depend on search.Default "search"; Example "urls"; Allowed search, urls, authors
    searchQueriesSearch KeywordsarrayTwo to four word phrases work best. Each query finds at most a couple of question seeds, then related questions expand the result.Default []
    searchTargetSearch TargetstringChoose whether keyword discovery looks for question pages, profile pages, or both. Profile search is best-effort because search engines index few Quora profiles.Default "questions"; Allowed questions, profiles, both
    directUrlsDirect Quora URLsarrayQuestion, answer, profile, or topic URLs. Language subdomains are accepted. Comma-separated or one URL per line.Default []; Example ["https://www.quora.com/What-is-Python-primarily-used-for"]
    usernamesProfile UsernamesarrayQuora profile usernames or slugs, with or without @ or a trailing slash. Each is normalised to a profile URL.Default []
    resultTypesResult TypesarrayWhich rows to save. Status and run-manifest rows are always emitted so blocked or empty sources stay visible.Default ["question", "answer", "search_result"]; Example ["question", "answer"]; Allowed question, answer, profile, author, topic, search_result
    includeAnswersInclude AnswersbooleanExpand question pages into answer rows. Turn off to keep question rows only.Default true
    maxAnswersPerQuestionMaximum Answers per QuestionintegerAnswers to collect from each question, including the 3-5 already visible on the page. Zero means no answers.Default 20; Example 2; Allowed 0 to 500
    expandRelatedQuestionsExpand Related QuestionsbooleanOpen related questions linked from each question page. Quora exposes up to 70, which is how keyword search reaches more than its first result.Default true; Example false
    maxRelatedQuestionsPerSeedRelated Questions per SeedintegerHow many related questions to open from each question page. Zero lists the links without opening them.Default 20; Example 0; Allowed 0 to 70
    maxQuestionsPerQueryMaximum Questions per QueryintegerHard cap on question rows for each search query, including seed and related questions.Default 50; Example 1; Allowed 1 to 500
    includeAuthorProfilesEnrich Authors with ProfilesbooleanOpen each discovered author's profile to add follower, answer, question, view, and join-date fields. Turn off to keep author rows from answer evidence only.Default true

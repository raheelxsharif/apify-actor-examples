    SimplyHired Job Search & Salary Parser is an Apify Actor published by Dataspryva. It accepts 18 input fields, and mode is required. Each result can carry up to 11 declared fields, including title, company, location, salary, salaryMin and salaryMax. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per job”, “Input”, “Examples”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 1 dataset view, and the README documents 20 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (keyword search with filters). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    SimplyHired Job Search & Salary Parser uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 18 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredWhat to fetch: search jobs on SimplyHired, or scrape specific SimplyHired URLs you already have.Default "search"; Allowed search, byUrl
    searchQueriesSearch queries (mode=search)arrayOne or more job titles, skills, or keywords. Each entry runs as its own search, e.g. registered nurse or python developer, remote. Ignored when Search URLs are provided.Default []; Example ["software engineer"]
    searchUrlsSimplyHired search URLs (mode=search)arrayFull SimplyHired search URLs, including any filters and a country domain (e.g. https://www.simplyhired.co.uk/search?q=nurse&l=London). When provided, these are used instead of the query, location and filter fields.Default []
    jobUrlsSpecific URLs (mode=byUrl)arraySimplyHired job URLs (https://www.simplyhired.com/job/...) or search URLs to scrape directly. Job IDs may also be pasted on their own.Default []
    locationLocationstringCity, state, ZIP code, or remote. Leave empty to search nationwide (mode=search).Default ""; Example "New York"
    countryCountrystringWhich SimplyHired site to search (mode=search). Choose the country that matches your location.Default "united-states"; Allowed united-states, canada, united-kingdom, ireland, germany, france, spain, italy and 15 more
    radiusSearch radiusstringDistance around the location (mode=search). Only applies when a location is set.Default ""; Allowed , exact, 5, 10, 15, 25, 50, 100
    sortBySort results bystringOrder of the search results (mode=search).Default "relevance"; Allowed relevance, date, distance
    datePostedDate postedstringOnly include jobs added within this window (mode=search).Default ""; Allowed , 1, 3, 7, 14, 30
    employmentTypeEmployment typestringFilter by employment type (mode=search).Default ""; Allowed , CF3CP, NJXCK, 75GKK, 4HKF7, 5QWDV, VDTG7, 7SBAT and 1 more
    minSalaryMinimum salaryintegerOnly jobs with pay at or above this amount, in the local currency of the selected country (e.g. 100000 = $100,000 a year on the US site). Leave 0 for no filter.Default 0; Allowed 0 to 1000000
    remoteTypeRemote workstringFilter by remote work arrangement (mode=search).Default ""; Allowed , Remote, Hybrid work

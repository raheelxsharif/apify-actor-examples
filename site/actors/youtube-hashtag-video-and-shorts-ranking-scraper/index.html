    YouTube Hashtag Video & Shorts Ranking Scraper is an Apify Actor published by Dataspryva. It accepts 9 input fields, and hashtags is required. Each result can carry up to 40 declared fields, including hashtag, position, type, videoId, title and url. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video or Short”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (one hashtag, ranked by views). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerHashtag (default 50, maximum 500) caps how many results a run collects, and so what it costs.

    What it costs

    YouTube Hashtag Video & Shorts Ranking Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    hashtagsHashtagsarray requiredHashtags to scrape. Accepts a bare tag, a #tag, or a full youtube.com/hashtag/<tag> URL. Up to 200 unique tags per run.Example ["programming"]
    maxResultsPerHashtagMax Results Per HashtagintegerMaximum records to return per hashtag after sorting and filters. YouTube's hashtag feed is a ranked sample, so large values may return fewer rows.Default 50; Example 2; Allowed 1 to 500
    contentTypeContent TypestringWhich cards to return: regular videos, Shorts, or both.Default "all"; Example "videos"; Allowed all, videos, shorts
    marketMarket / RegionstringCountry/region used for the hashtag feed. It changes which videos rank and the default language.Default "US"; Allowed US, GB, CA, AU, DE, FR, JP, KR and 23 more
    languageLanguagestringLanguage used for YouTube labels, counts and dates. Auto follows the selected market.Default "auto"; Allowed auto, en, de, fr, ja, ko, pt, hi and 22 more
    includeVideoDetailsInclude Video DetailsbooleanFetch each video's detail data to fill exact views, likes, comments, subscriber counts, publish date, description, keywords, category and Shorts channel metadata. Slower but more complete.Default true; Example false
    sortBySort BystringOrder the collected results within each hashtag. Default keeps YouTube's first-seen feed order.Default "default"; Allowed default, viewCount, durationSeconds, publishedAt
    minViewCountMinimum View CountintegerDrop videos with fewer than this many views. Turns on detail enrichment so compact Shorts labels are not mis-filtered.Allowed 0 to 2000000000
    publishedAfterPublished AfterstringOnly keep videos published on or after this date (YYYY-MM-DD). Turns on detail enrichment.

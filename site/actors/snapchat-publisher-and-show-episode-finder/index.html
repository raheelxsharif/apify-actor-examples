    Snapchat Publisher & Show Episode Finder is an Apify Actor published by Dataspryva. It accepts 11 input fields, and mode is required. Each result can carry up to 48 declared fields, including recordType, publisherId, pageUrl, displayName, username and isVerified.     Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (publisher profile with the latest page data only). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxEpisodesPerPublisher (default 100, maximum 5000) and maxItems (default 100, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    Snapchat Publisher & Show Episode Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

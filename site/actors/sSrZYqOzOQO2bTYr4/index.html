Willhaben Marketplace, Cars & Real Estate Listings Scraper

Search Willhaben.at classifieds, used cars, and real estate (rent or buy apartments, houses, land) by keyword, price range, and sort order. Get listing prices, locations, images, and category-specific details such as car mileage or living area.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
modestringrequiredChoose a marketplace section, cars, real estate, jobs, or paste Willhaben URLs.
querystringoptionalFree-text keyword, e.g. 'sofa', 'iPhone', 'BMW', 'Wohnung'. Leave empty to browse the category.
startUrlsarrayoptional(mode=byUrls) Paste search, category, single listing, job search or single job URLs. Filters already in the URL are preserved.

Published README

Read the full published documentation

Willhaben Marketplace, Cars, Real Estate & Jobs Scraper

Willhaben.at is Austria's largest classifieds site — marketplace goods, used cars, apartments, houses, land and jobs all live in one place. This actor turns those listings into structured records: prices, locations, seller details, car specifications, property areas and energy data, job salaries, images and direct links. Search by keyword and filters, or paste any Willhaben search or listing URL. No login, cookies, API key or proxy setup is needed.

What this actor does

  • Marketplace, cars, real estate and jobs in one actor — choose a section or paste URLs from any of them.
  • Location-aware search — filter by federal state, city, district or Austrian postcode.
  • Real filters, not post-filtering — price, car make/model/year/mileage/fuel/transmission/body/drive/colour/power, property type/rooms/area/outdoor space/equipment, and job region/field/employment type/employer type.
  • Optional detail enrichment — add full descriptions, seller contact details, equipment lists, energy certificates and rent breakdowns from each listing page.
  • Incremental monitoring — on recurring runs return only new, changed, expired or reappeared listings/jobs.
  • Omit-empty output — a field the source does not carry is left out, never sent as null or blank.

Output per listing

Every record has recordType: "listing" and the mode that produced it.

Output per job

Job records have recordType: "job".

  • jobId, jobTitle, description, jobUrl
  • companyName, companyId, companySlug, companyUid, companyAddress, companyLogoUrl
  • position, salary, salaryTimeFrame, employmentTime, employmentModes[]
  • locations[] — objects with name, federalState, country
  • publishedDate, modifiedDate, expiryDate
  • isExpired, isTopJob, overpay, brandNew, internalApplication
  • contactName, contactEmail, languageSkills[], professionalExperience
  • mode, scrapedAt

Add includeDetails to fill full descriptions, expiry dates, company addresses, contact details and language skills where the source publishes them. Contact email is only present on some job ads.

Incremental output

When incrementalMode is on, each record also has:

  • changeType — NEW, UPDATED, UNCHANGED, REAPPEARED or EXPIRED
  • changedFields[] — tracked fields that changed on an UPDATED record
  • firstSeenAt, lastSeenAt, previousPrice
  • emitUnchanged / emitExpired control whether unchanged or missing records are included

The first run returns everything as NEW. Later runs compare against the saved state for the same stateKey (or the same filters when stateKey is empty).

FAQ

Is this affiliated with Willhaben? No. This actor reads publicly visible listings and has no relationship with Willhaben.at.

Do I need an account, cookies or an API key? No. Listings, search pages and job ads are read without logging in.

Do I need to configure a proxy? No. The actor chooses a working connection automatically. Just fill in the input and run it.

Why are some fields missing on some records? Sellers do not always publish every attribute. A field the source does not carry is omitted, never sent as null or a blank value.

Why is car mileage or first registration missing on some cars? Some sellers leave those fields empty. The actor returns the data the listing actually contains.

What does "Fetch detail pages" add? Full descriptions, seller/contact details, equipment lists, energy certificates, rent breakdowns, floor plans and extra car specification fields. It is optional because it makes the run slower.

How many records can one run return? Up to maxItems, which can be set to 50,000. Willhaben serves at most 199,800 records per search query; for larger jobs, split by state or price range and combine the results.

Can I run this on a schedule and only get new listings? Yes. Turn on incrementalMode; the first run establishes the baseline and later runs return new, changed, expired or reappeared records according to emitUnchanged and emitExpired.

Do price and seller-type filters work for jobs and real estate? Job ads have no listing price, so price filters are ignored for jobs. Willhaben does not apply seller-type filtering to real estate or jobs; those filters are ignored and the run reports it in its status message.

Are image and listing links usable outside Apify? Yes. Image URLs and listing/job links are public absolute URLs.

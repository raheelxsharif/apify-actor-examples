    Google Autocomplete Keyword Expansion Scraper is an Apify Actor published by Dataspryva. It accepts 14 input fields, and keywords is required. Each result can carry up to 7 declared fields, including keyword, seed, type, position, locale and relevance. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What it does”, “Modes”, “Output”, “Input”, “How it works” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 7 fields in 1 dataset view, and the README documents 3 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (s). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 5000, maximum 50000) and maxSuggestionsPerSeed (maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Google Autocomplete Keyword Expansion Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 14 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    keywordsSeed keywordsarray requiredOne or more seeds. 1-3 word seeds return the most suggestions. Each seed is expanded according to mode.Default ["python tutorial"]
    modeExpansion modestringHow each seed is expanded. all runs every strategy; exact queries only the seed; alphabet adds a-z and 0-9 before and after; questions uses locale question words; modifiers adds prepositions and buyer-intent words; related adds trailing-space, wildcard, local, review and price variants.Default "all"; Example "exact"; Allowed all, exact, alphabet, questions, modifiers, prepositions, comparisons, related
    countryCountry (gl)stringGoogle market used for the gl parameter. Changes ranking and local phrasing. 134 markets were verified against the live endpoint; the legacy ALL value maps to US.Default "US"; Allowed US, GB, CA, AU, NZ, IE, DE, FR and 127 more
    languageLanguage (hl)stringLanguage used for the hl parameter and for the locale-aware question and modifier words. 19 languages have native expansion vocabularies; the rest fall back to English modifiers.Default "en"; Allowed en, es, fr, de, it, pt, nl, pl and 70 more
    sourceGoogle surfacestringWhich Google autocomplete surface to query: web, YouTube or Shopping. all runs all three and multiplies the request count.Default "web"; Allowed web, youtube, shopping, all
    maxItemsMax recordsintegerHard cap on dataset records across all seeds and sources. Flat mode counts suggestions; tree mode counts one record per seed/source.Default 5000; Example 3; Allowed 1 to 50000
    maxSuggestionsPerSeedMax suggestions per seedintegerCap on suggestions collected for one seed, applied after all expansion queries have run. Defaults to 2,000 when omitted (legacy maxItemsPerKeyword is honoured).Example 3; Allowed 1 to 10000
    minLengthMin charactersintegerDrop suggestions shorter than this many characters.Allowed 1 to 200
    maxLengthMax charactersintegerDrop suggestions longer than this many characters.Allowed 1 to 500
    containsKeywordMust containstringKeep only suggestions containing this substring (case-insensitive). Prefix with ! to exclude matches instead.
    outputFormatOutput shapestringflat emits one row per suggestion. tree emits one row per seed and source with a nested suggestions array (the legacy shape).Default "flat"; Allowed flat, tree
    expansionDepthRecursion depthstringRe-query the first 15 discovered suggestions to go one or two levels deeper. Off for the cheapest run.Default "0"; Allowed 0, 1, 2
    dedupeAcrossSeedsDedupe across seedsbooleanEmit a phrase only once per run. Off keeps every seed complete; on removes overlaps between seeds.Default false
    includeIntentAdd intent tagsbooleanAdd a deterministic intent tag (question, comparison, local, transactional, commercial, informational) where a language vocabulary matches.Default true; Example false

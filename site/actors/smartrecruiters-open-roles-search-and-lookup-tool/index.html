    SmartRecruiters Open Roles Search & Lookup Tool is an Apify Actor published by Dataspryva. It accepts 12 input fields, and mode is required. Each result can carry up to 9 declared fields, including title, companyName, companyIdentifier, location, department and typeOfEmployment. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Inputs”, “Output”, “Examples” and “Useful to know”.

    What it costs

    SmartRecruiters Open Roles Search & Lookup Tool uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    queryKeyword searchstringWords to look for in job titles and descriptions, e.g. 'software engineer' or 'registered nurse'. Used by searchJobs and optionally to narrow getJobs.Example "software engineer"
    companyIdsCompany identifiersarraySmartRecruiters company identifiers, taken from the company's job-board URL (e.g. AveryDennison from jobs.smartrecruiters.com/AveryDennison/...). Required for mode=getJobs.Example ["AveryDennison"]

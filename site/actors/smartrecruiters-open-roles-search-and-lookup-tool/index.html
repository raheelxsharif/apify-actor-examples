    SmartRecruiters Open Roles Search & Lookup Tool is an Apify Actor published by Dataspryva. It accepts 12 input fields, and mode is required. Each result can carry up to 9 declared fields, including title, companyName, companyIdentifier, location, department and typeOfEmployment. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    Collect live job postings from SmartRecruiters, the hiring platform used by thousands of employers for their public career sites. Three ways to work: search the public SmartRecruiters job index by keyword, read a complete company board, or look up individual posting links.

    Modes

    Mode What it does Best for
    searchJobs Searches the public SmartRecruiters index across all companies by keyword, then narrows by location, experience, employment type, and age. Market mapping and discovering which employers are hiring
    getJobs Reads the complete public board of one or more companies by their SmartRecruiters identifier, with optional keyword and filters. Talent sourcing and monitoring a target company
    getJobDetails Fetches one or more posting URLs or Company/PostingID pairs, including the full job-ad sections. Enriching a known shortlist or checking a single role

    Output

    Every record is a job with empty fields omitted:

    • id, uuid, refNumber - posting identifiers and the company reference number
    • title - role title
    • companyIdentifier, companyName, companyLogo - employer identity
    • location - city, country, region, address, postalCode, fullLocation, remote, hybrid, hybridDescription, latitude, longitude
    • department, industry, function, experienceLevel, typeOfEmployment - each with id and label
    • customField - company-defined fields with fieldId, fieldLabel, and value/valueId/valueLabel
    • creator - hiring contact name and avatar when published
    • releasedDate, createdOn, updatedOn, unpublishOn - posting lifecycle dates
    • language, jobAdLanguage, visibility, active - publication metadata
    • postingUrl, sourceUrl - canonical public posting links; applyUrl and referralUrl open SmartRecruiters' interactive apply/referral flow in a browser
    • companyDescription, jobDescription, qualifications, additionalInformation - full HTML sections when details are requested
    • descriptionText - plain-text version of the job-ad sections
    • videos - video links from the posting, when present
    • recordType, scrapedAt - collection metadata

    Examples

    Search every SmartRecruiters company for senior product roles in Germany:

    {
  "mode": "searchJobs",
  "query": "product manager",
  "country": "de",
  "experienceLevel": "mid_senior_level",
  "maxItems": 50
}

    Read all open roles at two companies, including descriptions:

    {
  "mode": "getJobs",
  "companyIds": ["AveryDennison", "BoschGroup"],
  "includeJobDetails": true,
  "maxItems": 100
}

    Look up a specific posting:

    {
  "mode": "getJobDetails",
  "jobUrls": ["https://jobs.smartrecruiters.com/AveryDennison/744000162663099-business-development-specialist"]
}

    Limits and notes

    Useful to know

    • No account, cookie, or API key is needed. The actor reads the same public postings and API that SmartRecruiters serves to any visitor.
    • Use postingUrl for automation. SmartRecruiters' applyUrl redirects into an interactive one-click flow that expects a browser; postingUrl is the stable public page.
    • Find a company identifier in its career-site URL: if a role lives at https://jobs.smartrecruiters.com/AveryDennison/..., the identifier is AveryDennison.
    • Global search has a source cap. The public index returns roughly 100 rows per keyword query. When you ask for more, the actor expands through the companies that appeared in the search results; for guaranteed completeness use getJobs with the company identifier.
    • Company boards are complete. Pagination follows SmartRecruiters' own totalFound and offset until the board or your maxItems is exhausted.
    • Filters reflect the company's labels. SmartRecruiters stores experience and employment types per posting; the actor uses the platform's own values.
    • Descriptions are optional. includeJobDetails adds one request per job, so leave it off when you only need titles, locations, and links.
    • Not affiliated with SmartRecruiters. This is an independent third-party tool that reads public data.

    Instagram Transcript Scraper - Reels & Video is an Apify Actor published by Dataspryva. It accepts 10 input fields, none of them required at the top level. Each result can carry up to 22 declared fields, including status, postUrl, shortCode, videoIndex, userName and userFullName. It costs $0.50 per 1,000 results on Apify's Free plan and $0.30 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per video”, “Input”, “Example output”, “Transcription methods” and “Authentication”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 22 fields in 1 dataset view, and the README documents 17 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (transcribe a single reel). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxPosts_per_username (default 10, maximum 100) caps how many results a run collects, and so what it costs.

    What it costs

    Instagram Transcript Scraper - Reels & Video uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    videoUrlsInstagram Video URLsarrayList of Instagram video or reel URLs to transcribe. Supports /p/, /reel/, and /tv/ formats. Provide this, usernames, or both.Example ["https://www.instagram.com/p/Dew5IIlNfMW/"]
    usernamesInstagram Usernames or Profile LinksarrayUsernames whose newest posts should be checked for videos. Each entry can be a username (with or without @) or a profile link such as https://www.instagram.com/natgeo/. Every video is transcribed (each video of a carousel on its own); a post without a video gets a record with the status not_a_video.Example []
    maxPosts_per_usernameMax Posts Per UsernameintegerHow many of each username's newest posts to check (after the date and pinned-post filters below). Every video among them is transcribed (each video of a carousel on its own); a post without a video gets a record with the status not_a_video. Public profiles need no sign-in, however many posts you ask for; a private profile needs your cookies.Default 10; Example 0; Allowed 0 to 100
    newerThanOnly posts newer thanstringSkip posts published before this date. Leave empty for no date filter. Must be a date from 2000-01-01 up to the day before the run. Applies to usernames only. The date is read from the post's id, so it can be off by up to a day.
    skipPinnedPostsSkip pinned postsbooleanLeave out the posts a profile has pinned to the top of its grid. Applies to usernames only. A pinned post that is also the newest post cannot be recognised and stays in.Default false
    transcriptionMethodTranscription MethodstringHow to extract transcripts. 'auto' tries native Instagram captions first, then falls back to Whisper AI. 'native' only uses Instagram captions. 'whisper' always uses AI speech-to-text.Default "auto"; Allowed auto, native, whisper
    whisperModelWhisper Model SizestringWhisper AI model size. Larger models are more accurate but use more memory and time. Only used when transcription method involves Whisper.Default "base"; Allowed tiny, base, small
    includeSegmentsInclude Timestamped SegmentsbooleanWhen enabled, the output will include a 'segments' array with per-segment timestamps and text alongside the full transcript. Each segment represents a distinct phrase with start/end times in seconds. Note: enabling this feature incurs an additional charge per run.Default false
    languageLanguagestringLanguage of the video audio. Leave empty for automatic detection. Only used when Whisper is active.Default ""; Allowed , en, es, fr, de, it, pt, ru and 22 more
    cookiesInstagram Cookies (Optional)stringOptional. Leave empty to transcribe public videos without signing in. Paste your own Instagram cookies in JSON format to also transcribe age-restricted videos and videos of private accounts your account follows. It is a secret input, so the Apify Console hides and encrypts it. Format: [{"name":"sessionid","value":"...","domain":".instagram.com"}, ...]

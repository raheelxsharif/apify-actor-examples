    Multi-League Season Results & Team Lookup is an Apify Actor published by Dataspryva. It accepts 10 input fields, and mode is required. Each result can carry up to 25 declared fields, including homeTeam, awayTeam, homeScore, awayScore, matchDate and status. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Modes”, “Input”, “Output per match (mode: results)”, “Output per team (modes: teams, teamSearch)” and “Which leagues are covered?”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (a full premier league season with odds). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 20, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Multi-League Season Results & Team Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 10 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to fetchstring requiredSeason results with odds, a league's team roster, or a team lookup by name.Default "results"; Allowed results, teams, teamSearch
    sportLeaguestringWhich competition to fetch. Ignored when leagueUrls is set.Default "epl"; Allowed epl, nfl, nba, mlb, nhl, mls, bundesliga, serie_a and 24 more
    seasonSeasonstringSeason to fetch. Soccer-style seasons use YYYY-YYYY (a plain YYYY expands to YYYY-YYYY); calendar-year leagues (MLB, MLS, NPB, J1, K League) use YYYY; 'current' is the live season. Used in results and teams modes.Default "2024-2025"; Allowed 2022-2023, 2023-2024, 2024-2025, 2025-2026, 2022, 2023, 2024, 2025 and 1 more
    leagueUrlsLeague URLsarrayOptional: one or more OddsPortal league or season-results URLs (any sport or league, e.g. https://www.oddsportal.com/football/england/premier-league-2024-2025/results/). Overrides League and Season.Example []
    teamQueryTeam namestringTeam to look up by name (teamSearch mode), e.g. Arsenal or Real Madrid.Example "Arsenal"
    includeOddsInclude oddsbooleanAdd 1X2 average and maximum odds, bookmaker count and per-bookmaker prices to each result.Default true
    includeUpcomingInclude upcoming matchesbooleanKeep scheduled and in-progress matches; turn off to get only finished results.Default true
    enrichTeamsFetch team profilesbooleanIn teams and teamSearch modes, open each team's page for its full name, venue, city, country and coach. Adds one request per team.Default true; Example false
    regionalFallbackRegional edition fallbackbooleanWhen a league-season is empty on the main domain, retry it on the same site's regional edition (a few competitions, e.g. ACB, only publish older seasons there). Only fires on empty results, so it does not change normal runs.Default true
    maxItemsMax itemsintegerMaximum records to return (1-10000). The run also stops when the source runs out of pages.Default 20; Allowed 1 to 10000

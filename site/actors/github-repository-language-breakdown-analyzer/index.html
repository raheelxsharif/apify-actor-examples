    GitHub Repository Language Breakdown Analyzer is an Apify Actor published by Dataspryva. It accepts 19 input fields, and mode is required. Each result can carry up to 9 declared fields, including fullName, language, languagesBreakdown, stars, forks and contributorCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    GitHub shows one primary-language badge per repository, which hides the real mix of code inside. This actor reads GitHub's public REST API and returns each repository with byte counts and percentage shares for every detected language, plus optional ranked contributors, weekly commit statistics, and release history. Pick repositories one at a time, paste a list, sweep an organization or user account, or discover them by keyword or topic. No API token, login, or proxy is needed.

    What this actor does

    • Six ways to choose repositories: one repository, a pasted list, an organization, a user account, a GitHub keyword search, or a topic search
    • Language detail: byte counts per language beside the existing percentage breakdown, with the primary language and total analyzed bytes
    • Contributor rankings: top contributors with public profile links and contribution counts, capped by your chosen limit
    • Commit statistics: 52-week commit activity, all/owner weekly participation, weekly additions and deletions, and the weekday/hour punch card
    • Release history: recent releases with tag, date, asset count, and total asset downloads
    • Discovery controls: primary-language filter, fork and archive filters, sort field, sort direction, and a hard result cap
    • Empty values are omitted from each record, so a field only appears when GitHub actually reports it

    Use cases

    • Tech due diligence — check what languages an acquisition target or vendor actually ships, not just its marketing page
    • Engineering benchmarking — compare language mix, contributor depth, and commit cadence across competitor organizations
    • Open-source health checks — review release rhythm, weekly participation, and top contributor concentration before adopting a dependency
    • Developer research — find repositories in a niche by topic or keyword and rank them by stars or forks
    • Portfolio monitoring — paste a watchlist of repositories and track stars, forks, language drift, and releases over time
    • License audits — scan an organization's repositories for declared licenses and SPDX identifiers

    Questions

    Do I need a GitHub token?

    No. The actor uses GitHub's public endpoints without authentication. GitHub allows 60 unauthenticated core requests per hour per IP and 10 search requests per minute. When that budget runs out, the actor returns the repository records it already collected and tells you which enrichment was skipped.

    Why are some language fields missing?

    Repositories with no analyzed code — documentation collections, awesome lists, empty repositories — genuinely have no language bytes on GitHub. The field is omitted rather than filled with a zero or a guess.

    What counts as a contributor?

    GitHub's ranked contributor list groups commits by linked GitHub account and includes anonymous author entries when they are the only match. The list is capped by contributorsLimit, so contributorCount is the number returned, not necessarily every person who ever committed.

    Why did a big repository return no code-frequency data?

    GitHub refuses code-frequency statistics for repositories with more than 10,000 commits. Other commit statistics still return when available.

    Why is commitActivity sometimes absent?

    GitHub computes statistics lazily and can return a temporary "accepted" response for a repository it has not analyzed recently. The actor retries twice with a short delay; if the data is still pending it omits the field instead of fabricating it.

    What happens with more than 1,000 search results?

    GitHub's search API stops at 1,000 matches. The actor reports the cap in the run status; narrow the query, split it by date or language, or use the organization/user modes, which paginate the full repository list.

    Are forks included by default?

    No. Discovery modes skip forks unless includeForks is on. When you request a specific repository by name or URL, that repository is returned even if it is a fork, because you named it explicitly. The primary-language filter still applies to named repositories.

    Why does sorting by stars sometimes fall back to recently updated?

    GitHub's organization and user listing endpoints sort by creation, update, push, or name, but not stars or forks. For those two sort options the actor switches to GitHub's repository search, which supports star and fork ranking and is capped at 1,000 results. Keyword-only sort choices that search does not support fall back to recently updated, and the run status says so.

    Can I fetch private repositories?

    No. Only public repositories and public metadata are reachable without credentials.

    Is this affiliated with GitHub?

    No. This is an independent, third-party actor built on GitHub's public REST API; it is not operated by or affiliated with GitHub, Inc.

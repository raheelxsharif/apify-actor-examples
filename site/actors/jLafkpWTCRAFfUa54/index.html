Actors/Amazon Search, Category & Seller Listings Extractor

Amazon Search, Category & Seller Listings Extractor

Get Amazon products from search results, categories, seller storefronts, or ASIN lookups across 20+ marketplaces, with price, rating, badges, deals, and delivery details.

Open on ApifyGitHub source

Input schema

Input fields, types, required flags, descriptions, defaults, and prefills come from the published definition. Prefill examples are distinct from defaults.

FieldTypeRequiredDescription
categoryUrlsarrayoptionalAmazon search, category, seller-profile, or exact product URLs. Search pages (/s?k=), browse nodes (/b?node=), seller profiles (/sp?seller=), and product pages (/dp/) are routed automatically. Combine with any other mode.
keywordsarrayoptionalPlain search keywords or phrases. Each keyword builds an Amazon search URL (/s?k={query}).
productUrlsarrayoptionalExact Amazon product URLs. Each URL is normalized to /dp/{ASIN} on its own marketplace and fetched directly (never as a search).

FieldTypeRequiredDescription
categoryUrlsarrayoptionalAmazon search, category, seller-profile, or exact product URLs. Search pages (/s?k=), browse nodes (/b?node=), seller profiles (/sp?seller=), and product pages (/dp/) are routed automatically. Combine with any other mode.
keywordsarrayoptionalPlain search keywords or phrases. Each keyword builds an Amazon search URL (/s?k={query}).
productUrlsarrayoptionalExact Amazon product URLs. Each URL is normalized to /dp/{ASIN} on its own marketplace and fetched directly (never as a search).
asinsarrayoptionalAmazon ASINs to fetch exactly. Each ASIN opens its own product page (/dp/{ASIN}) directly, never a keyword search.
sellerIdsarrayoptionalAmazon seller/merchant IDs. Each ID builds that seller's storefront listing (/s?me={sellerId}).
categoryNodeIdsarrayoptionalAmazon browse-node IDs. Each node builds a real category listing (/s?rh=n:{node}&fs=true), with a merchandising fallback only when Amazon renders no listing grid.
marketplaceDomainstringoptionalAmazon marketplace used for keyword, ASIN, seller, and node modes. URLs in categoryUrls/productUrls keep their own marketplace.
maxItemsintegeroptionalGlobal cap across every source in the run. 0 means no global cap.
maxItemsPerCategoryintegeroptionalMaximum products to return from each keyword, URL, seller, or node source.
maxPagesintegeroptionalMaximum listing pages per source. Amazon keyword search itself stops at page 7; category listings go deeper.
scrapeProductDetailsbooleanoptionalIf true, visit each accepted product's own page for specs, gallery images, seller, BSR, variants, and histogram. ASIN/product-URL modes always use detail pages. If false, only listing-card fields are returned.
includeSpecificationsbooleanoptionalIf true (and detail pages are scraped), return the specifications object parsed from the overview and technical-detail tables.
sortBystringoptionalSort order applied to search and category listings.
priceMinnumberoptionalOnly return products priced at or above this amount (marketplace currency).
priceMaxnumberoptionalOnly return products priced at or below this amount (marketplace currency).
minRatingnumberoptionalOnly return products with a star rating at or above this value (0-5).
includeSponsoredbooleanoptionalIf true (default), sponsored/ad placements are included. Set false to return organic results only.
onlyDealsbooleanoptionalIf true, only return products with visible deal evidence (coupon, limited-time-deal badge, or genuine strike-through list price).
primeOnlybooleanoptionalIf true, only return products with a visible Amazon Prime badge. Badges are render-dependent in some marketplaces.
rateLimitDelayintegeroptionalBase pacing delay between live requests. Product-detail requests always add human-like jitter.

FieldTypeRequiredDescription
titlestringoptionalProduct title

scrapedAtstringrequiredISO timestamp when the data was scraped

sponsoredstringoptionalWhether this result is a sponsored/ad placement (evidence-only)

boughtInPastMonthstringoptionalNumber of units bought in the past month, parsed from the card's compact-count hint

couponstringoptionalCoupon text shown on the card, if any
stockTextstringoptionalRaw stock hint shown on the listing card
unitPricestringoptionalPer-unit price text shown on the listing card
dealTextstringoptionalRaw deal/percent-off text shown on the listing card
soldByTextstringoptionalRaw "Sold by" line shown on the listing card
moreOptionsTextstringoptionalRaw "More options" hint shown on the listing card
deliveryEstimatestringoptionalEstimated delivery text shown on the card
shipsTostringoptionalShips-to location text shown on the card, if any
sustainabilityFeaturesstringoptionalSustainability/Climate Pledge Friendly badge labels (JSON array)
variantsCountstringoptionalNumber of additional color/style variants shown via the card's "+N" hint
primestringoptionalWhether the card shows an Amazon Prime badge (evidence-only)
isPrimestringoptionalSame true/false value as `prime`
offerCountstringoptionalNumber of "More Buying Choices" offers shown on the card
lowestOfferPricestringoptionalLowest "More Buying Choices" offer price (JSON object with value and currency)
resultsTotalstringoptionalTotal number of results reported by the results-info bar
resultsFromstringoptionalStarting result index reported by the results-info bar
resultsTostringoptionalEnding result index reported by the results-info bar
positionstringoptionalPosition metadata (JSON object with page, positionOnPage, globalPosition, uuid)
facetsstringoptionalRefinement facets available on this results page (JSON array)

Amazon Search, Category & Seller Listings Extractor

Pull Amazon product listings from keyword search, category/search URLs, browse-node IDs, seller storefronts, ASINs, and exact product URLs in one run. Every record carries the listing card data — price, brand, rating, badges, images, delivery hints, and organic/sponsored position — and optional product-detail enrichment adds specifications, the full gallery, seller identity, rating histogram, variants, and bestseller ranks. No login, cookies, or API key needed.

What this actor does

  • Six additive input modes. Combine keywords, categoryUrls, categoryNodeIds, sellerIds, asins, and productUrls in the same run; every source is processed and deduplicated by ASIN.
  • Exact product lookup. ASIN and product-URL modes open /dp/{ASIN} directly. They never fall back to an Amazon keyword search, so a known product cannot turn into an unrelated result.
  • Real category listings. Node IDs use Amazon's /s?rh=n:{node}&fs=true listing route, not the /b?node= merchandising landing page. Search, seller (/s?me=), and seller-profile (/sp?seller=) URLs are routed automatically.
  • Playwright reliability. Each marketplace session is warmed up on the homepage and paced with human-like jitter. Continue-shopping interstitials, dog pages, rate limits, and interstitial challenges are classified and retried. Proxy selection is automatic: an available non-residential (datacenter/static) group in the marketplace's country, never residential by default.
  • Listing intelligence. Brand, card image set and large image, organic position, sponsored flag, ships-to line, variant count, unit price, deal text, stock hint, sold-by line, and a genuine list price kept separate from Amazon's "Typical price".
  • Detail enrichment. Specifications, gallery images, rating histogram, reviews link, seller ID/name/URL, variant dimensions, BSR, breadcrumbs, description, features, and stock status.
  • Safe output. Empty fields are omitted at every depth; nothing is emitted as null.

Listing fields (all modes)

  • asin, title, url, marketplace, sourceMode, searchQuery
  • price {value, currency, display}, listPrice, typicalPrice, discountPercent

  • thumbnailImage, images, imageLarge
  • badge, coupon, dealText, stockText, unitPrice, soldByText, moreOptionsText
  • boughtInPastMonth, boughtInPastMonthText

Product-detail fields (detail enrichment or ASIN/product-URL modes)

  • brand, inStock, inStockText, currency
  • specifications (overview + technical tables)
  • images (gallery), imageLarge

  • seller {name, id, url} — omitted when no real seller ID can be resolved

Fields that Amazon does not render for a specific product are omitted, never fabricated. This includes render-dependent badges (Prime, sponsored), seller identity, and some buy-box details.

FAQ

Do I need Amazon cookies or an API key? No. The actor reads public search, category, seller, and product pages anonymously. No account, cookie, token, or API key is required.

Do ASIN inputs still search Amazon? No. ASIN and product-URL modes fetch the exact /dp/{ASIN} page. Keyword mode is the only mode that performs a search.

Why is listPrice missing on a product that shows a "Typical price"? "Typical price" is not a strike-through list price. It is returned separately as typicalPrice, and discountPercent is calculated only from a genuine current price plus list price. This prevents fake discounts.

Why are Prime or sponsored fields missing from some records? Amazon does not render Prime icons or sponsored labels for every marketplace, exit country, or layout. The actor reports only what the page actually shows and never claims a product is "not Prime" from a missing badge.

Why do I get fewer results than maxPages suggests? Amazon caps keyword search at page 7. Category listings can go deeper. For more than a keyword surface allows, split the query by category, brand, or price band and combine the runs.

Does the actor need my proxy? No. Proxy selection is automatic: it uses an available non-residential Apify Proxy group in the marketplace's own country and never switches to residential billing on its own. There is no proxy input to configure.

Why do prices appear in a currency different from the marketplace domain? Amazon localizes currency and delivery to the request's exit country. The actor sets the marketplace country automatically and reports the resolved currency; cross-border renders can still differ from the domain's nominal currency.

How expensive is detail enrichment? Each detail page is a full Amazon product page (roughly 2.5-3.1 MB). Set scrapeProductDetails to false for large listing runs and enable it only for a shortlist or for ASIN/product-URL modes.

Is this affiliated with Amazon? No. It is an independent third-party actor that reads Amazon's public pages.

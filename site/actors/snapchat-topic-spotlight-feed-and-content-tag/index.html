    Snapchat Topic Spotlight Feed & Content Tag Extractor is an Apify Actor published by Dataspryva. It accepts 9 input fields, none of them required at the top level. Each result can carry up to 52 declared fields, including topicId, snapId, creatorUsername, viewCount, uploadedAt and snapUrl. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Modes”, “Output”, “Input”, “Use cases”, “FAQ” and “Data source and limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (three topics). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxResultsPerTopic (default 50, maximum 100), maxTopicsPerQuery (default 50, maximum 500) and maxItems (default 1000, maximum 10000) cap how many results a run collects, and so what it costs.

    What it costs

    Snapchat Topic Spotlight Feed & Content Tag Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestringChoose what to collect: videos for topics/tags, topics for search keywords, or the current Spotlight feed.Default "topicFeed"; Allowed topicFeed, topicSearch, spotlightFeed
    topicsTopics or tagsarrayTopic names, hashtags, or Snapchat URLs. Examples: food, #travel, https://www.snapchat.com/tag/food, https://www.snapchat.com/topic/cappuccino-foam-technique.Default []; Example ["food"]
    maxResultsPerTopicMax videos per topicintegerMaximum videos to keep for each topic after combining its topic/tag page with Explore results. Snapchat serves 19-32 videos per page and the combined pool is usually 40-54.Default 50; Example 3; Allowed 1 to 100
    includeRelatedTagsInclude S2I content tagsbooleanInclude Snapchat's scene-to-interest (S2I) tags for each video when the page provides them. Coverage is partial, so the field is omitted when unavailable.Default true; Example false
    searchQueriesSearch keywordsarrayKeywords or phrases used to discover topics, such as coffee, new york, or taylor swift.Default []
    maxTopicsPerQueryMax topics per queryintegerMaximum topic rows to keep for each search query, including related topics when expansion is enabled.Default 50; Allowed 1 to 500
    includeRelatedTopicsExpand related topicsbooleanAdd one hop of related topics found on each discovered topic's topic, tag, or Explore page. This follows public page links; it does not recurse further.Default false
    enrichVideosEnrich videos with detail pagesbooleanVisit each video's Spotlight page to fill missing AI title, comment/recommend counts, language, S2I tags and sound, and each creator's profile once for subscriberCount. Cached and bounded; failures keep the original row.Default false
    maxItemsMax itemsintegerMaximum rows to save across the whole run.Default 1000; Example 3; Allowed 1 to 10000

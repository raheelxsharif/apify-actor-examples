LinkedIn University Alumni Search by Degree & Year

Search LinkedIn's alumni directory for any school and come away with a structured list of graduates, filterable by field of study, degree level, graduation year, current employer, and location — the same filters LinkedIn's own school page offers, minus the manual clicking.

What this actor does

  • Resolves a school by its LinkedIn page URL or just a plain name (e.g. "MIT") and searches its alumni.
  • Narrows results by field of study, degree level, a single graduation year or year range, current company, current location, and LinkedIn connection degree.
  • Infers each alumnus's current title and company from their headline when LinkedIn doesn't expose them as separate structured fields.
  • Can search multiple schools in one run, with each result tagged back to the school it came from.
  • Fields LinkedIn doesn't expose for a given alumnus (for example profilePicture on a private profile) are left out of that record rather than returned empty.

Authentication

This actor requires a LinkedIn session cookie (cookie) because alumni search is only available to signed-in accounts. Supply either the li_at cookie value from your browser's DevTools, or a full cookie-export JSON array.

Output per alumnus

  • name — full name as shown on LinkedIn
  • profileUrl — canonical LinkedIn profile URL
  • headline — profile headline
  • location, currentLocation — location shown on the profile
  • connectionDegree — your connection degree to this person (1st/2nd/3rd+)
  • additionalInfo — the search result's tertiary subtitle line (shared connections, "Open to work", etc.)
  • snippets[] — text snippets LinkedIn highlighted as matching your search
  • industryName — industry, when LinkedIn's search result includes it
  • profilePicture, profileImageUrl — profile photo URL
  • currentTitle — current job title, parsed from the headline or an explicit field when present
  • currentCompany — {name, slug} of the current employer, when resolvable
  • degree — degree level detected for this school (e.g. Bachelor, MBA), when available
  • fieldOfStudy — field of study detected for this school, when available
  • graduationYear — graduation year detected for this school, when available
  • verifiedStatus — true when LinkedIn marks the profile as verified
  • schoolName, schoolUrl — the school this alumnus was found under
  • scrapedAt — ISO 8601 timestamp of when the record was scraped

Input

Field Type Default Description
schoolUrls array – LinkedIn school page URLs
schoolNames array – Plain school/university names, when you don't have the LinkedIn URL
cookie string – LinkedIn session cookie — li_at value or full cookies JSON array (required)
maxAlumniPerSchool integer 100 Maximum alumni profiles to return per school (1–1000)
fieldOfStudy string – Narrow by field of study or specialization, e.g. Computer Science
graduationYear string – Narrow by a single graduation year, e.g. 2020
graduationYearRange object – Narrow by a {start, end} graduation year range (inclusive)
field string – Field of study (alternate filter alongside fieldOfStudy)
degree string – (any) Bachelor, Master, PhD, MBA, Associate, or Other
currentLocation string – Narrow to alumni whose current location matches this text
currentCompany string – Narrow to alumni currently working at this company
language string en_US Preferred LinkedIn locale; currently has no effect on returned alumni data
connectionDegree string – (all) F (1st degree), S (2nd degree), or O (3rd+)
proxyConfiguration object – Apify proxy settings; a residential proxy is recommended for reliability

Use cases

  • University recruiting — find graduates from target schools for campus hiring outreach
  • Alumni network mapping — see where a school's graduates in a given field ended up
  • Lead generation — identify alumni of schools that match your ideal customer profile
  • Academic research — study career outcomes by degree, field of study, or graduation year
  • Personal networking — find fellow alumni of your own school currently at a target company

FAQ

Why does this need my LinkedIn cookie? LinkedIn's alumni search is only served to authenticated accounts — there's no public, logged-out version of a school's alumni list.

Can I search by school name instead of URL? Yes — schoolNames accepts a plain name like "MIT" or "Harvard University"; the actor resolves it to LinkedIn's internal school ID via LinkedIn's own lookup. If a name can't be resolved, the actor falls back to using it as a search keyword, which may return fewer or less precise results.

How many alumni can I get per school? Up to maxAlumniPerSchool (max 1000), but LinkedIn itself caps how many alumni results it surfaces per search session — usually a few hundred — regardless of how high you set the limit.

Why do degree, fieldOfStudy, or graduationYear come back empty for some alumni? These are detected from text LinkedIn's search result exposes for that school (snippets, subtitle text); when LinkedIn doesn't surface that detail for a profile, the field is left out rather than guessed.

What's the difference between fieldOfStudy and field? Both filter by the same concept; fieldOfStudy is the primary input and field is kept as an alternate name for the same filter.

Does connectionDegree limit who I can find, or just label them? It filters — setting it to F, S, or O restricts results to that specific connection tier; leaving it blank returns alumni at any tier LinkedIn shows you.

Is my cookie stored anywhere? The cookie field is marked secret and isn't written to run logs, but the actor does use it to act as your LinkedIn session — use a dedicated account if you're concerned about exposure.

Is this affiliated with LinkedIn? No. This is an independent, third-party actor that uses your own session cookie to read alumni data LinkedIn already shows that account; it is not operated by or affiliated with LinkedIn.

    Amazon Wishlist & Registry Scraper is an Apify Actor published by Dataspryva. It accepts 6 input fields, none of them required at the top level. Each result can carry up to 11 declared fields, including recordType, title, type, accessClassification, asin and price. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Privacy — please read”, “Output: per-list record (recordType: "list")”, “Output: per-item record (recordType: "listItem")”, “Input” and “Use cases”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 1 dataset view, and the README documents 20 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (scrape a public wishlist). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 100, maximum 10000) caps how many results a run collects, and so what it costs.

    What it costs

    Amazon Wishlist & Registry Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 6 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    listUrlsWishlist / registry URLsarrayDirect, public/shareable Amazon list URLs. Accepted shapes: /hz/wishlist/ls/<ID>, the mobile /gp/aw/ls?lid=<ID>, /gp/registry/wishlist/<ID>, /baby-reg/<name>/<ID>, /wedding/guest-view/<ID> (or /wedding/<name>/registry/<ID>), and /registries/gl/guest-view/<ID>. This actor never searches for or enumerates lists; it only visits the exact URLs you provide.Example ["https://www.amazon.com/hz/wishlist/ls/2PBHI0DGWAAAF"]
    listIdsWishlist IDsarrayBare wishlist IDs copied from a list URL (for example 2PBHI0DGWAAAF from /hz/wishlist/ls/2PBHI0DGWAAAF). Each ID is opened on the marketplace selected below. Use this instead of listUrls when you only have the ID.
    marketplaceMarketplace for list IDsstringAmazon marketplace used to build URLs from listIds. Ignored for listUrls because each URL already carries its own marketplace.Default "amazon.com"; Allowed amazon.com, amazon.co.uk, amazon.de, amazon.ca, amazon.fr, amazon.it, amazon.es, amazon.com.au and 15 more
    maxItemsMax items per listintegerHard cap on the number of list items scraped per list URL. The full list is followed through Amazon's own pagination until this cap is reached or the list ends.Default 100; Example 20; Allowed 1 to 10000
    sortBySort orderstringSort order for wishlist items, matching the sort control shown on the live wishlist page. Registry pages expose their own fixed sort set; unsupported values fall back to the list's default order.Default ""; Allowed , date-added, priority, price-asc, price-desc, custom
    proxyConfigurationProxy configurationobjectApify proxy used to fetch list pages. Defaults to the free AUTO (datacenter) group; the actor escalates to a residential session automatically only if a block is detected.Default {"useApifyProxy": true}

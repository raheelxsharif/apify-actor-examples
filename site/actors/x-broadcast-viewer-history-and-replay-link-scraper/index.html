    X Broadcast Viewer History & Replay Link Scraper is an Apify Actor published by Dataspryva. It accepts 9 input fields, and broadcastIds is required. Each result can carry up to 8 declared fields, including type, title, state, broadcaster.username, viewersNow and viewersTotal. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Use cases” and “FAQ”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 8 fields in 1 dataset view, and the README documents 2 more. Fields without a value can be left out of a record.

    What it costs

    X Broadcast Viewer History & Replay Link Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 1 GB, so a run starts with 1 start event, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 9 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    broadcastIdsBroadcast links, IDs or broadcast postsarray requiredPaste broadcast links such as https://x.com/i/broadcasts/1YGNrbPLejQGw, bare broadcast IDs, post links that announce a broadcast, or legacy Periscope links (/v/<id> or /<user>/<id>). Old pscp.tv/w share links cannot be resolved and return a status row.Example ["https://x.com/i/broadcasts/1YGNrbPLejQGw"]
    includeViewerStatsInclude viewer statisticsbooleanInclude current/total viewers, the viewer-history graph when X exposes it, and derived peak/average viewers. Turn off for a lighter output.Default true
    includeViewerTimelineEmit viewer timeline points as rowsbooleanPush one "viewer timeline point" row per point of the broadcast's viewer-history graph. No rows are emitted when X provides no graph.Default false
    maxViewerTimelinePointsMax viewer timeline points per broadcastintegerMaximum timeline rows per broadcast. 0 means all points. When capped, points are evenly sampled across the full broadcast and each row keeps its original index.Default 0; Allowed 0 to 50000
    includeReplayVideoInclude replay video linkbooleanResolve the HLS playback URL and stream status. For a live broadcast the URL is the live stream; for an ended broadcast it is the replay.Default false
    includeChatHistoryInclude public chat replaybooleanCollect text messages from the broadcast's public chat replay after it ends. Live chat and private chats are not collected. No text is emitted when the chat only contains join/heart events.Default false
    maxChatMessagesMax chat messages per broadcastintegerMaximum public chat text messages per broadcast. Older events and join/heart events are not counted.Default 1000; Example 100; Allowed 1 to 100000
    includeThumbnailInclude thumbnail imagebooleanStore the broadcast cover image in the run's key-value store and return its stable URL plus the original X image URL.Default true
    includeBroadcasterProfileInclude broadcaster profilebooleanAdd the broadcaster's public profile (followers, bio, location, account creation date, pinned posts). Falls back to the compact broadcaster record if the profile is unavailable.Default true

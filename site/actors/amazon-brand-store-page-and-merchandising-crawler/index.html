    Amazon Brand Store Page & Merchandising Crawler is an Apify Actor published by Dataspryva. It accepts 10 input fields, none of them required at the top level. Each result can carry up to 11 declared fields, including recordType, brand, pageName, asin, title and url. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output: store page record (recordType: storePage)”, “Output: merchandising section record (recordType: section, when includeSections is on)”, “Output: product record (recordType: product)”, “Output: link record (recordType: link, when includeLinks is on)” and “Output: page error record (recordType: storePageError)”.

    What you get

    The Actor saves one record per result to an Apify dataset. Its build declares 11 fields in 1 dataset view, and the README documents 19 more. Fields without a value can be left out of a record.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (crawl a brand store including its subpages). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxDepth (default 1, maximum 5) and maxProducts (default 200, maximum 2000) cap how many results a run collects, and so what it costs.

    What it costs

    Amazon Brand Store Page & Merchandising Crawler uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    productUrlsProduct URLs (resolve brand store)arrayAmazon product (/dp/{ASIN}) URLs. The actor visits each product page, finds its "Visit the {Brand} Store" link, and crawls that store instead.Default []
    asinsASINs (resolve brand store, amazon.com)arrayProduct ASINs on amazon.com. Same resolution behavior as productUrls.Default []
    crawlSubpagesCrawl subpagesbooleanFollow the store's navigation menu (HOME, FEATURED DEALS, SSD, ...) and crawl every linked subpage, not just the landing page.Default true; Example false
    maxDepthMax navigation depthintegerHow many navigation-link hops to follow from the landing page when crawlSubpages is enabled (1 = landing page's direct subpages only).Default 1; Allowed 1 to 5
    maxPagesMax store pages to fetchintegerHard cap on the total number of store pages (landing + subpages) fetched per store.Default 10; Example 3; Allowed 1 to 50
    maxProductsMax products per storeintegerHard cap on the number of distinct product (ASIN) records emitted per store.Default 200; Example 30; Allowed 1 to 2000
    includeSectionsInclude merchandising sectionsbooleanEmit a section record for every merchandising module on each crawled page: its type, ID, position, heading, body copy, CTA, primary image/video, and product/link counts.Default true
    includeLinksInclude linksbooleanEmit a typed link record for every unique target on each crawled page (navigation, store page, product, search, external), with its section context.Default true
    proxyConfigurationProxy configurationobjectApify proxy. AUTO (datacenter) is used by default with homepage-priming; the actor escalates to RESIDENTIAL automatically only if it keeps getting blocked.Default {"useApifyProxy": true}

    Instagram Search Scraper - Keywords & Hashtags is an Apify Actor published by Dataspryva. It accepts 3 input fields, and keywords is required. Each result can carry up to 26 declared fields, including input_keyword, post_url, username, media_type, pub_date and caption. It costs $3.00 per 1,000 results on Apify's Free plan and $1.00 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per post”, “Input”, “Authentication”, “Free plan” and “Example output”.

    What you get

    What it costs

    Instagram Search Scraper - Keywords & Hashtags uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 3 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    keywordsKeywordsarray requiredList of keywords to search. Works for both single-word (e.g. "photography") and multi-word (e.g. "sunset photography") queries.Example ["messi"]
    maxPostsMax Posts Per KeywordintegerMaximum number of post URLs to collect per keyword.Default 100; Example 10; Allowed 1 to 10000
    cookiesInstagram Cookies (Optional)stringInstagram authentication cookies in JSON format. If not provided, a managed Instagram session is used for the search. Format: [{"name":"sessionid","value":"...","domain":".instagram.com"}, ...]. See README for extraction instructions.

    Medium Article Discovery & Metadata Extractor is an Apify Actor published by Dataspryva. It accepts 12 input fields, and mode is required. Each result can carry up to 8 declared fields, including title, authorName, publicationName, publishedDate, readingTimeMinutes and clapCount. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “Discovery modes”, “Output fields”, “Input fields”, “What you can do with it” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (newest python articles). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 5, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Medium Article Discovery & Metadata Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 12 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeDiscovery modestring requiredChoose how to find articles: browse a tag, list an author's posts, list a publication's posts, search by keyword, or look up article URLs.Default "byTag"; Allowed byTag, byUser, byPublication, search, byUrl
    tagTagstringTag to browse. Pick a common topic or use the matching value in the dropdown; the latest or most-clapped stories for that tag are collected.Default "programming"; Allowed programming, python, javascript, typescript, react, nodejs, java, golang and 23 more
    customTagCustom tag slug (optional)stringUse any Medium tag slug that is not in the list above. When set, it overrides the Tag selection.
    sortByTag orderstringOrder for tag browsing: newest first, or the most-clapped stories from the past week, month, or year.Default "new"; Allowed new, topWeek, topMonth, topYear
    usernameAuthor username or profile URLstringMedium username (for example towardsdatascience) or a profile URL such as https://medium.com/@towardsdatascience. Used by the author mode.
    publicationPublication slug or URLstringPublication slug as it appears in the URL (for example towards-data-science) or a full publication URL. Used by the publication mode.
    querySearch querystringKeywords to search for across Medium articles. Used by the search mode.Default "artificial intelligence"
    articleUrlArticle URLsstringOne or more article URLs, separated by new lines or commas. Medium URLs, custom-domain Medium articles, and medium.com/p/... links are accepted.
    fromDatePublished on or afterstringOnly keep articles published on or after this ISO date (for example 2025-01-01).
    containsKeywordTitle/preview containsstringOnly keep articles whose title or preview text contains this keyword (case-insensitive).
    excludePaywalledExclude member-only articlesbooleanWhen enabled, member-only (paywalled) articles are skipped.Default false
    maxItemsMaximum articlesintegerMaximum number of article records to save. Pagination stops when this number is reached or the source runs out.Default 5; Allowed 1 to 5000

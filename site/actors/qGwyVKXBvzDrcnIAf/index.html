Google Patents Inventor, Assignee & Citation Lookup

Pull complete patent records straight from Google's aggregated patent index — covering USPTO, EPO, WIPO, JPO, CNIPA, KIPO, and dozens of other offices — by free-text query, inventor, assignee, classification code, citation graph, publication number, or a pasted patents.google.com URL.

What this actor does

  • Searches the full Google Patents corpus by keyword, inventor name, assignee/company, or CPC/IPC classification code, or fetches one or more specific patents by publication number or URL.
  • Walks a patent's citation graph one hop at a time — backward (what it cites), forward (what cites it), or both.
  • Pulls full claims, abstract, description text, and classification codes when fetchFullDetails is enabled, rather than just the search snippet.
  • Filters any mode by jurisdiction, legal status, filing/publication date range, and sorts by relevance, newest, or oldest.
  • Fields Google Patents doesn't expose for a given patent (such as grantDate on a pending application) are left out of that record.

Output per patent

Field Description
publicationNumber, country Canonical publication number and filing-jurisdiction prefix
title, snippet, abstract Patent title, search snippet, and full abstract
description Specification text (truncated at 50,000 characters)

inventors, primaryInventor All listed inventors, and the first-listed one
assigneesOriginal, assigneesCurrent, primaryAssignee Assignees at filing, current assignees after reassignment, and the first one
priorityDate, filingDate, publicationDate, grantDate, expirationDate Key dates in the patent's lifecycle
applicationNumber The application's own filing number
legalStatus Active / Expired / Pending, when shown
classifications CPC and IPC codes
backwardCitations, backwardCitationCount Patents this one cites, with publication number, title, dates, assignee
forwardCitations, forwardCitationCount Patents that cite this one
familyJurisdictions Per-country status of patent family members
language Rendered-metadata locale
pdfUrl, thumbnailUrl, figureUrls PDF link, front-page figure, and all embedded figures (search modes)
patentUrl Canonical patents.google.com URL
recordType patent or citation
siteName Always Google Patents
scrapedAt ISO 8601 timestamp of when the record was scraped

Use cases

  • Prior-art search — find existing patents in a technology area before filing
  • IP landscaping — map a classification code or technology space across assignees
  • Competitive intelligence — pull a competitor's full patent portfolio by assignee name
  • Citation analysis — trace which patents a key invention builds on, or who later cites it
  • Freedom-to-operate checks — review legal status and expiration dates for patents in a space

FAQ

Does this scrape USPTO, EPO, or WIPO directly? No — it reads Google Patents, which already aggregates USPTO, EPO, WIPO, JPO, CNIPA, KIPO, and dozens of other offices into one searchable index, so a single run can span jurisdictions.

How many patents can I get in one run? Up to maxItems, capped at 1000. For larger pulls, split the query across date ranges or jurisdictions and run multiple times.

Does fetchFullDetails slow the run down? Yes — it adds a full page fetch per patent to retrieve claims, abstract, and citations. Leave it off if the search snippet (title, dates, primary inventor/assignee, thumbnail) is enough.

Are the PDF links usable directly? Yes — pdfUrl points to a public Google Cloud Storage object with no authentication or hotlink restriction.

Is citation traversal recursive? No, it's a single hop: byCitation returns the direct citations of the publication number(s) you supply. To go further, feed the returned publication numbers back in as a new run.

Why did my non-English search return English metadata? Google Patents infers query language automatically; set language to bias the rendered metadata to a different locale.

Do I need a login or API key? No — every mode reads Google Patents' public pages.

Is this affiliated with Google or Google Patents? No. This is an independent, third-party actor that reads Google Patents' public data and is not operated by or affiliated with Google.

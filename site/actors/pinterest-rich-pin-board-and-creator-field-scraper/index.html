    Pinterest Rich Pin, Board & Creator Field Scraper is an Apify Actor published by Dataspryva. It accepts 22 input fields, none of them required at the top level. Each result can carry up to 56 declared fields, including record_type, recordType, id, title, url and pinner_username. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per record”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (detailed pin). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 20000) and maxComments (default 10, maximum 20000) cap how many results a run collects, and so what it costs.

    What it costs

    Pinterest Rich Pin, Board & Creator Field Scraper uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 22 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeWhat to collectstringChoose a collection type. Auto-detect accepts mixed public Pinterest links.Default "auto"; Allowed auto, pinDetail, comments, searchPins, searchVideos, searchUsers, searchBoards, userProfile and 6 more
    keywordsSearch wordsarrayOne or more words or phrases for search modes.Default []
    pinUrlsPin URLs or IDsarrayPublic Pin links or numeric Pin IDs.Default []
    usernamesPinterest usernamesarrayUsernames, @usernames, or public profile links.Default []
    boardUrlsBoard URLsarrayPublic board links or username/board-name paths.Default []
    searchSearch QuerystringKeyword to search on Pinterest. Results will be pins matching this query.Example "cats"
    startUrlsPinterest URLsarrayList of Pinterest URLs to scrape. Supports pin URLs, user profile URLs, board URLs, and search URLs.Example []
    maxItemsMax ItemsintegerMaximum number of Pins/source records to collect. Comment rows are additional and are capped per Pin by maxComments. Set to 0 for unlimited.Default 50; Allowed 0 to 20000
    maxPagesMax pagesintegerMaximum pagination pages per search, profile, or board. 0 means continue until Pinterest has no next page.Default 0; Allowed 0 to 2000
    minSavesMinimum savesintegerKeep Pins only when Pinterest supplies at least this many saves.Allowed 0 to 10000000
    minCreatorFollowersMinimum creator followersintegerKeep Pins only when Pinterest supplies a creator follower count at or above this value.Allowed 0 to 1000000000
    verifiedOnlyVerified accounts onlybooleanKeep only rows explicitly marked verified by Pinterest.Default false

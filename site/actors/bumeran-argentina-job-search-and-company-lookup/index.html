    Bumeran Argentina Job Search & Company Lookup is an Apify Actor published by Dataspryva. It accepts 16 input fields, and mode is required. Each result can carry up to 10 declared fields, including recordType, jobId, companyId, title, companyName and location. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output fields”, “Input”, “Use cases”, “FAQ” and “Limitations”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (remote senior developer jobs). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 50, maximum 1000) caps how many results a run collects, and so what it costs.

    What it costs

    Bumeran Argentina Job Search & Company Lookup uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

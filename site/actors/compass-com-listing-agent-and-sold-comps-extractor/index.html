    Compass.com Listing, Agent & Sold-Comps Extractor is an Apify Actor published by Dataspryva. It accepts 24 input fields, and mode is required. Each result can carry up to 20 declared fields, including address, city, state, price, bedrooms and bathrooms. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per listing”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (search a city for sale, 3+ beds, under $600k). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxItems (default 60, maximum 5000) caps how many results a run collects, and so what it costs.

    What it costs

    Compass.com Listing, Agent & Sold-Comps Extractor uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 24 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredBrowse listings for a location, fetch full details for specific listing URLs, or fetch agent profiles (bio + active/sold listings).Default "search"; Allowed search, listingDetail, agentProfile
    locationLocation (mode=search)stringCity, neighborhood, or ZIP to browse. Accepts a plain name like Austin, TX / Miami Beach, FL, or a Compass URL slug like austin-tx / austin-tx-78734. A ZIP code alone (e.g. 78734) is not enough - append it to a city slug (austin-tx-78734) or just use City, ST.Default "Austin, TX"
    listingCategoryFor sale or for rentstringBrowse homes for sale, or homes for rent.Default "forSale"; Allowed forSale, forRent
    propertyTypeProperty typestringRestrict results to a property type.Default "any"; Allowed any, singleFamily, condos, townhomes, multiFamily, land, luxury, coop
    minBedsMinimum bedroomsstringOnly show listings with at least this many bedrooms.Default "any"; Allowed any, 1, 2, 3, 4, 5, 6
    minPriceMinimum price ($)integerDrop listings priced below this amount (sale price or monthly rent).Allowed 0 to 100000000
    maxPriceMaximum price ($)integerDrop listings priced above this amount (sale price or monthly rent).Allowed 0 to 100000000
    minBathsMinimum bathroomsnumberDrop listings with fewer bathrooms than this (e.g. 1.5).Allowed 0 to 20
    minSqftMinimum square feetintegerDrop listings smaller than this many square feet.Allowed 0 to 100000
    maxSqftMaximum square feetintegerDrop listings larger than this many square feet.Allowed 0 to 100000
    openHouseOnlyOpen houses onlybooleanOnly show listings with a scheduled open house.Default false
    comingSoonOnlyComing soon onlybooleanOnly show listings marked "Coming Soon" (not yet officially on market).Default false

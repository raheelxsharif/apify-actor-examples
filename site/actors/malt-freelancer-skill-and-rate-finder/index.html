    Malt Freelancer Skill & Rate Finder is an Apify Actor published by Dataspryva. It accepts 22 input fields, and mode is required. Each result can carry up to 18 declared fields, including profileId, name, headline, dailyRateEur, currency and avgRating. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per freelancer”, “Input”, “How coverage works”, “Backward compatibility” and “Limitations”.

    What you get

    What it costs

    Malt Freelancer Skill & Rate Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    All 22 fields of the published input schema, in the publisher's order. Required fields are marked. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    modeModestring requiredSearch the Malt directory, or enrich a list of profile URLs you already have.Default "searchFreelancers"; Allowed searchFreelancers, byProfileUrls
    searchQuerySearch query (skill or role)stringSkill, role or keyword to search for, e.g. react, python developer, data scientist. Used in mode=searchFreelancers.Default "python developer"
    searchQueriesAdditional search queriesarrayOptional list of extra queries searched after searchQuery. Each query is searched separately and results are de-duplicated, e.g. ["react", "typescript", "node.js"].Default []
    locationLocation (city, region or country)stringOnly keep freelancers whose city, region or country matches this text, e.g. Paris, Berlin, Spain. Leave empty for all locations.Default ""; Example "Berlin"
    profileUrlsProfile URLs (mode=byProfileUrls)arrayMalt profile URLs, slugs or profile URLs from any Malt market, e.g. https://www.malt.fr/profile/johndoe. Used in mode=byProfileUrls.Default []
    marketMarket (Malt country)stringWhich Malt marketplace to search. This also sets the profile URL domain and the search API country filter.Default "de"; Allowed com, fr, de, es, be, nl
    minRateMinimum daily rate (EUR)numberOnly include freelancers whose publicly listed daily rate is at or above this amount, in EUR.Allowed 0 to 100000
    maxRateMaximum daily rate (EUR)numberOnly include freelancers whose publicly listed daily rate is at or below this amount, in EUR.Allowed 0 to 100000
    experienceLevelExperience levelstringFilter by Malt's experience band. ANY includes every level.Default "ANY"; Allowed ANY, ENTRY, INTERMEDIATE, EXPERT, EXPERT_PLUS
    categoryCategory key (optional)stringMalt category key, e.g. backend_developer, frontend_developer, data_scientist. Leave empty to search all categories.Default ""
    specialitySpeciality / skill key (optional)stringMalt speciality key, e.g. React.js, Python, SEO. Leave empty to search all specialities.Default ""
    businessSectorClient business sectorstringFilter by the client sectors a freelancer has worked in. ANY includes every sector.Default "ANY"; Allowed ANY, it, software, e-commerce, high-tech, consulting, banking-insurance, education and 13 more

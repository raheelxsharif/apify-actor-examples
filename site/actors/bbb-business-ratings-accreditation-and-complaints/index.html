    BBB Business Ratings, Accreditation & Complaints Finder is an Apify Actor published by Dataspryva. It accepts 13 input fields, none of them required at the top level. Each result can carry up to 16 declared fields, including name, rating, accreditationStatus, primaryCategory, phone and emails. It costs $0.99 per 1,000 results on Apify's Free plan and $0.49 on the Business plan.

    What it does

    The full README, with every mode, example and answer the publisher documents, is on the Apify Store page. Its sections: “What this actor does”, “Output per business”, “Input”, “Use cases” and “FAQ”.

    Run it

    Set APIFY_TOKEN to your Apify API token, then run the Actor with the input below (accredited plumbers in chicago, a or better). Each run is billed to your Apify account. The export tutorial turns the results into a CSV file or an Excel workbook.

    Keep the first run small: maxRecordsGlobal (default 3, maximum 5000) and maxRecordsPerLocation (default 50, maximum 5000) cap how many results a run collects, and so what it costs.

    What it costs

    BBB Business Ratings, Accreditation & Complaints Finder uses pay-per-event pricing: a fee for each result saved to the dataset, plus a start fee per run. Paid Apify plans pay less per result. The start fee is charged once per GB of run memory (at least once); the default run uses 4 GB, so a run starts with 4 start events, as the run totals include. You also pay Apify platform usage (compute and proxy) for the run, which these totals do not include.

    Input reference

    All 13 fields of the published input schema, in the publisher's order. No field is required at the top level, but the README can describe conditions. Download the input schema as JSON.

    Input fields in the published schema
    FieldTypeDescription
    keywordsKeywordsstringWhat to search for on BBB: a business category (plumber, electrician, roofing, auto repair) or a company name. Required unless startUrls is set.Default "plumber"
    startUrlsStart URLs (optional)arrayBBB search or business-profile URLs to scrape instead of a keyword search. Search URLs keep the keyword, location, country, accreditation, sort and state parameters they contain, and every result page is followed. Profile URLs return one fully detailed business each. When this is set, Keywords, Locations, Country, Sort and State are ignored.
    locationsLocationsarrayOptional cities or postal codes, e.g. 'Chicago, IL', '10001', 'Toronto, ON'. Each is searched separately; businesses found twice are returned once. Leave empty for a country-wide search.
    countriesCountrystringBBB directory to search.Default "US"; Allowed US, CA
    maxRecordsGlobalMax businesses (total)integerMaximum number of businesses for the whole run, across all locations.Default 3; Allowed 1 to 5000
    maxRecordsPerLocationMax businesses per locationintegerMaximum per location (0 = no per-location limit). BBB shows up to 225 businesses per search, so use several locations for more.Default 50; Allowed 0 to 5000
    includeDetailsInclude profile detailsbooleanAlso open each business's BBB profile for website, emails, contacts, dates, hours, licences, social links, reviews and complaints. Turn off for faster runs with search-listing data only.Default true
    includeBranchLocationsInclude branch locationsbooleanBBB lists some businesses once per location (branches, franchises, service addresses). Off: one record per business. On: one record per listed location, each with its own address, phone and coordinates.Default false
    minRatingMinimum BBB ratingstringOnly businesses rated at least this grade (businesses without a rating are excluded when set).Default "any"; Allowed any, A+, A, A-, B+, B, B-, C+ and 6 more
    accreditedOnlyBBB Accredited businesses onlybooleanOnly return BBB Accredited Businesses.Default false
    sortBySort bystringOrder of BBB search results.Default "relevance"; Allowed relevance, rating, distance, aToZ, zToA
    stateFilterState / province filterstringOptional two-letter state or province code (e.g. IL, ON) to keep results from one state when a search area spans several.
    proxyConfigurationProxy configurationobjectOptional. BBB is fetched directly first; Apify proxies are used automatically only if needed. Choose your own proxy to use it as the fallback, or 'No proxy' to stay direct.

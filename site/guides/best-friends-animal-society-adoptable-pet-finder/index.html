    Best Friends Animal Society Adoptable Pet Finder: export to CSV, Excel or JSON

    Find adoptable dogs and cats at Best Friends Animal Society's adoption centers by location, name, or pet ID, with breed, age, photos, and an adoption link.

    This tutorial runs Best Friends Animal Society Adoptable Pet Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 7 columns its publisher puts first: name, species, primaryBreed, age, sex, location and sourceUrl.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript

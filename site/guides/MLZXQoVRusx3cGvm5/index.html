professionstringoptionalUniversal profession mapped to the selected market's Houzz category. Used in search mode.
categorySlugstringoptionalExact Houzz category slug, used instead of the mapped profession, e.g. `general-contractor`, `architekten`, `architectes`. Use a direct directory URL if you are unsure.
keywordstringoptionalOptional keyword filter for professional search, or the search term for photo mode.
sortBystringoptionalServer-side order for professional directory results.
minRatingnumberoptionalDrop professionals below this star rating. Set 0 to keep all.
minReviewCountintegeroptionalDrop professionals with fewer reviews. Set 0 to keep all.

profileUrlsarrayoptionalDirect Houzz professional profile URLs, including localised paths such as /experten/, /professionnels/ and /profesionales/.
photoUrlsarrayoptionalDirect Houzz photo detail URLs. Use mode=photos.

photoStylestringoptionalOptional design style filter for photo inspiration.
includeReviewsbooleanoptionalAttach review history to each professional record.
maxReviewsPerProintegeroptionalReview cap per professional. Set 0 to fetch the full history (up to 1,024).
fetchDetailsbooleanoptionalOpen each professional profile for services, awards, socials, counts and licensing. Turn off for directory-card-only records.
fetchPhotoDetailsbooleanoptionalOpen each photo for full image sizes, owner, location and question count.

maxPagesintegeroptionalOptional page cap. Set 0 to use the source ceiling: 100 directory pages, 30 keyword pages, 250 photo pages or 10 photo keyword pages.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/MLZXQoVRusx3cGvm5/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

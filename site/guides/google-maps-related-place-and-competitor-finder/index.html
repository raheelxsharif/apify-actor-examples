    Google Maps Related Place & Competitor Finder: export to CSV, Excel or JSON

    Find the related and 'people also search for' places Google Maps shows on a business, hotel, or landmark page. Get each related place's name, rating, review count, category, coordinates, and image, linked back to the place you searched.

    This tutorial runs Google Maps Related Place & Competitor Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, relationMode, relationQuery, relatedSectionType, rank, name, placeId and featureId.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.

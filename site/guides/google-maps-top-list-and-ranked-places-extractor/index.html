Use Google Maps Top List & Ranked Places Extractor with Python

Pull the ranked places from a Google Maps Top list query like 'Top hotels in Paris', or from a list/search URL, with optional full place-page enrichment.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringoptionalUse 'topList' for ranked queries like 'Top hotels in Paris'. Use 'listUrl' for a shared Google Maps list link or a Maps search URL.
queriesarrayoptionalRanked list queries. For example: 'Top hotels in Paris', 'Best coffee in Brooklyn', 'Things to do in Tokyo'. Each query is scraped separately.
locationstringoptionalOptional city, neighborhood or region appended to every query when it is not already mentioned.
listUrlsarrayoptionalPublic Google Maps shared-list links (google.com/maps/placelists/list/...) or Maps search URLs. Short maps.app.goo.gl links are resolved automatically.
maxResultsintegeroptionalMaximum places to return per query or list. The public feed may expose fewer; lists are returned up to the source window.
enrichDetailsbooleanoptionalAdds Plus Code, rating histogram, photos, amenities, price range, booking links, closure state and hotel details. Turn it off for the fastest, smallest runs using list-feed data only.
languagestringoptionalGoogle Maps interface language. Names, categories, addresses and hours are localized.
minRatingnumberoptionalDrop places with a lower rating or no published rating.
maxRatingnumberoptionalDrop places with a higher rating.
minReviewsintegeroptionalDrop places with fewer reviews or no published review count.
maxReviewsintegeroptionalDrop places with more reviews.
openNowbooleanoptionalKeep only places Google currently marks as open.
hasWebsitebooleanoptionalKeep only places with a published website.
hasPhonebooleanoptionalKeep only places with a published phone number.
includeClosedbooleanoptionalWhen disabled, permanently closed places are dropped. This needs full place details.
nameFilterstringoptionalKeep only places whose name contains this text (case-insensitive).
excludeCategoriesarrayoptionalDrop places whose primary or secondary category contains any of these words.
includeCategoriesarrayoptionalKeep places whose primary or secondary category contains any of these words.
countryCodesarrayoptionalKeep places in these two-letter countries, e.g. FR, US, JP. Empty means all countries.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/YpWNF6hudIGBsowV8/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

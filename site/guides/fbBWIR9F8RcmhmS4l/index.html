Use Y Combinator Startup Directory with Founders & Jobs with Python

Search Y Combinator's company directory by batch, industry, status, or keyword, and get each company's profile, founders, and open job postings. No login required.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "directoryUrl": "https://www.ycombinator.com/companies",
  "maxItems": 3,
  "regions": [],
  "scrapeFounders": true,
  "scrapeOpenJobs": true,
  "tags": []
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
directoryUrlstringrequiredY Combinator company directory URL. Default scrapes the full directory. You can paste a filtered URL (e.g. https://www.ycombinator.com/companies?batch=S24&industry=AI).
querystringoptionalOptional free-text query. When set, filters the directory using the ?q=<query> Algolia search (matches name, description, tags).
batchstringoptionalFilter by YC batch code. 'any' returns every batch. Codes: S=Summer, W=Winter, F=Fall followed by two-digit year (e.g. S24 = Summer 2024).
industrystringoptionalFilter by industry (e.g. 'B2B', 'Consumer', 'Fintech', 'Healthcare', 'Industrials', 'Real Estate and Construction'). Case-sensitive, exact match against YC's industry facets.
statusstringoptionalFilter by company operating status. 'any' returns all statuses.
scrapeFoundersbooleanoptionalInclude each company's founders (name, title, bio, LinkedIn, Twitter). Requires an extra detail-page fetch per company.
scrapeOpenJobsbooleanoptionalInclude each company's open job postings (title, URL, location, salary, equity, skills, visa). Shares the same detail-page fetch as founders.
regionsarrayoptionalOptional region filter (case-insensitive substring match against the company's location). Example: ["San Francisco", "New York"].
tagsarrayoptionalOptional tag filter (case-insensitive). Matched against industry, subIndustry and any tag arrays Algolia returns. Example: ["B2B", "Fintech"].
highlightBlackFoundersbooleanoptionalIf true, only return companies flagged as having Black founders. Requires the signal to be present on Algolia — companies without the flag are not fabricated.
highlightWomenFoundersbooleanoptionalIf true, only return companies flagged as having women founders. Requires the signal to be present on Algolia.
highlightHispanicFoundersbooleanoptionalIf true, only return companies flagged as having Hispanic / Latino founders. Requires the signal to be present on Algolia.
maxItemsintegeroptionalMaximum number of companies to return.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/fbBWIR9F8RcmhmS4l/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

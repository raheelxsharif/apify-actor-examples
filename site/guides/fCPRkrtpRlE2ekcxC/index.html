Use Trading Economics Market, Indicator & Calendar Scraper with Python

Get live commodity, currency, stock index, bond yield, and crypto quotes, country economic indicators and forecasts, global rankings, the economic calendar, public holidays, and corporate earnings releases from Trading Economics.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhich Trading Economics surface to collect.
marketTypestringoptionalWhich live market table to collect.
categorystringoptionalRestrict the market table to one category or region. Commodities use Energy/Metals/Agricultural/Industrial/Livestock/Index/Electricity; currencies, stocks and bonds use Major/Europe/America/Asia/Oceania/Africa; crypto uses Crypto/BTC/ETH; shares use Top Gainers/Top Losers. Leave unset for all rows.
countriesarrayoptionalOne or more countries. Required for countryIndicators, countryForecast, creditRatingHistory and bondYields. Optional for calendar, holidays and earningsCalendar (leave empty for global data).
indicatorCategorystringoptionalRestrict country indicators or forecasts to one category. `markets` only appears on the forecast page and `health` only on the indicators page. Leave unset for all categories.
rankingIndicatorsarrayoptionalOne or more indicators to rank across every country. The `rating` indicator returns sovereign credit ratings instead of a numeric series.
indicatorHistoryUrlsarrayoptionalTrading Economics indicator pages as full URLs or `country/indicator-slug`, e.g. `united-states/inflation-cpi` or `https://tradingeconomics.com/germany/unemployment-rate`. Up to 100 pages.
marketSymbolsarrayoptionalSymbols such as `CL1:COM`, `AAPL:US`, `USGG10YR:IND` or full Trading Economics market URLs. Up to 100 symbols.
forecastAssetClassstringoptionalWhich public forecast table to collect.
searchQuerystringoptionalKeyword used to resolve indicators and markets, e.g. `gold`, `inflation`, `EURUSD`. Required for mode=search.
historySpanstringoptionalHow far back to fetch historical series. `max` returns the full available history.
marketIntervalstringoptionalIntraday or daily interval for market history. Leave on `auto` to use the span's natural frequency.
searchKeywordstringoptionalCase-insensitive substring filter on the record name/title (instrument, indicator, event, company or news headline). Leave blank for no filtering.
minChangePercentnumberoptionalOnly keep instruments whose daily percent change is at least this value. Enter -5 for -5%.
maxChangePercentnumberoptionalOnly keep instruments whose daily percent change is at most this value.
dateFromstringoptionalISO date (YYYY-MM-DD). Lower bound for calendar, holidays, earnings, credit-rating history, bond yields and history points. For calendar this fetches the requested range, not just the default page.
dateTostringoptionalISO date (YYYY-MM-DD). Upper bound for the same date-aware modes.
importancestringoptionalKeep only releases/news at this market-impact level. Leave unset for all levels.
maxItemsintegeroptionalHard cap on emitted records. History modes cap the total number of points across all requested series.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/fCPRkrtpRlE2ekcxC/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

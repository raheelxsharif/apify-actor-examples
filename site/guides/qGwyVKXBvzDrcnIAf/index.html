Use Google Patents Inventor, Assignee & Citation Lookup with Python

Search Google's aggregated patent index by keyword, inventor, assignee, classification code, or citation graph, and get abstract, claims, dates, family, and citations for each matching patent.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhich lookup axis to use.
querystringoptionalFree-text search query — same syntax as the Google Patents site search box.
publicationNumberstringoptionalPatent publication number, e.g. US11704715B2, EP3789012A1, WO2020012345A1, CN101234567A. The actor accepts any country prefix supported by Google Patents.
publicationNumbersarrayoptionalOptional: list multiple publication numbers to fetch in one run (mode=byPatent) or to seed citation traversal (mode=byCitation).
inventorstringoptionalInventor name, e.g. "Geoffrey Hinton".
assigneestringoptionalAssignee or applicant company, e.g. "Google", "Apple Inc", "IBM".
classificationstringoptionalCPC or IPC code, e.g. H04L9/06 or G06N3/00. The Google Patents site search uses CPC=... internally.
citationDirectionstringoptionalWhich side of the citation graph to walk: backward (cited by this patent), forward (citing this patent), or both.
urlsarrayoptionalDirect patents.google.com URLs (search results, patent pages, or inventor / assignee search URLs).
countrystringoptionalRestrict search modes to a specific patent office. (any) = no restriction.
languagestringoptionalTranslate the returned patent metadata to this language when Google Patents has a translation available. Patent text is multilingual; this only affects the rendered locale.
statusstringoptionalRestrict results by legal status of the family.
sortBystringoptionalSort order for search modes.
filingDateFromstringoptionalDrop patents filed before this date.
filingDateTostringoptionalDrop patents filed after this date.
publicationDateFromstringoptionalDrop patents published before this date.
publicationDateTostringoptionalDrop patents published after this date.
fetchFullDetailsbooleanoptionalFor search modes (searchPatents, byInventor, byAssignee, byClassification): also fetch each patent's full HTML page for abstract, claims, classifications, citations. Adds 1 HTTP request per patent.
maxItemsintegeroptionalHard cap on emitted records.
useProxybooleanoptionalRoute requests through Apify proxy. Google Patents is generally accessible without a proxy; enable only if direct fetches return 429 / 403.
autoEscalateOnBlockbooleanoptionalIf direct fetches start returning 403 / 429, automatically retry through Apify proxy.
proxyConfigurationobjectoptionalApify proxy configuration. Used when useProxy is enabled or auto-escalation triggers.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/qGwyVKXBvzDrcnIAf/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

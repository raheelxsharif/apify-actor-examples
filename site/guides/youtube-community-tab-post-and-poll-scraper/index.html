    YouTube Community Tab Post & Poll Scraper: export to CSV, Excel or JSON

    Read a YouTube channel's Community tab and get structured records for every text post, image, poll, and shared video, with vote counts and optional comment threads.

    This tutorial runs YouTube Community Tab Post & Poll Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 7 columns its publisher puts first: postId, postType, channelName, contentText, publishedAt, likeCount and commentCount.

    Fix common problems

    Why does a channel stop at 200 posts?

    YouTube's Posts tab only serves the newest 200 posts. There is no public way to page further back. If you already have an older post URL or ID, the postDetails and postComments modes can still read it.

    Why are poll percentages missing?

    YouTube only reveals per-choice votes and percentages to signed-in viewers who voted in that poll. Logged out, the page carries the choices and a rounded total vote count, which the actor returns.

    Why does a post have no comment count?

    The creator turned comments off. The record then carries commentsDisabled: true instead of inventing zero.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

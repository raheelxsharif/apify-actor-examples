    Rent the Runway Designer Rental Catalog Extractor: CSV and Excel export

    Browses or searches Rent the Runway's designer rental catalog by category, designer, occasion, color, and price, returning rental price, retail price, sizes in stock, and ratings.

    This tutorial runs Rent the Runway Designer Rental Catalog Extractor through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: itemName, designer, rentalPrice, retailPrice, category, rating, sizesAvailable and inStock.

    Fix common problems

    Do I need an account, cookie or proxy?

    No. The catalog, product pages and review endpoints used here are public. The actor connects directly and manages any fallback internally.

    Why is sizesAvailable missing on some records?

    It is only emitted when availability was checked. sizesOffered still lists every size the style was made in. Availability changes by date, duration and ZIP.

    Why do some styles disappear when I change the date?

    The one-off catalog only includes styles with at least one available size for that date window. Sundays are not valid rental start dates; the actor falls back to the default date and says so in the run message.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

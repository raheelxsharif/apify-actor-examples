    Fix common problems

    Why is the agent mobile missing on some records?

    Mobile numbers are only published on some listing pages. Project and new-launch listings usually show a developer contact instead, so those records carry developer fields rather than agent fields. Email addresses are not published at all.

    Why does one listing have price and another only priceMin/priceMax?

    A fixed asking price becomes price; a range or a project with several unit prices becomes priceMin/priceMax. priceText always keeps the label shown by the source, including "Price on ask" or "Starting From".

    Why is floorAreaUnit sometimes sqft and sometimes sqm?

    Singapore and Malaysia publish square feet; Thailand publishes square metres. Both floorAreaSqft and floorAreaSqm are provided so records from different markets can be compared directly.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

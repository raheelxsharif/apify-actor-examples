    Wallapop Listings by Keyword, Item & Seller: export to CSV, Excel or JSON

    Searches Wallapop by keyword and location, fetches a specific item by URL, or pulls a seller's full listing set, returning price, location, images, and seller details.

    What people export it for

    • Price research: compare asking prices for the same product across Spanish, Italian and Portuguese cities.
    • Resale sourcing: follow a category with a price cap and spot under-priced listings early.
    • Seller vetting: read seller ratings, review history and public business details before buying.
    • Catalogue monitoring: export a shop's full active inventory to a spreadsheet on a schedule.
    • Demand analysis: rank listings by views, favourites and conversations.
    • Marketplace analytics: build a clean dataset of condition, attributes and geography.

    Fix common problems

    Do I need to configure a proxy?

    No. The actor connects directly to Wallapop; no proxy configuration is required.

    Why are some fields missing from a record?

    Wallapop omits data for some listings, and some fields are mode-specific. Empty fields are left out rather than returned as null. Turn on Include item details for condition, attributes, views and favourites.

    Why did I get fewer rows than maxItems?

    Wallapop exhausted the matching results, or the country filter removed cross-border listings. The run status reports the requested and returned counts honestly. The actor never fabricates rows.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

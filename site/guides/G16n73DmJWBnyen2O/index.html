Use Goodreads Book, Author & Listopia List Scraper with Python

Look up Goodreads books by URL, search query, or ISBN, or pull every book by an author, in a series, on a Listopia list, shelf, or genre page. Filter by rating, ratings count, publish year, language, genre, or author.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

shelfNamesarrayoptionalPopular shelf names like 'mystery', 'fantasy', 'historical-fiction'. Paginated. (mode=auto, shelves)
genreNamesarrayoptionalGenre names like 'fiction', 'romance', 'mystery'. (mode=auto, genres)
maxItemsintegeroptionalHard cap on total records emitted across all inputs. Books, search results, and listing-page results all count toward this.
maxResultsPerQueryintegeroptionalLegacy field. Use maxItems instead. When set and maxItems is at its default, this value is used as the cap.
minRatingintegeroptionalDrop books with averageRating below this integer threshold (0-5). For finer thresholds (e.g. 4.5), use a higher minRatingsCount filter to surface highly-rated books.
minRatingsCountintegeroptionalDrop books with fewer than N ratings.
publishYearMinintegeroptionalDrop books published before this year.
publishYearMaxintegeroptionalDrop books published after this year.
languagestringoptionalDrop books whose language doesn't contain this string (case-insensitive substring match). E.g. 'en', 'eng', 'English'.
containsGenrestringoptionalDrop books unless one of their genres contains this substring (case-insensitive).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/G16n73DmJWBnyen2O/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

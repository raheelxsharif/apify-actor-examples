    Daraz South Asia Product & Price Finder: export to CSV, Excel or JSON

    Search Daraz products by keyword or category across the Pakistan, Bangladesh, Sri Lanka, and Nepal storefronts, with price, rating, brand and shipping filters.

    This tutorial runs Daraz South Asia Product & Price Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: title, price, currency, rating, reviewCount, brand, sku and freeShipping.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    Get an API token

    Copy it from Console, Settings, API and Integrations.

    Choose the input

    2 fields are required:

    • mode: What to fetch: search keywords, browse a category, or crawl one or more Daraz category/search URLs.
    • countrySite: Which Daraz storefront to scrape.

    Save this as input.json (keyword search with price range):

    Keep the first export small. These fields cap how many results a run collects, and so what it costs:

    • maxItems (default 50, maximum 2000)

    The input reference lists every field.

    Run it and write a CSV

    call() waits for the run to finish; the loop then reads the results page by page.

    Download Excel or JSON

    One request runs it and returns the file with just these columns. It waits at most 300 seconds (then HTTP 408 while the run carries on).

    Fix common problems

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

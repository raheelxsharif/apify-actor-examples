    Bing Maps Local Business Finder: export to CSV, Excel or JSON

    Find restaurants, shops, hotels, and other local businesses on Bing Maps by keyword and city, or by a precise latitude/longitude and radius, with address, phone, website, rating, and coordinates.

    This tutorial runs Bing Maps Local Business Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, category, address, phone, rating, reviewCount, website and openStatus.

    Fix common problems

    Why is minRating sometimes returning zero rows?

    No business in the fetched result set matched the rating, or none had a published rating. Lower the threshold or broaden the query.

    Should I use a proxy?

    Small runs usually work without one. Apify Proxy AUTO is the default to reduce rate limiting on larger runs; you can change it in the input.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

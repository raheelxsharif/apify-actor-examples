Use Google Maps Restaurant Menu & Popular Dish Extractor with Python

Extract a restaurant's menu items from its Google Maps place page - dish name, photo, Popular badge, menu section, and an external menu link when the business has one.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includePlacesWithoutMenu": true,
  "includePopularDishes": false,
  "language": "en",
  "maxItemsPerPlace": 3,
  "maxPlacesPerQuery": 1,
  "mode": "byPlace",
  "placeUrls": [
    "https://www.google.com/maps/place/Sicily+Osteria/@40.7601601,-73.9891863,17z/data=!3m1!4b1!4m6!3m5!1s0x89c25932322b79d3:0x7c085aeae6751161!8m2!3d40.7601601!4d-73.9891863"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionalHow to choose restaurants: paste place URLs/IDs or run a Google Maps search query.
placeUrlsarrayoptionalOne restaurant per line (mode=byPlace). Accepts Google Maps place URLs, short maps.app.goo.gl links, canonical ChIJ Place IDs, and 0x…:0x… feature IDs.
searchQueriesarrayoptionalCuisine + city queries, e.g. `italian restaurant, New York` or `sushi in Austin` (mode=bySearch). Each query returns up to Max places per query.
maxPlacesPerQueryintegeroptionalMaximum restaurants to process from each search query (mode=bySearch).
maxItemsPerPlaceintegeroptionalMaximum menu rows to return for each restaurant.
languagestringoptionalLanguage used for Google Maps place lookups and search results.
includePlacesWithoutMenubooleanoptionalReturn one summary row for a restaurant whose menu cannot be read, so every input place is accounted for.
includePopularDishesbooleanoptionalAlso check Google's own inline menu when it is available and mark dishes Google labels Popular. This uses a browser and is slower.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/tXaH53j6e7DJ08To5/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

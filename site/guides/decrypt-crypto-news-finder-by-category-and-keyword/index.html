Search Decrypt's crypto, Web3, and AI news by keyword or category, or look up specific articles, for full article text, authors, tags, mentioned coins, and featured images.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch. Search matches titles, excerpts and article bodies. The latest mode returns the newest stories.
searchQuerystringoptionalKeyword or phrase matched against article titles, excerpts and bodies (mode=search). E.g. bitcoin, ethereum, NFT.
categorystringoptionalOne Decrypt category slug (mode=browseByCategory and as a filter in other modes). Leave empty for any category.
categoriesarrayoptionalFilter by several category slugs at once. Applies to search, latest, tag, coin and author modes.
tagSlugsarrayoptionalFilter by Decrypt tag slugs, e.g. bitcoin, ethereum, regulation. Tag names are not accepted; use the slugs returned in each record.
coinSlugsarrayoptionalFilter by coin slugs, e.g. bitcoin, ethereum, solana. Names and ticker symbols are also accepted and mapped to slugs. The source can match articles with no explicit coin relation; those rows omit coins and coinSlugs.
authorSlugsarrayoptionalFilter by author slugs, e.g. jose, stephengraves. Author names are not accepted; use the slugs returned in each record.
articleIdsarrayoptionalArticle IDs or decrypt.co URLs (mode=byId). Accepts bare IDs, /id/slug, localized /es/id/slug, ?p=id and /resources/slug URLs.
localestringoptionalArticle language. Leave empty to include every locale.
dateRangeFromstringoptionalOnly articles published on or after this date (YYYY-MM-DD). The date range is applied by the source.
dateRangeTostringoptionalOnly articles published on or before this date (YYYY-MM-DD). The date range is applied by the source.
sortBystringoptionalNewest first, oldest first, or best match. Best match needs a search query; otherwise newest is used.
includeContentbooleanoptionalInclude full HTML and plain-text article bodies, TL;DR content and word count. Turn off for a lighter dataset.
onlyNewbooleanoptionalSkip article IDs returned by earlier runs of this actor. Useful for scheduled monitoring. State is kept automatically.
maxItemsintegeroptionalMaximum number of articles to return (1-10,000).
proxyConfigurationobjectoptionalOptional. Leave off for a direct connection; the actor does not require a proxy.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/khuWc0CVpBIzolNFr/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

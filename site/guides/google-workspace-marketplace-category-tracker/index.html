    Google Workspace Marketplace Category Tracker: export to CSV, Excel or JSON

    Track ranked apps in any Google Workspace Marketplace category. Returns app name, developer, rating, review count, pricing model, categories, description, icon URL and direct app URL - sorted by rank.

    This tutorial runs Google Workspace Marketplace Category Tracker through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, rankInCategory, name, developer, rating, reviewCount, installCount and pricingModel.

    Fix common problems

    Do I need a Google account, API key or proxy?

    No. Every field comes from public marketplace pages and their embedded JSON. The actor makes direct HTTP requests and needs no credentials.

    Why is rankInCategory missing on some rows?

    Rank comes from the category's default (unsliced) page. Apps that only appear in a later slice have no position on that page, so the field is omitted rather than invented.

    Why do some apps have no pricingModel?

    Some listings do not state pricing. That row simply omits the field instead of guessing "Free".

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

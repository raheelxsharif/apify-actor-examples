    YellowPagesPK Business Directory & Lead Finder: export to CSV, Excel or JSON

    Browse Pakistan's YellowPagesPK.com directory by business category, run a keyword search, or fetch full profiles by listing URL. Get business names, addresses, cities, phone numbers, emails, websites, ratings, and claimed status.

    This tutorial runs YellowPagesPK Business Directory & Lead Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, category, city, country, address, phone, email and website.

    Fix common problems

    Why do some records have no email, website, hours or rating?

    The directory only shows what each business supplied. Email and website appear on profile pages; hours are published by a small minority; ratings exist only after a review. Missing values are omitted, never invented.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

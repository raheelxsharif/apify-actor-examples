Use Hcareers Hotel & Restaurant Job Finder by Category with Python

Search Hcareers hospitality job listings by keyword, location, state/province, or 26 job categories, with employment-type and remote filters, full descriptions, and parent-brand details.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "employerUrls": [],
  "employmentTypes": [],
  "fetchFullDescription": true,
  "includeEmployerJobs": true,
  "jobUrls": [],
  "keywords": "chef",
  "maxItems": 24,
  "mode": "search",
  "remoteOnly": false
}

FieldTypeRequiredDescription
modestringrequiredWhat to fetch.
keywordsstringoptionalFree-text search terms (job title, skill, employer/brand name). Leave empty to browse by category/state/brand only. (mode=search)
locationstringoptionalCity, region, or landmark to search near (e.g. `New York, NY`, `Miami Beach`). (mode=search)
statestringoptionalRestrict to a US state or Canadian province. Oregon, Puerto Rico and Quebec are kept for older saved tasks; they have no current Hcareers postings. (mode=search)
categorystringoptionalRestrict to a specific hospitality job category. (mode=search)
brandstringoptionalRestrict to jobs at properties of a specific hotel brand or group. (mode=search)
remoteOnlybooleanoptionalOnly remote-eligible positions. On its own this uses Hcareers' dedicated remote list; combined with other filters it keeps only remote matches of the combined search. (mode=search)
employmentTypesarrayoptionalKeep only jobs whose listing badges match one of the selected types. (mode=search)
jobUrlsarrayoptionalDirect Hcareers job posting URLs or job IDs, e.g. `https://www.hcareers.com/jobs/4239412-bell-person` or `4239412`.
employerUrlsarrayoptionalHcareers employer profile URLs or slugs, e.g. `https://www.hcareers.com/omni-hotels-resorts` or `grand-casinos`.
includeEmployerJobsbooleanoptionalAlso collect each employer's open job postings beside its profile. (mode=employers)
fetchFullDescriptionbooleanoptionalIn mode=search, visit each job's detail page for the full description, pay, apply link, photos and property profile. Always on for mode=allJobs and mode=byUrls. (mode=search)
updatedSincestringoptionalOptional cutoff for incremental runs — a date `2026-10-11` or a full timestamp `2026-10-11T08:30:00`. Only jobs whose Hcareers index entry changed on/after it are returned.
maxItemsintegeroptionalHard cap on emitted records (jobs plus employer profiles).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/7RmIU4jIs8a7yOKmM/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

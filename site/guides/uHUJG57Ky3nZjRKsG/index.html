Use Hepsiburada Product Search & Category Price Scraper with Python

Search Hepsiburada by keyword, browse a category page, look up specific product URLs, or find a keyword's top sellers, and get price, rating, discount, and seller details for each product.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredChoose keyword search, category browsing, or product lookup.
searchQueriesarrayoptionalOne or more product searches (mode=search). Each query is collected separately.
categoryUrlsarrayoptionalHepsiburada category page URLs (mode=category), e.g. https://www.hepsiburada.com/laptop-notebook-dizustu-bilgisayarlar-c-98
productUrlsarrayoptionalProduct page URLs, short product URLs, or bare product/SKU IDs (mode=productDetails).
sortBystringoptionalResult order for search and category modes.
minPriceintegeroptionalLowest product price to include, in Turkish Lira.
maxPriceintegeroptionalHighest product price to include, in Turkish Lira.
minRatingstringoptionalOnly include products rated at or above this many stars.
brandsarrayoptionalExact brand names to include, e.g. Lenovo, Asus. Leave empty for all brands.
sellersarrayoptionalExact seller names to include, e.g. Hepsiburada. Leave empty for all sellers.
discountedOnlybooleanoptionalKeep only products Hepsiburada marks as advantageous or discounted.
fastDeliveryOnlybooleanoptionalKeep only products with Hepsiburada's fast-delivery signal.
officialSellersOnlybooleanoptionalKeep only products from authorized or official sellers.
includeProductDetailsbooleanoptionalOpen each product page to add description, specifications, variants, stock count, seller rating, shipping cost, and return policy. One extra request per record.
maximizeCoveragebooleanoptionalSplit broad searches into price bands to go beyond the site's single-query result limit.
maxItemsintegeroptionalMaximum records per search query or category (1-2000). For product lookup it is the total across all URLs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/uHUJG57Ky3nZjRKsG/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

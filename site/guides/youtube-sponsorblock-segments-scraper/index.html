    YouTube SponsorBlock Segments Scraper: export to CSV, Excel or JSON

    Get community-reported SponsorBlock segments for any YouTube video: sponsor reads, intros, outros, self-promos, filler, highlights, and more, with start/end times and votes.

    This tutorial runs YouTube SponsorBlock Segments Scraper through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, videoId, category, actionType, startTime, endTime, durationSeconds and votes.

    The columns you can export

    The Actor's build declares 41 output fields in 3 dataset views ("SponsorBlock segments", "Detailed" and "Summaries"). The export below keeps these, under the labels the publisher gave them:

    Get an API token

    Copy your token from Apify Console, Settings, API and Integrations and keep it in an environment variable rather than in the script.

    Choose the input

    1 field is required:

    • videoUrls: YouTube video URLs or 11-character video IDs. Accepts watch, youtu.be, Shorts, live, embed, and music links. Add multiple videos for a batch.

    Download Excel or JSON

    The API can run the Actor and hand back the dataset as a file in one request. format takes xlsx, csv, json, jsonl, xml or html, and fields keeps only the columns you list. The request waits up to 300 seconds; a longer run answers HTTP 408 and carries on, so use the Python script for big runs.

    Fix common problems

    • HTTP 401: the token is missing or wrong; run echo $APIFY_TOKEN in the same shell.
    • An empty file: open the run in Console and read its log; it usually names the input that matched nothing.
    • Odd characters in Excel: open the CSV through Data, From Text/CSV and pick UTF-8, or download xlsx instead.

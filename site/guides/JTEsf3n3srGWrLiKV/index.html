Use Florida Sunbiz Registry Lookup by Name, Agent & FEI with Python

Look up Florida business entities on the Sunbiz registry by entity name, officer, registered agent, FEI/EIN, document number, ZIP, or street address, and get status, addresses, officers, annual filings, and filed-document links for each match.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "entityStatus": "any",
  "entityType": "any",
  "includeEventHistory": false,
  "maxItems": 2,
  "mirrorFiledDocuments": "none",
  "searchTerms": [
    "publix super markets"
  ],
  "searchType": "entityName"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
searchTypestringrequiredWhich Sunbiz index to search. Applies to the values in `searchTerms`; pasted `startUrls` are fetched directly.
searchTermsarrayoptionalOne or more values for the selected `searchType` (entity names, officer/agent names, FEI/EIN digits, document numbers, ZIP codes, street addresses, or trademark terms). Sunbiz matches names/addresses from the start of its ordered index and returns the nearest entries when there is no exact match; `documentNumber` is the only exact lookup.
startUrlsarrayoptionalOptional Sunbiz detail or search-results URLs to fetch directly. You can mix URLs with `searchTerms` in one run.
entityStatusstringoptionalOnly emit entities with this status. Determined from each entity's detail page.
entityTypestringoptionalKeep only this kind of filing. Useful for hiding trademarks and nearest-name neighbours.
includeEventHistorybooleanoptionalFetch each entity's full filing-event trail (amendments, mergers, reinstatements, dissolutions, old names). Adds one request per entity that has events.
mirrorFiledDocumentsstringoptionalSave copies of filed documents to Apify storage and add a permanent `pdfUrl` to each `filedDocuments` entry. `all` mirrors up to the 20 newest documents per entity.
maxItemsintegeroptionalHard cap on emitted records across all search terms and URLs. Each record requires a detail-page fetch.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/JTEsf3n3srGWrLiKV/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One record per matched Florida entity: identity, status, FEI/EIN, addresses, registered agent, officers/directors, LLC authorized persons, annual reports, event and name history, trademark data, protected series, and optional filed-document PDFs.

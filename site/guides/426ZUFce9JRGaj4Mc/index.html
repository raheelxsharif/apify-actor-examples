Use X Community Activity & Member Finder with Python

Collect public X Community posts, about info, rules and members with no login required. Get the community profile, member count, ranked posts with engagement metrics, authors and media.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "authorVerifiedOnly": false,
  "communityUrls": [
    "https://x.com/i/communities/1493446837214187523"
  ],
  "includeAbout": true,
  "includeActiveMembers": false,
  "includeMembers": false,
  "language": "any",
  "maxMembers": 10,
  "maxPosts": 3,
  "postSource": "all",
  "sort": "top"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
communityUrlsarrayrequiredPaste the links of the X communities you want to collect. Community links look like https://x.com/i/communities/1493446837214187523. You can also paste the numeric community ID on its own.
postSourcestringoptionalWhich public post feed to collect. All merges the popular and media feeds; Top keeps X's ranked posts; Media keeps posts with photos or videos.
sortstringoptionalHow to order the collected posts. Top keeps X's popular order; Latest and Most liked/Viewed re-sort the collected rows.
maxPostsintegeroptionalUpper bound on posts per community. X exposes roughly 1-66 unique public posts per community (typically 20-66), so a larger number is not a guarantee.
includeAboutbooleanoptionalAdd a community row with the name, description, member count, creation date, banner, topic, join policy and rules.
includeMembersbooleanoptionalAdd one row per publicly visible member: the creator, the full exposed moderator list and the community facepile, expanded with public profile details.
includeActiveMembersbooleanoptionalAdd the authors of the collected posts as member rows with role active. This is the cookieless substitute for a full member directory, which requires login on X.
maxMembersintegeroptionalCap on member rows per community when either member option is on. The creator and moderators are kept first.
dateFromstringoptionalOnly keep posts created on or after this date.
dateTostringoptionalOnly keep posts created on or before this date.
minimumLikesintegeroptionalOnly keep posts with at least this many likes.
minimumViewsintegeroptionalOnly keep posts with at least this many views.
minimumRepliesintegeroptionalOnly keep posts with at least this many replies.
minimumRetweetsintegeroptionalOnly keep posts with at least this many retweets.
languagestringoptionalOnly keep posts written in this language.
authorVerifiedOnlybooleanoptionalKeep only posts whose author is verified or blue-verified.
proxyConfigurationobjectoptionalOptional. The actor works without a proxy; use one only for large or repeated runs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/426ZUFce9JRGaj4Mc/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

Questions before you run

Which inputs are required?

The published required fields are communityUrls

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

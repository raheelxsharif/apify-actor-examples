Use LinkedIn Profile Engagement Timeline Scraper with Python

Pull a LinkedIn profile's posts, reposts, comments, and reactions in one run, with the original post's author, text, and link attached to each activity. Needs your own LinkedIn session cookie.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

The published schema does not supply an example for these required fields: cookie. Supply them using the reference documentation before execution.

{
  "activityTypes": [
    "posts",
    "comments",
    "reactions",
    "shares"
  ],
  "profileUrls": [
    "https://www.linkedin.com/in/adam-grant/"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
profileUrlsarrayrequiredLinkedIn profile URLs or usernames. Accepts: https://www.linkedin.com/in/williamhgates/, https://uk.linkedin.com/in/williamhgates, or just the username: williamhgates
cookiestringrequiredYour LinkedIn session cookie. Accepts: (1) the li_at value from browser DevTools, or (2) full cookies JSON array from an extension like EditThisCookie.
activityTypestringoptionalLegacy single-select for backwards compatibility. Prefer 'activityTypes' below. 'all' fetches likes, comments, and posts/reposts in separate passes.
activityTypesarrayoptionalMulti-select activity types to scrape. Leave empty (or include 'all') to scrape posts, comments, reactions, and shares.
minDatestringoptionalOnly include activities on or after this ISO date (e.g. 2024-01-01 or 2024-01-01T00:00:00Z). Leave empty for no lower bound.
maxDatestringoptionalOnly include activities on or before this ISO date. Leave empty for no upper bound.
languagestringoptionalPreferred response language for LinkedIn API requests.
maxActivitiesPerProfileintegeroptionalMaximum number of activity items to scrape per profile (per activity type when 'all' is selected).
proxyConfigurationobjectoptionalOptional Apify proxy configuration. Residential proxy recommended for best results.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/ENtqoTbxwWPCmRg9X/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

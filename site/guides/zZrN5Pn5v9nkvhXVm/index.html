Use Medium Article Discovery & Metadata Extractor with Python

Find Medium articles by tag, author, publication, keyword search or direct URL, returning title, author, tags, preview text, reading time, publish date and paywall status for each.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "excludePaywalled": false,
  "maxItems": 5,
  "mode": "byTag",
  "query": "artificial intelligence",
  "sortBy": "new",
  "tag": "programming"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredChoose how to find articles: browse a tag, list an author's posts, list a publication's posts, search by keyword, or look up article URLs.
tagstringoptionalTag to browse. Pick a common topic or use the matching value in the dropdown; the latest or most-clapped stories for that tag are collected.
customTagstringoptionalUse any Medium tag slug that is not in the list above. When set, it overrides the Tag selection.
sortBystringoptionalOrder for tag browsing: newest first, or the most-clapped stories from the past week, month, or year.
usernamestringoptionalMedium username (for example `towardsdatascience`) or a profile URL such as `https://medium.com/@towardsdatascience`. Used by the author mode.
publicationstringoptionalPublication slug as it appears in the URL (for example `towards-data-science`) or a full publication URL. Used by the publication mode.
querystringoptionalKeywords to search for across Medium articles. Used by the search mode.
articleUrlstringoptionalOne or more article URLs, separated by new lines or commas. Medium URLs, custom-domain Medium articles, and `medium.com/p/...` links are accepted.
fromDatestringoptionalOnly keep articles published on or after this ISO date (for example `2025-01-01`).
containsKeywordstringoptionalOnly keep articles whose title or preview text contains this keyword (case-insensitive).
excludePaywalledbooleanoptionalWhen enabled, member-only (paywalled) articles are skipped.
maxItemsintegeroptionalMaximum number of article records to save. Pagination stops when this number is reached or the source runs out.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/zZrN5Pn5v9nkvhXVm/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

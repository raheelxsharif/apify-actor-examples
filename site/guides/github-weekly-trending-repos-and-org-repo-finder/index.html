Use GitHub Weekly Trending Repos & Org Repo Finder with Python

Find GitHub repositories gaining stars this week, run keyword searches across all public repos, or list an organization's public repos with stars, forks, language, topics and license for each one.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch: GitHub Trending repositories, trending developers, keyword search, an organization's repos, a user's repos, or specific repository details.
sincestringoptionalTime window for trending repositories and developers (mode=trending / developers).
searchQuerystringoptionalKeywords to search in repository names, descriptions and READMEs (mode=search). GitHub search syntax such as `language:` or `topic:` also works.
languagestringoptionalRestrict results to one programming language (all modes except developers; trending uses the language's trending page).
customLanguagestringoptionalOptional free-text GitHub language name that overrides the dropdown above (e.g. `Blade`, `QML`, `Tcl`).
spokenLanguagestringoptionalOnly show trending repos whose README is written in this language (mode=trending).
customSpokenLanguagestringoptionalOptional ISO 639-1 code that overrides the spoken language dropdown (e.g. `fi`, `uk`, `vi`).
orgstringoptionalGitHub organization login or profile URL (mode=orgRepos).
userstringoptionalGitHub user login or profile URL (mode=userRepos).
repoUrlsarrayoptionalRepository links or `owner/repo` paths, one per line (mode=repoDetails).
sortBystringoptionalResult order for search, org and user modes. `Best match` uses GitHub relevance; other values rank by that metric.
minStarsintegeroptionalDrop repositories with fewer stars than this. Set 0 to disable.
pushedWithinDaysintegeroptionalOnly repositories with a push in the last N days. Set 0 to disable (365 = one year).
aiOnlybooleanoptionalKeep repositories related to AI, machine learning, LLMs, computer vision and related topics (all repository modes).
filterTopicsarrayoptionalKeep repositories with at least one of these GitHub topics (e.g. `llm`, `rag`, `pytorch`). Empty = no topic filter.
includeForksbooleanoptionalInclude forked repositories in search, org and user results. Off by default for a clean signal.
includeDeveloperProfilesbooleanoptionalFetch bio, followers, public repo count, company and location for each trending developer (mode=developers). Adds one request per developer.
includeLanguagesbooleanoptionalFetch the byte-count language breakdown for each repository (mode=repoDetails). Adds one request per repository.
includeContributorsbooleanoptionalFetch the top 10 contributors for each repository (mode=repoDetails). Adds one request per repository.
includeReadmebooleanoptionalFetch each repository's README as markdown (mode=repoDetails). Adds one download per repository.
maxItemsintegeroptionalMaximum number of records to return. GitHub search, org and user modes cap at 1,000 results; Trending exposes about 25 per page.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

request = urllib.request.Request(
    "https://api.apify.com/v2/acts/U0CWdV7bxFGtUC1Ne/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

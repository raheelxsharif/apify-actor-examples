    Best Buy Price Drop & Stock Tracker: export to CSV, Excel or JSON

    Search Best Buy by keyword or product URL to get current and regular price, savings, rating, review count, brand, model and stock status for each item in one structured record.

    This tutorial runs Best Buy Price Drop & Stock Tracker through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: sku, name, brand, currentPrice, regularPrice, savings, savingsPercent and onSale.

    Fix common problems

    Do I need a proxy?

    No. There is no proxy field and no proxy setup step. The actor uses a normal browser session and the public price endpoint.

    Why does a SKU sometimes have no rating or image?

    Those values come from the search card. Direct SKU and product-URL lookups skip the grid, so the actor can fill price, stock, name, brand and taxonomy but may not see the card-only fields. Add a keyword search for the richest row.

    Why is availability different from what I see in a store?

    The field tracks Best Buy's online button state. Store pickup and nearby inventory depend on a ZIP code and a different fulfillment call, which this actor does not make.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

Use Vivino Wine Ratings & Tasting Profile Scraper with Python

Search Vivino wines by name, browse by type and country, look up specific vintages by ID, or pull a winery's full catalogue. Get ratings, prices, grapes, tasting notes, and food pairings for each wine.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredWhat to fetch. `search` runs one or more free-text queries; `explore` browses with filters; `byWineId` resolves wine/vintage URLs or IDs; `winery` pages through a producer's catalogue.
searchQueriesarrayoptionalOne or more free-text wine searches (mode=search). Searches match wine, winery, region and grape names. Example: `barolo`, `chateau petrus`, `napa valley cabernet`.
wineIdsarrayoptionalVivino wine/vintage IDs or URLs (mode=byWineId). Accepts 171525306, https://www.vivino.com/w/1167880?year=2022, /vintages/171525306 and /wines/171525306.
winerystringoptionalWinery to scrape (mode=winery). Accepts 1945, michele-chiarlo, or a Vivino winery URL.
wineTypestringoptionalFilter by wine type. Applies to search, explore and winery.
countrystringoptionalFilter wines by country of origin (ISO 2-letter code). Leave empty for all countries.
regionstringoptionalOptional region filter, e.g. `Barolo`, `napa-valley`, or a Vivino region URL. Combine with Country when a name is ambiguous.
grapestringoptionalOptional grape filter, e.g. `Nebbiolo`, `pinot-noir`, or a Vivino grape URL.
minRatingnumberoptionalOnly wines whose displayed rating is at or above this value (0-5).
maxRatingnumberoptionalOnly wines whose displayed rating is at or below this value (0-5). Applied after fetching.
minPricenumberoptionalOnly wines with a current offer at or above this price.
maxPricenumberoptionalOnly wines with a current offer at or below this price. Leave empty for no cap.
orderBystringoptionalHow Vivino orders search and explore results.
orderstringoptionalDescending (highest first) or ascending (lowest first).
includeReviewsbooleanoptionalAttach the latest wine-level Vivino reviews to each record. Reviews span all vintages; each review keeps its own year.
maxReviewsPerWineintegeroptionalHow many latest reviews to attach when Include reviews is on (1-50).
maxItemsintegeroptionalMaximum wine records to emit. Vivino exposes at most 2,500 rows per search/explore query; split broad queries into narrower filters for more.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/g1kkodoLYUEZBw5Kk/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

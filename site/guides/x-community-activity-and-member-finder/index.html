    X Community Activity & Member Finder: export to CSV, Excel or JSON

    Collect public X Community posts, about info, rules and members with no login required. Get the community profile, member count, ranked posts with engagement metrics, authors and media.

    This tutorial runs X Community Activity & Member Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: type, communityName, name, text, author.username, createdAt, likeCount and memberCount.

    Fix common problems

    Why do I get fewer posts than maxPosts?

    X exposes only its ranked and media slices to logged-out visitors and has no working public cursor. The actor returns everything reachable and never fabricates rows.

    Why are dates or counts missing on a few rows?

    Some media-grid rows only expose their date and counts through a second public guest timeline. The actor merges those twins automatically and still omits any value X genuinely does not publish.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

Use Google Maps Business Lead & Email Finder with Python

Find business leads on Google Maps by category, keyword, or location and collect name, address, phone, website, rating, review count, and coordinates. Optionally adds emails and social links found on each business's own website.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "category": "bakery",
  "categoryFilter": [],
  "country": "US",
  "extractEmails": true,
  "language": "en",
  "locationQuery": "",
  "maxContactPagesPerWebsite": 2,
  "maxEmailsPerWebsite": 3,
  "max_results": 3,

FieldTypeRequiredDescription
modestringoptionalSearch Google Maps, look up specific places, or enrich a list of websites you already have.
searchQueriesarrayoptionalNatural-language searches such as 'coffee shops in Austin TX'. Include the place in each phrase, or use the location field below.
locationQuerystringoptionalAdds a shared location to every search phrase, for example 'Austin, TX, USA'. Leave empty when your phrases already name the place.
categorystringoptionalBusiness category such as bakery, dentist or plumber. Used when keyword and search phrases are empty.
keywordstringoptionalCustom search term such as 'boutique coffee' or 'pet grooming'. Takes priority over category.
statestringoptionalUS state for the search. Choose 'All' for nationwide. Ignored for non-US countries.
countrystringoptionalCountry for the search. Other countries can be named directly in a search phrase.
websitesarrayoptionalWebsites to read for contact details, one per line. Bare domains such as example.com are accepted.
placeUrlsarrayoptionalGoogle Maps place links copied from the address bar or a previous export.
placeIdsarrayoptionalCanonical Google Place IDs starting with 'ChIJ'.
max_resultsintegeroptionalMaximum number of leads to save. Google returns a ranked window of roughly 150-220 businesses per search phrase, so a larger request may end when that window ends.
minRatingnumberoptionalKeep only businesses rated at least this value (1.0-5.0). Leave empty for any rating.
extractEmailsbooleanoptionalVisit each business website for public emails, phone numbers and social profiles. Turn off for a faster Maps-only run.
maxEmailsPerWebsiteintegeroptionalMaximum email addresses to keep for one business website.
maxContactPagesPerWebsiteintegeroptionalHomepage plus contact, about, legal, privacy or careers pages to read. More pages find more contacts but take longer.
onlySaveResultsstringoptionalSave every business, only businesses with an email, or only businesses with any contact detail.
categoryFilterarrayoptionalKeep places whose Google Maps category contains all words of at least one entry. Leave empty for no category filter.
websiteFilterstringoptionalKeep all places, only places with a website, or only places without one.
skipClosedPlacesbooleanoptionalCheck Google's public status and leave out permanently or temporarily closed places.
languagestringoptionalLanguage of the Google Maps interface and listing text.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/nzmL4XdPKeDa1Ahe3/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

Use YouTube Community Tab Post & Poll Scraper with Python

Read a YouTube channel's Community tab and get structured records for every text post, image, poll, and shared video, with vote counts and optional comment threads.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "commentSort": "top",
  "includeComments": false,
  "includeDetails": false,
  "includeReplies": false,
  "language": "en",
  "market": "US",
  "maxPosts": 3,
  "mode": "channelPosts",
  "postTypes": [],
  "urls": [
    "https://www.youtube.com/@MrBeast"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionalChoose channel posts, one post per URL/ID, or comments from post URLs/IDs.
urlsarrayoptionalChannel URLs, @handles or channel IDs when mode=channelPosts. Post URLs or post IDs when mode=postDetails/postComments.
maxPostsintegeroptionalMaximum posts per channel, or per run in the post modes. The run also accepts at most this many channel/post inputs. YouTube exposes at most 200 posts per channel.
postTypesarrayoptionalIn channelPosts mode, only return these post types. Leave empty to include every type. The post modes return the post URLs/IDs you give them.
keywordstringoptionalIn channelPosts mode, only keep posts whose text contains this phrase. Case-insensitive. Leave empty for all posts.
publishedAfterstringoptionalIn channelPosts mode, keep posts published on or after this date. Uses YouTube's exact publish date, so details are fetched when set.
publishedBeforestringoptionalIn channelPosts mode, keep posts published on or before this date. Uses YouTube's exact publish date, so details are fetched when set.
includeDetailsbooleanoptionalIn channelPosts mode, fill the exact publish date, exact like count, comment count and a 3-comment preview. Adds one detail and one comment request per post. postDetails always returns details.
includeCommentsbooleanoptionalReturn comment threads on each post (up to Maximum comments) in channelPosts and postDetails modes. postComments always returns comments.
maxCommentsintegeroptionalMaximum top-level comments to keep per post when comments are included. Replies are counted separately.
includeRepliesbooleanoptionalAlso fetch replies under each comment when comments are included.
maxRepliesPerCommentintegeroptionalMaximum replies to keep per comment when replies are included.
commentSortstringoptionalShow YouTube's featured comments first, or the newest comments first, when comments are returned.
marketstringoptionalCountry used to render YouTube's localized labels and relative times.
languagestringoptionalLanguage used for YouTube's relative times and display labels. Post text is never translated.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/TgWj38cfCgu54papJ/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Community posts with exact dates, engagement, images, polls, quizzes, playlists, reposts and comment threads, plus one-row-per-comment output in postComments mode.

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

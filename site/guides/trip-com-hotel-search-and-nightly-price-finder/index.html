Use Trip.com Hotel Search & Nightly Price Finder with Python

Search Trip.com hotels by city and travel dates, or fetch one hotel by ID, with nightly price, star rating, guest score, amenities, and location.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "checkIn": "",
  "checkOut": "",
  "cityName": "London",
  "maxItems": 5,
  "mode": "searchHotels",
  "proxyConfiguration": {
    "useApifyProxy": true
  }
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringoptionalScraping mode: 'searchHotels' to search by city, 'hotelDetail' to fetch a single hotel by its Trip.com hotel ID.
hotelIdstringoptionalTrip.com hotel ID to fetch detail for. E.g. '732036'. Used in hotelDetail mode.
cityNamestringoptionalName of the city to search for hotels. E.g. 'London', 'Paris', 'Tokyo', 'Bangkok'. Also accepts 'destination' as an alias. Supported regions: Europe, Asia, Middle East. US/Americas cities may return 0 results due to Trip.com frontend differences.
checkInstringoptionalCheck-in date in YYYY-MM-DD format. Leave blank to use tomorrow's date.
checkOutstringoptionalCheck-out date in YYYY-MM-DD format. Leave blank to use the day after check-in.
minStarsintegeroptionalMinimum hotel star rating filter (1-5). Leave blank for no minimum.
minRatingnumberoptionalMinimum guest rating score (0-10). E.g. 7.0 for 'Good', 8.0 for 'Very Good'.
maxPricenumberoptionalMaximum price per night in USD. Leave blank for no limit.
maxItemsintegeroptionalMaximum number of hotels to return. Min 1, max 200.
proxyConfigurationobjectoptionalProxy settings. Recommended: use Apify Proxy AUTO group for reliable access.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/eT4LscLDfutKSxvXg/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

What does this guide verify?

Use Skool Community Directory, Pricing & Member Finder with Python

Browse Skool's public community directory by category, pull pricing and member-count details for communities you already know, and list top members visible on a public community page.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to scrape: discover communities from the directory, get details for specific communities, or list visible members.
searchQueriesarrayoptionalKeywords to search the Skool directory for, e.g. ["ai automation", "fitness"]. Leave empty to browse the selected category and sort order.
startUrlsarrayoptionalSkool community URLs, e.g. https://www.skool.com/the-skool-of-life.
slugsarrayoptionalCommunity slugs from the Skool URL, e.g. ["the-skool-of-life", "buildwithskool"]. Alternative to startUrls.
categorySlugstringoptionalBrowse one of Skool's nine directory categories, or all categories. Filtering by category also fills the category fields on each community.
priceTypestringoptionalFilter communities by membership price: free, paid, or free trial.
categorystringoptionalDeprecated alias for categorySlug kept so saved tasks keep working. categorySlug takes precedence when both are set.
isFreebooleanoptionalDeprecated alias for priceType=free kept so saved tasks keep working. priceType takes precedence when set.
communityTypestringoptionalFilter the directory by public or private communities.
languagestringoptionalFilter the directory by the community's language.
sortBystringoptionalOrder the directory by trending or by all-time popularity. Legacy popular/new values are accepted.
minMembersintegeroptionalOnly keep communities with at least this many members.
maxMembersintegeroptionalOnly keep communities with at most this many members.
enrichDetailsbooleanoptionalOpen each discovered community to add pricing, owner, rating, review and roster fields.
includeReviewsbooleanoptionalAdd the latest public reviews (up to five) to each community record.
memberScopestringoptionalWhich public member tab to read: the default members list, the online list, the admin list, or all three combined.
maxItemsintegeroptionalMaximum number of records to emit (communities or members combined).
maxMembersPerCommunityintegeroptionalMaximum public members to emit per community. Skool exposes about 30 rows per tab plus the admin and online tabs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/9EPFdk1OYOKL8zvqC/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Use TrustRadius Product Ratings & Feature Score Extractor with Python

Extract TrustRadius product pages by direct URL, search term, or category: pricing, aggregate ratings, feature scorecards, award badges, and related products for B2B software comparison.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to collect: product profiles, individual reviews, product discovery cards or a side-by-side comparison.
productUrlsarrayoptionalTrustRadius product URLs, review URLs or bare slugs. Used by product and reviews modes; compare mode accepts a /compare-products/a-vs-b URL or two products.
searchQueriesarrayoptional(mode=discover) Keywords to search in the TrustRadius software directory.
categoryUrlsarrayoptional(mode=discover) TrustRadius category URLs or slugs, such as https://www.trustradius.com/categories/crm or crm.
maxItemsintegeroptionalHard cap on emitted products, reviews, discovery cards or comparisons.
maxReviewsPerProductintegeroptional(mode=reviews) Reviews to collect per product. Use 0 for the entire archive.
reviewSortstringoptional(mode=reviews) Order in which reviews are collected.
starRatingsarrayoptional(mode=reviews) Only reviews with these ratings (1-5), for example ["1","2"]. Leave empty for all ratings.
companySizesarrayoptional(mode=reviews) Reviewer company sizes: small, medium or large. Leave empty for all sizes.
countriesarrayoptional(mode=reviews) Reviewer country codes in ISO3 form, for example USA, CAN or GBR.
reviewerRolesarrayoptional(mode=reviews) Roles reviewers played: user, manager, support, decisionMaker, consultant or implementer.
jobTypesarrayoptional(mode=reviews) Job types such as Engineer, Manager, Director or Analyst.
departmentsarrayoptional(mode=reviews) Departments such as Marketing, Engineering or Information Technology.
minYearsExperienceintegeroptional(mode=reviews) Minimum reviewer experience in years. Use 0 for no minimum.
lastUpdatedstringoptional(mode=reviews) Only include reviews updated within this window.
publishedAfterstringoptional(mode=reviews) Keep reviews published on or after this date (YYYY-MM-DD). Leave empty for no cutoff.
includeReviewDetailsbooleanoptional(mode=reviews) Open each review to collect ROI, alternatives and the full Q&A. Adds one request per review.
includeProductDetailsbooleanoptional(mode=product) Also collect feature scorecards, pricing plans, product details, FAQs and alternatives.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.

    "https://api.apify.com/v2/acts/Bi0XIucr8FdHafeVw/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",

# This starts a potentially billable run. Do not automatically retry this POST.

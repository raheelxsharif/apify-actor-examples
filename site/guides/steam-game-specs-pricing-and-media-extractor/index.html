    Steam Game Specs, Pricing & Media Extractor: export to CSV, Excel or JSON

    Collect per-game data from Steam store pages by URL or name search: pricing, system requirements, genres, tags, screenshots, trailers, DLC, review scores and Steam Awards.

    This tutorial runs Steam Game Specs, Pricing & Media Extractor through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: appId, title, appType, releaseDate, developers, genres, tags and currency.

    Fix common problems

    Why is a price missing on a free game?

    Free titles carry isFree: true and zero price fields instead of a paid price block. Steam does not publish a currency price for them.

    Why do some games have no Metacritic fields?

    Steam only links Metacritic for games that have a matching review page. When the link is absent the fields are omitted.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

Use Zillow Distressed Property Finder by City or ZIP with Python

Find foreclosure, pre-foreclosure, bank-owned, and auction properties on Zillow by city, neighborhood, or ZIP, with price, Zestimate, tax value, and property specs for each listing.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "distressTypes": [
    "foreclosure"
  ],
  "includeAuctionDetails": false,
  "includeDetails": false,
  "locations": [
    "Austin, TX"
  ],
  "maxItems": 3
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
locationsarrayoptionalUS locations to search, one per line: a city ("Austin, TX"), ZIP code ("78701"), neighborhood ("Hyde Park, Austin, TX") or county ("Travis County, TX").
startUrlsarrayoptionalZillow search pages to scrape instead of (or in addition to) locations. The distress filter is layered on top of whatever the URL already filters.

daysOnZillowstringoptionalOnly include listings that have been on Zillow within this window.
sortBystringoptionalOrder in which Zillow returns the listings.
includeDetailsbooleanoptionalOpen each listing's detail page for the listing agent, photos, description, year built and distress flags. Adds one request per listing; rows still return without it.
includeAuctionDetailsbooleanoptionalFor auction listings whose page links to auction.com, also read that public page for the auction date/time, occupancy, starting bid and lender/attorney details. Adds one request per linked auction and requires "Include full property details".
maxItemsintegeroptionalMaximum number of listings to return across all locations and URLs (1–5000).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/TFgUch48s7mbPQ6Kw/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

    OpenCitations DOI Citation Graph Extractor: export to CSV, Excel or JSON

    Look up a scholarly DOI in the OpenCitations index to get every paper that cites it, every paper it references, or its total citation count, with cross-walked DOI, OMID, PMID and OpenAlex identifiers.

    This tutorial runs OpenCitations DOI Citation Graph Extractor through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 5 columns its publisher puts first: oci, citingDoi, citedDoi, creation and timespan.

    What people export it for

    • Literature mapping — build out the citation network around a seminal paper, one DOI at a time
    • Impact analysis — track how many works cite a paper and how quickly citations accumulated using timespan
    • Reference-list harvesting — pull a paper's full reference list as structured rows instead of reading a bibliography
    • Self-citation audits — flag journal and author self-citations at scale using journalSc/authorSc
    • Identifier reconciliation — cross-walk a DOI-only dataset to OMID, PMID and OpenAlex identifiers

    Fix common problems

    Why does a DOI return no results?

    Either OpenCitations hasn't indexed that DOI yet, or the work genuinely has no recorded citations or references in the index. In that case the actor still finishes successfully with a single recordType: "error" record (error: "not_found") instead of an empty dataset.

    Why are citingPmid or citedOpenalex sometimes missing?

    OpenCitations only stores the identifiers it has successfully cross-walked for a given work. If a work's PubMed ID or OpenAlex ID isn't on file, that field is left out of the record.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

Use Noon.com Multi-Market Product Search by Discount with Python

Search Noon.com's UAE, Saudi Arabia, and Egypt storefronts by keyword, category, or URL, and get price, discount, rating, brand, and promotional labels for each product in that market's own currency.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categoryPaths": [],
  "dealOnly": false,
  "includeDetails": false,

  "language": "en",
  "market": "uae",
  "maxItems": 3,
  "mode": "search",
  "productInputs": [],
  "searchQueries": [
    "laptop"

  "startUrls": []

FieldTypeRequiredDescription
modestringrequiredChoose what to fetch. Search needs `searchQueries`; category needs `categoryPaths`; product needs `productInputs`; URL needs `startUrls`.
searchQueriesarrayoptionalKeywords to search for (mode=search). One query per line, e.g. `laptop`.
categoryPathsarrayoptionalnoon category paths or URLs (mode=byCategory), e.g. `electronics-and-mobiles/computers-and-accessories/computers-new/laptops`.
productInputsarrayoptionalnoon SKUs or product URLs (mode=byProduct), e.g. `N70367827V`.
startUrlsarrayoptionalnoon search, category, or product URLs (mode=byUrl). The market in each URL overrides the Market field.
marketstringoptionalnoon storefront and currency. Product and URL inputs can override it from the URL.
languagestringoptionalProduct titles and descriptions language used by the storefront.
sortBystringoptionalOrdering for search and category results.
minPricenumberoptionalOnly emit products at or above this price, in the selected market's currency.
maxPricenumberoptionalOnly emit products at or below this price, in the selected market's currency.
minRatingnumberoptionalOnly emit rated products at or above this star rating (0-5). Unrated products are excluded when this is set.
minDiscountPercentnumberoptionalOnly emit products discounted by at least this percentage. Products without a list price have no discount and are excluded.
maxDiscountPercentnumberoptionalOnly emit products discounted by at most this percentage. Set 0 to require no discount.
brandstringoptionalOptional brand name or brand code, e.g. `HP` or `hp`. Matched against noon's brand filter.
sellerstringoptionalOptional seller name or seller code, e.g. `noon` or `p_9404`.
dealOnlybooleanoptionalOnly emit products carrying a noon deal tag.
includeDetailsbooleanoptionalAdd description, specifications, stock, warranty, delivery, and all seller offers. Adds one request per product.
includeReviewsbooleanoptionalAdd up to five latest review snippets per product. Adds one request per product.
maxItemsintegeroptionalHard cap on emitted products across the whole run.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/qDg5x3pgFoSyTs8EB/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

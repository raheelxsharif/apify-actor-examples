Use Multi-League Season Results & Team Lookup with Python

Get final scores for a season across 10 major soccer, football, basketball, baseball, and hockey leagues, or look up every team's roster details for a league in one run.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "enrichTeams": false,
  "includeOdds": true,
  "includeUpcoming": true,
  "leagueUrls": [],
  "maxItems": 20,
  "mode": "results",
  "regionalFallback": true,
  "season": "2024-2025",
  "sport": "epl",
  "teamQuery": "Arsenal"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
modestringrequiredSeason results with odds, a league's team roster, or a team lookup by name.
sportstringoptionalWhich competition to fetch. Ignored when leagueUrls is set.
seasonstringoptionalSeason to fetch. Soccer-style seasons use YYYY-YYYY (a plain YYYY expands to YYYY-YYYY); calendar-year leagues (MLB, MLS, NPB, J1, K League) use YYYY; 'current' is the live season. Used in results and teams modes.
leagueUrlsarrayoptionalOptional: one or more OddsPortal league or season-results URLs (any sport or league, e.g. https://www.oddsportal.com/football/england/premier-league-2024-2025/results/). Overrides League and Season.
teamQuerystringoptionalTeam to look up by name (teamSearch mode), e.g. Arsenal or Real Madrid.
includeOddsbooleanoptionalAdd 1X2 average and maximum odds, bookmaker count and per-bookmaker prices to each result.
includeUpcomingbooleanoptionalKeep scheduled and in-progress matches; turn off to get only finished results.
enrichTeamsbooleanoptionalIn teams and teamSearch modes, open each team's page for its full name, venue, city, country and coach. Adds one request per team.
regionalFallbackbooleanoptionalWhen a league-season is empty on the main domain, retry it on the same site's regional edition (a few competitions, e.g. ACB, only publish older seasons there). Only fires on empty results, so it does not change normal runs.
maxItemsintegeroptionalMaximum records to return (1-10000). The run also stops when the source runs out of pages.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/cIiSpiIctD5BGgSun/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

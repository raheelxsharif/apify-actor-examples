Use Lowe's Price, Stock & Specification Scraper with Python

Search Lowe's products by keyword, browse a category, or fetch details by item ID or URL. Get price, original price, discount percent, stock status, ratings, model number, and full specifications for each product.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "category": "tools",
  "inStockOnly": false,
  "includeDetails": false,
  "itemIds": [
    "5013207487"
  ],
  "maxItems": 1,
  "mode": "productDetails",
  "onSaleOnly": false,
  "onShelfOnly": false,
  "searchQueries": [],
  "sortBy": "featured",
  "startUrls": [],
  "storeId": "0208",
  "zipCode": "92253"
}

FieldTypeRequiredDescription
modestringrequiredWhat to look up.
searchQueriesarrayoptionalKeywords to search for (mode=search). Each query adds its own discovery results.
categorystringoptionalLowe's department to browse (mode=byCategory).
itemIdsarrayoptionalLowe's item numbers (for example 5013207487) or /pd/ product URLs. Used by mode=productDetails.
startUrlsarrayoptionalLowe's product, search, or /pl/ category URLs. Used by mode=byUrl, and category URLs are also accepted by mode=byCategory.
storeIdstringoptionalFour-digit Lowe's store number used for price and stock context. Default 0208 (La Quinta, CA).
zipCodestringoptionalFive-digit ZIP code used with the store number for price and stock context. Default 92253.
sortBystringoptionalHow to order the products found in this run.
inStockOnlybooleanoptionalOnly emit products with at least one fulfilment method available.
onSaleOnlybooleanoptionalOnly emit products with a current was/sale price.
onShelfOnlybooleanoptionalOnly emit products with pickup quantity above zero at the selected store.
minPriceintegeroptionalDrop products priced below this value. Products without a price are skipped when a price filter is set.
maxPriceintegeroptionalDrop products priced above this value. Products without a price are skipped when a price filter is set.
minRatingnumberoptionalDrop products rated below this value. Products without a rating are skipped when this filter is set.
includeDetailsbooleanoptionalAdd description, bullets, specifications, UPC, dimensions, warranty, and manuals to each product.
maxItemsintegeroptionalMaximum number of products to emit. Discovery may return fewer candidates than this.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/KnnU4GxLeum2JdDP7/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

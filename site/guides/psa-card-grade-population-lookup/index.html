    PSA Card Grade Population Lookup: export to CSV, Excel or JSON

    Look up PSA grading population counts for trading cards: search by keyword, fetch by spec number, browse a set, or see recently graded cards, each with grade 1-10 counts and total graded.

    This tutorial runs PSA Card Grade Population Lookup through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: recordType, specId, subject, cardNumber, variety, setName, setYear and grade10Count.

    Steps

    1. See the columns
    2. Get an API token
    3. Choose the input
    4. Run it and write a CSV
    5. Download Excel or JSON
    6. The same in JavaScript
    7. Fix common problems

    Fix common problems

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

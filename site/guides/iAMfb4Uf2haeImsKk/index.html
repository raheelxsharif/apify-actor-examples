Use Greenhouse ATS Job Board Lookup by Company with Python

Pull every open role from one or more Greenhouse company boards, or look up specific postings by job ID, with location, department, employment type, salary, and apply link for each.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "companies": [
    "airbnb"
  ],
  "content": false,
  "descriptionFormat": "html",

  "mode": "companyJobs",

FieldTypeRequiredDescription
modestringrequiredWhat to fetch: jobs from company boards, specific job URLs, or company board lookup.
companiesarrayoptionalBoard tokens, board URLs, embed URLs, job URLs, company names or domains. Examples: "stripe", "https://job-boards.greenhouse.io/figma", "Airbnb", "jobs.elastic.co".
jobUrlsarrayoptionalFull Greenhouse job URLs to fetch one by one. A company board URL alone is not enough; include /jobs/<id>.
searchQuerystringoptionalName or token text to match against the built-in company directory. Leave empty to resolve the Companies list instead.
titleKeywordsarrayoptionalKeep jobs whose title contains any of these words (case-insensitive).
excludeTitleKeywordsarrayoptionalDrop jobs whose title contains any of these words (case-insensitive).
locationsarrayoptionalKeep jobs whose location or office contains any of these words, e.g. Remote, London, New York.
departmentsarrayoptionalKeep jobs in departments that contain any of these words, e.g. Engineering, Sales.
workplaceTypestringoptionalKeep remote, hybrid or on-site roles. Jobs without a stated arrangement are dropped when this is not Any.
employmentTypestringoptionalKeep full-time, part-time, contract, internship or temporary roles when the employer states it.
publishedAfterstringoptionalKeep jobs first published on or after this date (YYYY-MM-DD).
updatedAfterstringoptionalKeep jobs last updated on or after this date (YYYY-MM-DD).
onlyWithSalarybooleanoptionalKeep only jobs with a published or clearly stated pay range.
minAnnualSalaryintegeroptionalKeep jobs whose base pay reaches at least this yearly amount. Hourly, monthly and weekly ranges are annualized.
salaryCurrencystringoptionalOnly keep jobs with pay in this currency. Use Any to ignore currency.
sortBystringoptionalResult order after filtering.
contentbooleanoptionalInclude the full job description. Departments and offices are always included (fetched separately when descriptions are off).
descriptionFormatstringoptionalFormat used when Include job descriptions is on. HTML is always the content field; text/markdown add contentText/contentMarkdown.
includeQuestionsbooleanoptionalFetch each job's application form questions. Adds one request per emitted job.
maxItemsintegeroptionalMaximum number of job or company records to emit.
maxJobsPerCompanyintegeroptionalCap jobs per company after filters (mode=companyJobs). 0 means no per-company cap.
verifyCompaniesbooleanoptionalCheck each company against the live board and report its open-job count.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/iAMfb4Uf2haeImsKk/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One record per Greenhouse job (title, company, locations, departments, structured pay, dates, apply link) or per company in company-search mode.

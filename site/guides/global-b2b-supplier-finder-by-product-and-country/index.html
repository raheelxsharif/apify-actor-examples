Use Global B2B Supplier Finder by Product & Country with Python

Search the Kompass B2B directory by company name, product keyword, or country, or fetch specific profiles, for firmographic detail: employees, revenue, certifications, products, and contact info.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
modestringrequiredChoose what to do: search by keyword, browse a country/type directory, browse activity/region URLs, or fetch profile URLs.
querystringoptionalCompany name, product, or service keyword (mode=searchCompanies).
searchTypestringoptionalMatch all text, company names only, or products/services only (mode=searchCompanies).
countrystringoptionalKompass market used for search and directory browsing, and to filter records to that country.
companyTypestringoptionalFilter by company role. Directory mode opens the matching country path; search mode filters card roles.
sectorstringoptionalKompass sector used by mode=browseDirectory. Choose any to skip the sector path.
directoryUrlsarrayoptionalActivity, region, sector, producer, distributor, service, importer, or exporter URLs (mode=browseCategoryOrRegion). Paste page URLs from any Kompass country site.
companyUrlsarrayoptionalKompass company profile URLs or bare Kompass IDs such as IT0050676 (mode=companyDetails).
includeDetailsbooleanoptionalFetch each company profile for contacts, address, legal IDs, executives, products, and catalogues. Turn this off for cheaper card-only searches.
maxItemsintegeroptionalMaximum number of company records to return. Status rows do not count toward this limit.
maxPagesintegeroptionalMaximum live keyword-search pages to read (mode=searchCompanies). Kompass exposes about five pages per keyword.
archivePagesintegeroptionalWayback CDX index pages to scan per market when live pages are blocked (mode=searchCompanies). Each page holds about 1,700 archived company URLs.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/WY0bmptmiK1TxCKqS/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Use Hacker News Story, Comment & Karma Scraper with Python

Pull Hacker News front-page, newest, best, Ask HN, Show HN, or job stories, look up specific items or user profiles, or run a full-text search across HN history. Filter by score, domain, date range, and comment count or author.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

modestringrequiredWhat to scrape. `topStories` / `newStories` / `bestStories` / `askStories` / `showStories` / `jobStories` walk the public feeds. `item` fetches specific item IDs (`itemIds`). `user` fetches profiles (`usernames`). `search` uses the Algolia HN API (`searchQuery`).
itemIdsarrayoptionalDirect Hacker News item IDs (numeric strings or integers). Used when mode=`item`.
usernamesarrayoptionalHacker News usernames. Used when mode=`user`.
searchQuerystringoptionalFree-text query passed to the Algolia HN search API.
startUrlsarrayoptionalHacker News URLs to scrape directly. Supports `news.ycombinator.com/item?id=N` and `news.ycombinator.com/user?id=USER`. Each URL is converted to an item or user fetch.
enableCommentHierarchybooleanoptionalWhen true, attach a nested `comments[]` array to each story (recursive replies). When false, comments are emitted as flat sibling records (one per row, with `parentId` and `depth`).
maxItemsintegeroptionalHard cap on emitted records (stories + comments + users combined).
maxCommentsintegeroptionalCap on comments fetched per story. 0 = no comments. Default 0 (skip comments).
maxDepthintegeroptionalMaximum reply depth when fetching comments (only applies when `maxComments` > 0). Root comments are depth 0.
minScoreintegeroptionalDrop stories with fewer points than this. Comments are unaffected.
domainAllowlistarrayoptionalOnly emit stories whose URL host contains one of these substrings (case-insensitive). e.g. ['github.com','arxiv.org'].
domainBlocklistarrayoptionalDrop stories whose URL host contains one of these substrings. e.g. ['twitter.com','x.com'].
excludeDeadOrDeletedbooleanoptionalDrop items flagged `dead: true` or `deleted: true` by Hacker News.
dateRangeFromstringoptionalDrop items posted before this date (UTC). Empty = no lower bound.
dateRangeTostringoptionalDrop items posted after this date (UTC). Empty = no upper bound.
commentMinScoreintegeroptionalDrop comments below this score. (Note: HN exposes comment scores only sporadically; comments without a score are kept.)
commentAuthorFilterarrayoptionalOnly emit comments authored by one of these usernames (case-insensitive substring match).
minCommentCountintegeroptionalDrop stories with fewer than this many comments.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/shC9wAKWFYbt1zZYs/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

Stories, comments, job posts, and user profiles from Hacker News. Fields vary by record type: stories include id, title, url, score, author, numComments, createdAt, domain, hnUrl; comments include id, storyId, parentId, depth, author, text; users include id, karma, submittedCount, profileUrl.

Use Amazon Brand Store Page & Merchandising Crawler with Python

Crawl an Amazon Brand Store's navigation, creative modules (images, video, CTAs), and every product link found on its pages. Resolves a brand's Store URL automatically from a product page or ASIN.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "asins": [],
  "crawlSubpages": false,
  "includeLinks": true,
  "includeSections": true,
  "maxDepth": 1,
  "maxPages": 3,
  "maxProducts": 30,
  "productUrls": [],
  "proxyConfiguration": {
    "useApifyProxy": true
  },
  "storeUrls": [
    "https://www.amazon.com/stores/soundcore/page/AD6AD8C0-90C7-4C65-8000-0AC741FA2633"
  ]
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
storeUrlsarrayoptionalAmazon Brand Store URLs, e.g. `https://www.amazon.com/stores/soundcore/page/AD6AD8C0-90C7-4C65-8000-0AC741FA2633`. At least one of storeUrls / productUrls / asins is required.
productUrlsarrayoptionalAmazon product (/dp/{ASIN}) URLs. The actor visits each product page, finds its "Visit the {Brand} Store" link, and crawls that store instead.
asinsarrayoptionalProduct ASINs on amazon.com. Same resolution behavior as productUrls.
crawlSubpagesbooleanoptionalFollow the store's navigation menu (HOME, FEATURED DEALS, SSD, ...) and crawl every linked subpage, not just the landing page.
maxDepthintegeroptionalHow many navigation-link hops to follow from the landing page when crawlSubpages is enabled (1 = landing page's direct subpages only).
maxPagesintegeroptionalHard cap on the total number of store pages (landing + subpages) fetched per store.
maxProductsintegeroptionalHard cap on the number of distinct product (ASIN) records emitted per store.
includeSectionsbooleanoptionalEmit a `section` record for every merchandising module on each crawled page: its type, ID, position, heading, body copy, CTA, primary image/video, and product/link counts.
includeLinksbooleanoptionalEmit a typed `link` record for every unique target on each crawled page (navigation, store page, product, search, external), with its section context.
proxyConfigurationobjectoptionalApify proxy. AUTO (datacenter) is used by default with homepage-priming; the actor escalates to RESIDENTIAL automatically only if it keeps getting blocked.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/NoDN50TMXljcpzeSO/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

4. Inspect the actual results

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.

One dataset of typed records: store pages (identity, navigation, counts), merchandising sections (type, heading, CTA, media, counts), products (price, rating, badge, section context), and links (typed, section-scoped).

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

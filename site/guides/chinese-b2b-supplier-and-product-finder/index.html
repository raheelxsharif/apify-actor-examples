Use Chinese B2B Supplier & Product Finder by Province with Python

Search Made-in-China.com products and suppliers by keyword or category, with province, business type, certification, price, MOQ and trust-badge filters for sourcing and lead generation.

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredWhat to scrape from Made-in-China.com.
searchQueriesarrayoptionalOne or more product or supplier keywords. Used by 'Search products' and 'Find suppliers' modes (e.g. 'industrial pump', 'LED lights').
categoryPathsarrayoptionalMade-in-China.com catalog paths (or full catalog URLs) to browse in 'Browse a product category' mode, e.g. 'Agriculture-Food-Catalog/Beverage'.
productUrlsarrayoptionalProduct page URLs or product IDs to scrape in 'Scrape these product URLs/IDs' mode. A bare ID is resolved through the site's own search.
supplierUrlsarrayoptionalSupplier storefront URLs or subdomains, e.g. 'allslorm.en.made-in-china.com' or just 'allslorm'. Used by 'Scrape these supplier storefronts' and 'Scrape a supplier's catalog'.
provincestringoptionalOnly return listings whose supplier is located in this Chinese province, municipality, or region. Leave blank for no filter.
businessTypestringoptionalOnly return suppliers of this business type. Leave blank for no filter. Used by product and supplier search modes.
goldSupplierOnlybooleanoptionalOnly return listings from suppliers with a Gold Member, Diamond Member, or higher paid membership badge.
auditedSupplierOnlybooleanoptionalOnly return listings whose supplier carries an 'Audited Supplier' badge from an independent inspection agency.
leadingFactoryOnlybooleanoptionalOnly return listings whose supplier holds an 'Industry-leading Audited Factory' badge.
securedTradingOnlybooleanoptionalOnly return listings that offer Secured Trading (payment protection and after-sales support through Made-in-China.com).
rdCapacitystringoptionalOnly return products from suppliers with this R&D or production capability. Leave blank for no filter.
certificationstringoptionalOnly return products from suppliers who advertise this quality or safety certification. Leave blank for no filter.
maxMinOrderintegeroptionalOnly return products whose Minimum Order Quantity is at or below this number. Leave blank for no filter.
priceMinnumberoptionalOnly return products whose listed price is at or above this USD value. Must be used together with the maximum; a lone bound is ignored.
priceMaxnumberoptionalOnly return products whose listed price is at or below this USD value. Must be used together with the minimum; a lone bound is ignored.
sampleAvailableOnlybooleanoptionalOnly return products whose supplier offers a paid sample order ('Buy Sample').
maxItemsintegeroptionalMaximum number of records to return across all keywords, categories, or URLs.
maxPagesPerQueryintegeroptionalMaximum listing pages to walk for each keyword, category, or supplier catalog. Each page holds about 24-30 records.
includeProductDetailsbooleanoptionalOpen each product page to add description, specifications, price tiers, images, video, categories, FAQ, and deeper supplier data. Adds one request per product.
includeSupplierProfilebooleanoptionalOpen supplier storefront and company-profile pages to add firmographics, trade terms, audit report, product groups, and verification data. Adds requests per supplier.
includeContactDetailsbooleanoptionalOpen the public contact page in supplier modes to add contact person, position, postal code, and showroom URL. Phone and email are not public.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/qhABZwuIp7K1Y60yB/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

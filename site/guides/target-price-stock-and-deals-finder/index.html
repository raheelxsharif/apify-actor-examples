Use Target Price, Stock & Deals Finder with Python

Get Target.com product data by keyword search, department, exact item number, product URL, or trending deals - with price, stock status, fulfillment options, and ratings.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "categoryId": "electronics",
  "inStockOnly": true,
  "includeDetails": false,
  "maxItems": 2,
  "maxPages": 1,
  "mode": "search",
  "onSaleOnly": false,
  "query": "iPhone case",
  "sortBy": "relevance"
}

FieldTypeRequiredDescription
modestringrequiredWhat to fetch from Target.
querystringoptionalKeyword to search for (mode=search). E.g. 'iPhone case'.
tcinsarrayoptionalOne or more Target item numbers (TCINs), e.g. '94715153'. Comma-separated strings are also accepted.
categoryIdstringoptionalTarget department to browse.
urlstringoptionalA Target product, category, brand or search URL. E.g. 'https://www.target.com/p/item/-/A-12345678'.
sortBystringoptionalHow Target should order results.
includeDetailsbooleanoptionalFetch each product page to add description, UPC/DPCI, category breadcrumbs, specifications, review counts and the online stock status Target publishes.
minPricenumberoptionalDrop products cheaper than this price.
maxPricenumberoptionalDrop products more expensive than this price.
minRatingnumberoptionalDrop products with an average rating below this value (0–5).
onSaleOnlybooleanoptionalOnly emit products currently marked on sale or clearance.
inStockOnlybooleanoptionalExclude products Target reports as out of stock. Search, department and deals listings that carry no stock signal are kept and marked `UNKNOWN` unless full-detail enrichment resolves them.
maxItemsintegeroptionalHard cap on emitted records (1–1000). Target exposes up to 50 pages of 24 results per query.
maxPagesintegeroptionalMaximum result pages to request per query (1–50; 24 products per page).

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/tFok5WUalfr5iu22C/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

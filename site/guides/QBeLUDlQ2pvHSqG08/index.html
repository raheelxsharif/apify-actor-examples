Use Google Maps Radius Search Around a Coordinate with Python

Find Google Maps places within a set radius of an exact latitude/longitude, with rating, reviews, address, phone, website, coordinates, and distance from the center point.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

FieldTypeRequiredDescription
centerTypestringoptionalHow the center of the radius is supplied: exact latitude/longitude, a free-text address, or a Google Maps place URL / Place ID.
latitudenumberoptionalLatitude of the center when the center type is Coordinates.
longitudenumberoptionalLongitude of the center when the center type is Coordinates.
addressstringoptionalAddress, landmark or place name to use as the center when the center type is Address. Google resolves it to its own coordinates.
placestringoptionalGoogle Maps place URL or canonical ChIJ Place ID to use as the center when the center type is Place.
searchTermsarrayrequiredOne or more categories or free-text keywords, for example ['coffee shop'], ['dentist', 'pharmacy'] or ['restaurant'].
radiusKmnumberoptionalHard search radius in kilometres around the center. Places outside it are dropped; every returned row carries its exact distance from the center.
maxResultsintegeroptionalMaximum places to return for each search term. Google's ranked window usually contains roughly 130-180 places inside a dense radius; when the source runs out the run stops honestly instead of padding.
includeDetailsbooleanoptionalAdd preview-panel fields such as plus code, price level, rating histogram, photos, description, attributes, service options, closing status and hotel/fuel/booking extras. Adds one request per place; listing fields and weekly hours are always collected.
minRatingnumberoptionalOnly keep places rated at or above this value. Places with no published rating are skipped.
maxRatingnumberoptionalOnly keep places rated at or below this value. Places with no published rating are skipped.
minReviewsintegeroptionalOnly keep places with at least this many reviews. Places with no review count are skipped.
maxReviewsintegeroptionalOnly keep places with at most this many reviews. Places with no review count are skipped.
openNowbooleanoptionalOnly keep places Google currently shows as open. A place whose open/closed state cannot be read is skipped, so this filter can return fewer rows.
hasWebsitebooleanoptionalOnly keep places that publish a website on their Google Maps listing.
hasPhonebooleanoptionalOnly keep places that publish a phone number on their Google Maps listing.
includeClosedbooleanoptionalWhen off, places Google marks as permanently closed are skipped. This requires reading each place's preview panel.
nameFilterstringoptionalOnly keep places whose name contains this text, for example 'pizza'.
excludeCategoriesarrayoptionalSkip places whose category contains any of these words, for example ['hotel', 'casino'].
languagestringoptionalLanguage for place names, categories, addresses and hours.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/QBeLUDlQ2pvHSqG08/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

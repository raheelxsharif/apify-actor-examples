Use Twitter (X) Space Scraper with Python

Collect public X Spaces without login. Get the Space title, state, schedule, live and replay listener counts, host and participants, replay audio with a downloadable file, and an optional captions/AI transcript.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

{
  "includeParticipantProfiles": false,
  "includeParticipants": true,
  "includeReplayAudio": false,
  "includeTranscript": false,
  "maxParticipantProfiles": 10,
  "maxSpaces": 1,
  "spaceState": "any",
  "spaceUrls": [
    "https://x.com/i/spaces/1YpKkZgnrDXxj"
  ],
  "transcriptSegmentsAsRows": false,
  "transcriptionMethod": "auto",
  "whisperModel": "base"
}

Download input.example.json and save your reviewed copy as input.json.

FieldTypeRequiredDescription
spaceUrlsarrayoptionalPaste Space links such as https://x.com/i/spaces/1YpKkZgnrDXxj, bare Space IDs, or the post that announces a Space (the actor finds the Space from its card). x.com and twitter.com links both work.
searchQueriesarrayoptionalFind public Spaces from posts that match a keyword or hashtag, for example AI, crypto or #Space. Each query reads recent matching posts and resolves the Spaces they announce.
hostUsernamesarrayoptionalFind Spaces announced by specific X accounts. Paste handles with or without @, or a profile URL.
maxSpacesintegeroptionalUpper limit for Spaces found through keywords and hosts. Spaces that you paste as links or IDs are always collected.
spaceStatestringoptionalOnly keep Spaces in this state. Applies to links and discovery alike.
includeParticipantsbooleanoptionalAdd the host, speakers and listeners to the Space row and emit one separate "space participant" row per person.
includeParticipantProfilesbooleanoptionalLook up each participant's public profile (bio, followers, website, verification) instead of only the compact name shown in the Space. Adds one request per participant.
maxParticipantProfilesintegeroptionalCap on profile lookups per Space. 0 means every participant. Large Spaces with many listeners can be expensive.
includeReplayAudiobooleanoptionalAdd the HLS replay link and, when a file can be produced, store a downloadable audio file with its duration and size.
includeTranscriptbooleanoptionalProduce a spoken-word transcript. Captions are used when the replay has them; otherwise AI speech recognition runs (slower and memory-hungry).
transcriptSegmentsAsRowsbooleanoptionalIn addition to the transcript summary row, emit one "space transcript segment" row per timed segment.
transcriptionMethodstringoptionalHow the transcript should be produced.
whisperModelstringoptionalWhisper model for AI transcription. Larger models are more accurate but need more actor memory; on 1 GB the actor safely falls back to a smaller model.
proxyConfigurationobjectoptionalOptional. The actor works without a proxy and switches to Apify Proxy automatically if X blocks the direct connection.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/zhRubyXu0We3FiDsl/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Questions before you run

Which inputs are required?

No top-level fields are marked required in the published schema. Conditional requirements can still apply; check the README.

What does this guide verify?

The fields, prefills, and schema links are rendered from the published build. This is a usage recipe, not a paid live extraction test. Source availability and collection results can vary.

What if the run request times out?

Check Apify Console before retrying. The first request may already have created a run. Do not automatically repeat a run-creation POST.

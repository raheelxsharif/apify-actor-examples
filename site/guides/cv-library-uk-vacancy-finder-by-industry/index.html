    CV-Library UK Vacancy Finder by Industry & Location: CSV and Excel export

    Find live UK job vacancies on CV-Library by keyword and city, or by browsing an industry sector, with salary, company, location and a direct apply link.

    This tutorial runs CV-Library UK Vacancy Finder by Industry & Location through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 7 columns its publisher puts first: jobTitle, companyName, location, salary, jobType, postedDate and jobUrl.

    Fix common problems

    Why do some jobs have no companyName or salary?

    Those details are optional when an employer posts a listing on CV-Library; if a listing doesn't include them, this actor leaves the field out rather than returning an empty value.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

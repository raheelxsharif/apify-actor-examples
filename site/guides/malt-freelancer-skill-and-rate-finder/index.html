    Malt Freelancer Skill & Rate Finder: export to CSV, Excel or JSON

    Search Malt freelancers by skill and location or enrich specific profile URLs across all six Malt markets: headline, skills, daily rate, rating, review count, experience, location and languages.

    This tutorial runs Malt Freelancer Skill & Rate Finder through the Apify API and saves what it returns as a CSV file, an Excel workbook or JSON, keeping the 8 columns its publisher puts first: name, headline, skills, location, verified, market, profilePhotoUrl and profileUrl.

    What people export it for

    • Talent sourcing — shortlist freelancers by skill, location and rating before reaching out
    • Market research — compare freelancer availability and typical rates for a skill across European markets
    • Competitor benchmarking — see who the top-rated freelancers are in your own niche
    • Lead generation — build outreach lists from Malt search results
    • Directory building — enrich an existing list of Malt profile URLs with current rate, rating and skill data

    Fix common problems

    Why is a residential proxy required?

    Malt blocks traffic that doesn't come from a normal residential connection, so a European residential proxy is applied by default and is required for the actor to reach the site reliably.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

Use Google Workspace Marketplace Review Tracker with Python

Track and monitor reviews for any Google Workspace Marketplace app. Filter by date, rating, and sort order - ideal for daily sentiment monitoring and competitor analysis.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

FieldTypeRequiredDescription
modestringrequiredChoose 'Reviews for specific apps' to watch an app list, or 'Search apps by keyword' to discover popular Marketplace apps.
appIdsarrayoptionalNumeric App IDs or full Google Workspace Marketplace app URLs. Add one app per item. Example: 1008170693301 or https://workspace.google.com/marketplace/app/mailmeteor_mail_merge_for_google_sheets/1008170693301. Used by the 'Reviews for specific apps' mode.
searchQueriesarrayoptionalKeywords for the 'Search apps by keyword' mode, for example 'mail merge' or 'crm'. Each keyword ranks the Marketplace's public app index; niche apps should be added by ID or URL instead.
maxAppsintegeroptionalHow many top matching apps to track for each search keyword.
minAppRatingnumberoptionalSkip apps rated below this value (0–5). Use 0 for no app-rating filter.
minAppReviewsintegeroptionalSkip apps with fewer total reviews than this. Use 0 for no app-review-count filter.
sortBystringoptionalOrder in which to retrieve reviews. The Marketplace supports newest and most helpful; legacy rating sorts are computed over the collected reviews.
reviewLanguagestringoptionalChoose a language, or 'All languages' to check every supported language slice until Max reviews per app is reached.
minRatingintegeroptionalOnly include reviews with this star rating or higher (1–5). Leave blank for all ratings.
maxRatingintegeroptionalOnly include reviews with this star rating or lower (1–5). Leave blank for all ratings.
sinceDatestringoptionalOnly include reviews posted on or after this date. Use YYYY-MM-DD, or a period such as '30 days', '2 weeks' or '6 months'. Leave blank for all dates.
untilDatestringoptionalOnly include reviews posted on or before this date (YYYY-MM-DD). Leave blank for no end date.
reviewKeywordstringoptionalOnly include reviews whose text contains this phrase (case-insensitive). Leave blank for all review text.
maxReviewsPerAppintegeroptionalStop after this many matching reviews for each app (1–2000). Raise it to collect full history; the Marketplace serves 10 per page.
maxItemsintegeroptionalMaximum number of review rows to return across all apps (1–5000).
outputModestringoptionalUse 'Only new reviews' or 'New + changed reviews' with a state key to compare this run with the previous run.
trackChangesbooleanoptionalIn 'All matching reviews' mode, add isNew/changeTypes and save a snapshot for the next run.
stateKeystringoptionalName of the saved snapshot. Use a different name for each schedule or watchlist. Leave blank to derive one from the app list and review language.
resetStatebooleanoptionalClear the saved snapshot before this run so every review is treated as new.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/MCQnyePxbC4pIjM4J/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

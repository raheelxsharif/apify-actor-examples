    RemoteOK Job Board Tag & Region Filter Tool: export to CSV, Excel or JSON

    Search RemoteOK's remote job board by keyword, tag, region, or salary range, or fetch jobs by direct URL, and get position, company, salary, tags, location, and apply link for each listing.

    Fix common problems

    Why is the salary range often missing?

    The public feed publishes salary for only part of the board. Many more listings carry a baseSalary on their own job page, so set enrichDetails: true to fill those (one extra HTTP request per emitted job). Set salaryOnly: true if you only want priced postings — combine it with enrichment to apply it to page salaries too.

    Why does byUrls mode sometimes return fewer records than I passed in?

    Live job pages embed a JobPosting record even when the listing is no longer in the latest feed, and the actor reads it. Once Remote OK expires a listing, the page still returns HTTP 200 but drops that structured data, so expired URLs cannot be resolved. This is a source limit, not an actor error.

    HTTP 401 means the token is missing; an empty file usually means the input matched nothing, which the run log in Console names.

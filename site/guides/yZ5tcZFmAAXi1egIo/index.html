Use Amazon Deals Grid Tracker by Category & Discount with Python

Pull Amazon's Today's Deals grid across 23 marketplaces, with deal price, list price, savings amount/percent, deal type, brand, and department for each product. Filter by category, brand, price range, and discount range.

FieldTypeRequiredDescription
marketplacestringrequiredWhich Amazon domain's Today's Deals page to scrape.
dealTypestringoptionalOnly emit deals belonging to this collection bubble (the real filter chips Amazon shows atop the Deals page). Department-scoped bubbles (e.g. Customers' Most-Loved) are enforced by matching each deal's department IDs; tag-scoped bubbles (Lightning Deals, Coupons, Outlet) can't be verified per-deal from the grid data and pass through unfiltered. `(any deal type)` applies no filter.
categorystringoptionalFree-text filter matched against each deal's department/category name (case-insensitive substring, e.g. `Electronics`, `Home`, `Toys`). Leave empty for all categories.
brandstringoptionalFree-text filter matched against each deal's brand name (case-insensitive substring, e.g. `Anker`, `Samsung`). Leave empty for all brands.
minRatingintegeroptionalOnly emit deals with a star rating at or above this value. Deals without a visible rating pass through unless this is set.
priceMinintegeroptionalDrop deals priced below this amount (in the marketplace's local currency).
priceMaxintegeroptionalDrop deals priced above this amount (in the marketplace's local currency).
discountMinintegeroptionalDrop deals with a savings percentage below this value.
discountMaxintegeroptionalDrop deals with a savings percentage above this value.
maxItemsintegeroptionalHard cap on emitted deal records.
maxPagesintegeroptionalHard cap on how many grid pages (up to 30 items each) to walk (each page is a fresh in-browser fetch of the widget's own pagination request).
proxyConfigurationobjectoptionalApify proxy used to fetch the Deals page. AUTO (datacenter) is used by default; the actor escalates to residential automatically only after repeated block detections within a run.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/yZ5tcZFmAAXi1egIo/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])
# Inspect and download results in Apify Console once the run succeeds.

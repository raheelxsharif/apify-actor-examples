Use Amazon Deals Grid Tracker by Category & Discount with Python

Pull Amazon's Today's Deals grid across 23 marketplaces, with deal price, list price, savings amount/percent, deal type, brand, and department for each product. Filter by category, brand, price range, and discount range.

1. Choose the data you need

Review the published README for supported collection modes, examples, and limits. The recipe below uses the current published input definition.

2. Prepare a source-based input

This JSON contains published prefills and required-field defaults. Review every value for your task before running it; it is not a promise of successful collection.

  "sortBy": "featured"
}

Add several categories to scan past Amazon's 500-deal window.
collectionstringoptionalRestrict to one of Amazon's curated deal collections. The collection names differ by marketplace; unsupported collections return a clear status record instead of unfiltered data.
brandstringoptionalCase-insensitive brand name substring (e.g. Anker, Samsung). Leave empty for all brands.
minRatingintegeroptionalKeep only deals whose product rating is at least this value. Deals without a rating are excluded when this is set.
priceMinintegeroptionalKeep deals at or above this price in the marketplace's local currency.
priceMaxintegeroptionalKeep deals at or below this price in the marketplace's local currency.
discountMinintegeroptionalKeep deals with at least this percentage off, filtered by Amazon itself.
discountMaxintegeroptionalKeep deals with at most this percentage off, filtered by Amazon itself.
primeExclusiveOnlybooleanoptionalOnly return deals in Amazon's Prime Exclusive collection.
sortBystringoptionalFeatured keeps Amazon's order. Other sorts read the fetched deal window before returning, so they may take longer.
maxItemsintegeroptionalHard cap on emitted deal records. Amazon exposes up to 500 deals per category/collection query; add categories to partition the window.

3. Start an Actor run

Set APIFY_TOKEN in your environment. Python 3.10 or newer is sufficient; this recipe uses no third-party packages.

Execution may incur charges. Review current pricing on Apify. The request asks for a 120-second timeout and a charge limit; these settings are subject to Apify’s pricing and do not guarantee an all-inclusive spending cap.

import json
import os
import urllib.request

# Save the schema-derived example as input.json; review and edit it first.
with open("input.json", encoding="utf-8") as stream:
    actor_input = json.load(stream)

token = os.environ["APIFY_TOKEN"]
request = urllib.request.Request(
    "https://api.apify.com/v2/acts/yZ5tcZFmAAXi1egIo/runs?timeout=120&maxTotalChargeUsd=0.50",
    data=json.dumps(actor_input).encode("utf-8"),
    headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
    method="POST",
)
# This starts a potentially billable run. Do not automatically retry this POST.
with urllib.request.urlopen(request, timeout=40) as response:
    run = json.load(response)["data"]
print("Run ID:", run["id"])
print("Status:", run["status"])

Open the run in Apify Console and wait for a successful completion. Use the published output schema to locate results and the dataset schema to understand declared views. Missing or optional record fields must not be treated as guaranteed values.
